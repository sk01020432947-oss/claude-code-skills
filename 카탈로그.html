설치 및 사용법

  1. 받기 — 공유받은 claude-skills-share.zip 압축을 풉니다.
  2. 설치 — 원하는 스킬 폴더만 골라 C:\Users\<내이름>\.claude\skills\ (Mac/Linux는 ~/.claude/skills/)에 복사합니다. 전부 복사해도 됩니다.
  3. 사용 — Claude Code를 재시작한 뒤, 채팅에서 /스킬이름을 입력하거나 각 스킬의 발동 트리거 문장(카드의 "상세 설명" 참조)을 자연어로 말하면 자동 발동됩니다.
  4. 골라 가져가기 — 각 카드의 복사 아이콘을 누르면 스킬 폴더명이 클립보드에 복사됩니다. ZIP 압축을 푼 곳에서 같은 이름의 폴더를 찾아 .claude\skills\에 넣으면 그 스킬만 설치됩니다.

⚠ 일부 스킬은 별도 준비물이 필요합니다 — 영상 제작 계열(ElevenLabs·HeyGen·fal.ai API 키), 이미지 렌더 계열(codex CLI), 검색 계열 ir-search·insane-search(Python + curl_cffi), 공공데이터 계열(data.go.kr 등 본인 API 키). 키가 없으면 실행 시 스킬이 안내합니다.
