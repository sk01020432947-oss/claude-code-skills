## 설치 방법

### 1. 내려받기

```bash
git clone https://github.com/sk01020432947-oss/claude-code-skills.git
```

또는 이 페이지 우측 상단 **Code → Download ZIP**.

### 2. 스킬 폴더 복사

`skills/` 안에서 원하는 스킬 폴더를 골라 아래 위치에 넣습니다.

| 운영체제 | 경로 |
|---|---|
| Windows | `C:\Users\내계정이름\.claude\skills\` |
| Mac / Linux | `~/.claude/skills/` |

> **Windows에서 빠르게 찾기** — `윈도우키 + R` → `%USERPROFILE%\.claude\skills` 입력 후 엔터
> `skills` 폴더가 없으면 `.claude` 안에 새로 만드세요.

폴더째로 넣어야 합니다. 예) `skills/sermon-research` → `.claude/skills/sermon-research`

### 3. Claude Code 재시작

## 사용 방법

채팅창에 `/스킬이름`을 입력하거나, 그냥 평소 말투로 말하면 알아서 발동합니다.

```
/sermon-research
```
```
설교 준비 자료 조사해줘
```

어떤 스킬이 어떤 말에 반응하는지는 카탈로그의 "상세 설명 · 발동 트리거"에서 확인할 수 있습니다.

## 준비물이 필요한 스킬

대부분은 그냥 쓰면 되지만, 외부 서비스를 쓰는 일부 스킬은 본인 API 키가 필요합니다. 키가 없으면 실행할 때 스킬이 안내해 줍니다.

| 분야 | 필요한 것 |
|---|---|
| 영상 제작 | ElevenLabs / HeyGen / fal.ai API 키 |
| 이미지 렌더 | codex CLI |
| 검색 계열 | Python + `curl_cffi` |
| 공공데이터 | data.go.kr 등 본인 API 키 |

## 함께 보면 좋은 스킬 (여기 없음)

아래 스킬은 다른 분들이 만들어 공개한 것이라 이 저장소에 포함하지 않았습니다. 원본에서 받으세요.
