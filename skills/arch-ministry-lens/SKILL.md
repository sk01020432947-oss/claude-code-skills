# arch-ministry-lens

데이터는 전부 `korean-archhub` MCP 도구로 조회한다. 이 스킬은 순서·검증·출력 형식만 정한다. 새 코드·키 없음.

## 0. 입력 확인
- 주소(동 + 번지) 또는 동 이름, 용도(실사·돌봄·심방·설교·강의·브리프).
- 항상 `find_region`부터. 번지가 섞인 주소는 bun/ji가 자동 분리된다.
- 소유자·위반건축물 여부는 이 MCP 범위 밖이다. 묻지도 추정하지도 않는다.

## 1. 레시피

| 용도 | 호출 순서 | 산출 |
|---|---|---|
| 교회 건물 실사(매입·임대·리모델링) | `building_profile` → `parcel_history` → `building_floors` | 확인표: 용도지역·주용도·구조·규모·주차·정화조·내진·사용승인·철거(석면) 이력. 종교시설 가능 여부·주차 기준은 `korean-law-search`로 별도 확인 |
| 통합돌봄 주거취약 동 선별 | `district_stats(min_age_years=30)` → `old_buildings(40)` → `seismic_check` | 동별 노후 비율·내진 미적용 추정 수 표 + 방문 우선 동 3곳. 고령화율은 `stats-ministry-lens`와 결합 |
| 심방·교구 현황 | 교구 동마다 `district_stats` | 동 × (단독주택 비율, 30년↑ 비율, 평균 경과연수) 표 |
| 새가족·교회학교 수요 예측 | `permits_pipeline(since_year)` → 공동주택·세대수만 추림 | 착공/미착공 단지·세대수·허가일 → 1~3년 뒤 유입 메모. 학교 쪽은 `school-ministry-radar` |
| 설교·강의 한 줄 | `district_stats` 연대별·노후도 | "○○동 건물 N동 중 30년↑ M동(K%)" + 출처·조회일 각주 |
| 정책·의회 브리프 | 여러 동 `district_stats` → (`local-government` 예산·조례, `korean-law` 조문) | 동 × 지표 매트릭스 + 한계 문단 |
| 철거·석면 안내 | `demolitions(since_year)` | 석면 부위 ⚠ 현장 목록 → 인근 교육관·어린이집 안내문 초안 |

## 2. 검증 규칙 (실측 2026-10-04)
- **전남광주통합특별시 지역(전남·광주)은 `find_region`이 코드를 주지만 대장 도구가 `[NOT_FOUND]`를 돌려준다**(순천 조례동·연향동, 광주 서구 치평동 확인. 서울 광진구·부산진구는 정상). 이때 지어내지 말고 "건축HUB 응답 없음"으로 적고 대안을 안내한다: 세움터(eais.go.kr) 열람 또는 `building-register-search` 스킬.
- `[NOT_FOUND]`·`[EXTERNAL_API_ERROR]`는 그대로 보고한다. 추측 금지.
- 공시가격(`price_history`)은 시세가 아니다. 상승률을 시세 상승으로 쓰지 않는다.
- `seismic_check`는 의무화 연혁 기반 **추정**이다. "내진 미적용"이 아니라 "미적용 추정"으로 쓴다.
- 큰 동은 응답이 느리다. 필지 질문은 번지를 꼭 넣는다.
- 수치에는 "출처: 국토교통부 건축HUB(data.go.kr), 조회일"을 붙인다. 출처 없는 수치는 "예시"(CLAUDE.md 규칙 8).
- 특정 주택·동네를 설교·광고에서 낙인으로 쓰지 않는다. 개별 번지는 공개 자료에 싣지 않는다.
