# 노모스(νόμος) 용례 판별

출처: 이진섭, 「바울과 율법」 §1. 로마서 74회 + 갈라디아서 32회 = 106회 (바울전서 전체 121회의 88%, 신약 전체 194회의 55%). 율법 논의를 이 두 서신에 국한해도 충분한 이유다.

## 판별 원리

- 헬라어 '노모스'가 언제나 '율법'을 의미하지는 않는다. 판별 기준은 **문맥 속에서 실제로 가리키는 지시대상(referent)** — 오그덴-리차즈의 '의미 삼각형'(기호 symbol → 개념 thought → 지시대상 referent) 적용.
- 1세기 '율법' 논의는 '모세의 토라'에 대한 논의다(마 8:4; 19:7-8; 요 1:17, 45; 행 15:1, 5; 고전 9:9; 고후 3:15 등에 반영).
- **제유법(synecdoche) 용례 주의**: '율법'이 '행위 보응의 원리'를 대신 지시하거나(롬 2장), '계명'이 '율법' 전체를 지시하는(롬 7:9) 경우가 있다.

## 판별 시 자주 틀리는 지점

1. **롬 3:27** — 한 구절 안에 두 용례: "무슨 법으로냐"(법 체계) + "믿음의 법으로니라"(믿음의 법). '믿음의 법'을 단순 수사로 읽으면 로마서의 축을 놓친다.
2. **롬 8:2** — "생명의 성령의 법"(믿음의 법 계열) vs "죄와 사망의 법"(모세 율법의 정죄 기능 별칭). 후자를 '죄의 원리'로 읽으면 7장과의 연결이 끊어진다. '죄와 사망의 법'이라는 명칭 자체가 로마서가 율법의 기능 문제를 심각하게 논의하고 있다는 반증이다.
3. **롬 2:26 번역** — τὰ δικαιώματα τοῦ νόμου는 '율법의 제도/규례'(개역/개역개정)가 아니라 **'율법의 요구'**(홍인규). 롬 8:4의 동일 계열 표현은 두 역본 모두 '율법의 요구'로 옮겼다.
4. **롬 3:20 접속사** — διότι는 결론('그러므로')이 아니라 근거('왜냐하면', NRSV 'for')를 제시한다.
5. **갈 6:2 '그리스도의 법'** — 새 계명 목록이 아니라, 그리스도로 말미암아 신실한 새 이스라엘을 창조해내는 '믿음의 법'을 실현하라는 뜻.
