# kbg 발표자료 5 — 보드게임 로드맵

출처: 유튜브 혼잡스(@honjobs) 발표 영상 프레임 실측(2026-10-28). 다른 스타일과 비교·선택은 라우터 [kbg-발표자료](../kbg-발표자료/SKILL.md)에서 한다.
[template.html](template.html)이 정본 틀이다(엔진·CSS 인라인, 단독 실행). **구조와 클래스는 그대로 두고 내용만 바꾼다.**

## 0. 시작 전

- 발표자료이므로 **작업 시작 전 한 번** 묻는다: "`awesome-ai-motion` 스킬도 함께 쓸까요?" (CLAUDE.md 8번). 승낙해도 이 스킬의 시각 규칙이 우선이다.
- [template.html](template.html)을 `~/Desktop/cysjavis/<주제폴더>/<한글이름>.html`로 복사한 뒤 고친다(정본). 아티팩트는 사본이다.
- 통계는 출처 있는 값만 쓴다. 없으면 자막이나 라벨에 "(예시)"를 붙인다.
- 공용 마크업(`data-in`, `data-cams`, `data-count` 등)과 진행 키는 라우터 [kbg-발표자료](../kbg-발표자료/SKILL.md) 2·3절에 있다.

## 1. 스타일 사양 (영상 실측)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#FAFCF9` | 살짝 초록 기운의 흰 판 |
| `--ink` | `#111` | 트랙, 외곽선 |
| `--red` | `#F01400` | 자동차 |
| `--yellow` `--orange` `--green` `--blue` `--purple` `--pink` | `#FAAA00` `#FA8C3C` `#78C8A0` `#4A90E2` `#9B6FD0` `#F28DB2` | 트랙 구간·배지 색(구간마다 하나) |
| `--hl` | `#FFE14D` | 라벨 형광 |

| 글꼴 | 쓰임 |
|---|---|
| Black Han Sans (`--title`) | 크레용 제목 `.ctitle` — 줄무늬 `--c1`/`--c2`, 외곽선 7px, `#crayon` 필터 |
| Gaegu 700 (`--hand`) | 정거장 라벨 `.lbl` |
| Pretendard | 자막, 카드 본문 |

## 2. 부품

| 클래스·심볼 | 모양 |
|---|---|
| `.board` + `.deco` | 표지·배경 판, 장식 절대 배치 |
| `.ctitle` | 크레용 제목. `<span style="--c1:…;--c2:…">`로 줄 색 바꿈 |
| `section.road[data-stops="0,.17,…,1"]` | 트랙 장면. 정거장 위치(0~1) 목록 |
| `<path id="trk" pathLength="100">` | 트랙 모양. **이 d 값 하나만 바꾸면** 카메라·정거장·자동차가 따라온다 |
| `.stop[data-stop]` > `.lbl` > `span` + `small` | 정거장 라벨(좌표는 스크립트가 계산) |
| `#car` `#tree` `#cone` `#seats` `#flag` | 자동차, 나무, 고깔, 관중석, 결승 깃발 |
| `.badge` | 색 배지 |
| `.dimwrap` > `.pcard` | 어둡게 깐 배경 위 팝업 카드(체크 목록) |

예시 장면 4개: 표지(크레용 제목+차+깃발) → 트랙 6정거장(7박자, 마지막 전체 보기) → ③번 칸 팝업 카드 → 결승.

## 3. 모션 어휘

| 움직임 | 구현 | 쓸 때 |
|---|---|---|
| 자동차 주행 | `offset-path` + 박자별 `offset-distance` | 다음 단계로 |
| 카메라 추적 | 스크립트가 `getPointAtLength`로 `data-cams` 생성, 마지막 `1900,1100,.49` 전체 | 단계마다 클로즈업 → 전체 |
| 라벨 팝 | `.lbl[data-in]` | 정거장 도착 |
| 카드 팝 | `.pcard.pop` + `li[data-in]` | 한 단계 깊이 보기 |

정거장 수를 바꾸면 `data-stops`, `.stop` 개수, 자막 수(정거장 수 + 전체 보기 1)를 함께 맞춘다. 트랙 색 구간은 `<use>`의 dasharray `"0 시작 길이 100"`으로 정한다.

## 절차

1. 원고를 **장면 → 박자**로 쪼갠다. 박자 하나 = 자막 한 줄 = 화면 변화 하나. 자막은 25자 안팎.
2. 템플릿 예시 장면 중 가장 가까운 것을 복제해 내용만 바꾼다. 쓰지 않는 예시 장면은 지운다.
3. 브라우저로 열어 →로 넘기며 확인한다. 넘침·겹침은 글자 크기보다 **박자를 나눠서** 푼다.
4. 장면별 확인 사진: `node ~/.claude/skills/kbg-발표자료/tools/record.mjs 발표.html --shots 확인 --beats`
