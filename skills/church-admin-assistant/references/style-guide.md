# 문체가이드 (예시 — 교회 관행에 맞게 고치십시오)

## 호칭
- 교인 전체: "성도님들", "온 교우" (교인/회원/신자 혼용 금지)
- 직분은 이름 뒤에: "김OO 장로", "이OO 권사"

## 경어
- 주보·안내문: 합쇼체 ("~합니다", "~해 주십시오")
- 카톡 공지: 합쇼체 기본, 청년부 공지만 해요체 허용

## 날짜·시간 표기
- 11월 15일(주일) — 일요일 대신 "주일"
- 오전/오후 표기, 24시간제 쓰지 않음: 오후 7시 30분
- 기간: 11월 18일(수)까지

## 금지 표현
- 과장: "역대급", "꼭꼭!!", 느낌표 두 개 이상
- 강요: "반드시 참석", "불참 시"
- 낯선 외래어: "케어" → "돌봄", "이벤트" → "행사"
