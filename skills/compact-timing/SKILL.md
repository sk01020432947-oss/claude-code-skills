# compact-timing

2026-10-10 설치. 근거: everything-claude-code의 strategic-compact 발상 + Claude Code 공식 문서 costs 절(2026-10-10 확인).

## 판정표

| 상황 | 쓸 것 | 이유 |
|---|---|---|
| 다음 일이 지금 일과 무관하다 | `/clear` (필요하면 먼저 `/rename`) | 비용 없음. 낡은 맥락이 매 메시지에 실리지 않는다 |
| 산출물의 성격이 바뀐다 (조사→집필, 초고→퇴고, 분석→시각화) | `/compact <보존 지시문>` | 다음 단계에 필요한 것만 남긴다 |
| 한 시간 넘게 쉬었다 돌아왔다 | 새 세션 또는 요약에서 재개 | 캐시가 식어 전체 대화를 다시 읽는다 |
| 여러 파일을 고치는 중, 디버깅 중, 파이프라인 실행 중 | 아무것도 하지 않는다 | 경로·변수명·중간 판정을 잃는다 |
| 읽을 양이 많은 일이 남았다 | 서브에이전트에 넘긴다 | 원문이 본 대화에 실리지 않는다 |

## 보존 지시문

`/compact` 뒤에 그대로 붙인다. 괄호 안은 그 세션의 실제 값으로 바꾼다.

- 설교: `본문 구절, 확정한 중심 명제와 대지, 인용한 주석의 저자·자료명·위치, 정본 파일 경로를 보존. 탈락한 대안은 버림.`
- 강의안: `과목·주차, 학습목표, 확정한 목차, 출처 있는 통계와 그 출처, 정본 파일 경로를 보존.`
- 영상 묶음 분석: `영상별 한 줄 요약, 수치 검증표의 판정, 산출물 경로, 아티팩트 URL을 보존. 자막 원문은 버림.`
- 논문·보고서: `연구 질문, 확정한 구조, 인용 키와 읽음 표시 여부, 미해결 심사 의견을 보존.`
- 코드: `변경한 파일 경로, 통과·실패한 테스트 이름, 아직 안 고친 원인을 보존.`

## 절차

1. 지금이 판정표의 어느 줄인지 한 문장으로 말한다.
2. `/compact`라면 위 지시문을 이 세션 값으로 채워 한 줄로 제시한다.
3. 압축 전에 디스크에 없는 결정(아직 파일에 안 쓴 판정, URL)이 있으면 먼저 파일에 쓴다.
4. 실행은 사용자가 한다. 이 스킬은 명령을 대신 실행하지 않는다.

## 하지 않는 것

- 자동 압축 임계값(`CLAUDE_AUTOCOMPACT_PCT_OVERRIDE`) 변경 제안. 낮추기만 가능하고 압축 자체가 큰 요청이다.
- 사용자가 묻지 않았는데 매 턴 압축을 권하는 일.
