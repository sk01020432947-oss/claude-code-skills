# 내용증명 초안 (notice-letter-kr)

초안 머리에 "AI 작성 내용증명 초안 — 발송 전 본인·전문가 확인"을 넣는다. 사실은 사용자가 준 자료에서만 가져오고, 없는 사실·금액·날짜는 지어내지 않고 `[확인 필요]`로 둔다.

## 1. 먼저 묻는다 (AskUserQuestion 1회)

- 이행 기간: 7일 / 14일 / 30일
- 가진 증거: 계약서 / 세금계산서·청구서 / 메일·메시지 / 납품 확인 (복수 선택)
- 현재 절차: 없음 / 변호사 상담 중 / 소송·조정 진행 중 (진행 중이면 표현 수위를 낮추고 변호사 확인을 먼저 권한다)
- 형식: DOCX / HWPX / HTML (인터넷우체국 업로드는 DOCX·HWP 계열)

## 2. 근거 조회 (korean-law MCP)

- 지체 책임: 민법 제387조. 금전채무: 제397조. 해제 전 최고: 제544조.
- **시효**: 내용증명(최고)은 6개월 안에 재판상 청구·압류 등을 하지 않으면 시효중단 효력이 없다(민법 제174조). 점검표에 반드시 적는다.
- 공공기관 상대 반환 요구·처분이면 행정절차법·행정심판법·해당 개별법을 `search_law`로 확인.
- 초안의 모든 법 인용은 `legal_analysis(mode=verify_citations)`로 검증.

## 3. 산출물 3종

1. **초안**: 수신인·발신인(상호·주소는 등기부 기준) / 제목 / 계약 사실 → 이행 사실 → 미이행 사실(시간순) → 요구 사항(금액·기한·계좌) → 불이행 시 조치(지급명령·소송 등, 위협·명예훼손 표현 금지) / 날짜·서명.
2. **사실확인표**: 각 문장 ↔ 근거 증거 대조, 미확인 항목 표시.
3. **발송 전 점검표**: 당사자 표기, 금액 계산, 기한 날짜, 감정적 표현 제거, 3부 출력(발신·수신·우체국 보관), 배달증명 선택, 시효 일정.

저장: `~/Desktop/cysjavis/법률_대응/<사건명>_내용증명_초안.docx`, `_사실확인표.html`, `_발송전점검표.html`.

## 4. 멈춤선

발송은 사용자가 직접 한다(인터넷우체국 → 우편 → 내용증명, 회원 로그인 필요). Claude는 발송·결제를 하지 않는다. 금액이 크거나 분쟁이 진행 중이면 변호사·대한법률구조공단(132) 상담을 먼저 권한다.
