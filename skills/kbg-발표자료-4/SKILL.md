# kbg 발표자료 4 — 데스크톱 창 타임라인

출처: 유튜브 혼잡스(@honjobs) 발표 영상 프레임 실측(2026-10-28). 다른 스타일과 비교·선택은 라우터 [kbg-발표자료](../kbg-발표자료/SKILL.md)에서 한다.
[template.html](template.html)이 정본 틀이다(엔진·CSS 인라인, 단독 실행). **구조와 클래스는 그대로 두고 내용만 바꾼다.**

## 0. 시작 전

- 발표자료이므로 **작업 시작 전 한 번** 묻는다: "`awesome-ai-motion` 스킬도 함께 쓸까요?" (CLAUDE.md 8번). 승낙해도 이 스킬의 시각 규칙이 우선이다.
- [template.html](template.html)을 `~/Desktop/cysjavis/<주제폴더>/<한글이름>.html`로 복사한 뒤 고친다(정본). 아티팩트는 사본이다.
- 통계는 출처 있는 값만 쓴다. 없으면 자막이나 라벨에 "(예시)"를 붙인다.
- 공용 마크업(`data-in`, `data-cams`, `data-count` 등)과 진행 키는 라우터 [kbg-발표자료](../kbg-발표자료/SKILL.md) 2·3절에 있다.

## 1. 스타일 사양 (영상 실측)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` / `--grid` | `#F3F3F0` / `#E1E1DC` | 48px 모눈 바탕 |
| `--ink` | `#111` | 창 테두리, 글자 |
| `--red` | `#E8342A` | 오늘 날짜 동그라미, REC, 창 닫기 점 |
| `--blue` / `--sel` | `#2A6CF0` / `#B5D3FF` | 커서, 텍스트 선택 영역 |
| `--yellow` | `#FADC46` | 형광 훑기 `.mk` |

| 글꼴 | 쓰임 |
|---|---|
| Black Han Sans (`--title`) | 창 안 큰 제목 `.big` |
| Pretendard | 창 제목, 본문, 자막 |
| JetBrains Mono (`--mono`) | 파일명·코드 `.mono` |

화면 구성: 고정 요소 둘 — 왼쪽 `.dock`(앱 아이콘 4개), 오른쪽 `.months`(2026 + 1~12월). 장면의 `data-mark="N"`이 N월을 켠다. 내용은 가운데 **맥 창** 안에 둔다. 자막은 아래 흰 박스 + 검정 테두리.

## 2. 부품

| 클래스 | 모양 |
|---|---|
| `.win` > `header > em` + `.body` | 맥 창(● ● ● · 제목 · ⤢). `.pop`이면 튀어나옴 |
| `.win.dark.cam` + `.rec` | 웹캠 창, REC 깜박임 |
| `.chip` | 창 안 태그 |
| `.cal` > `span.h` / `span` / `span.today` / `i.ev` (`.r`) | 달력 칸, 오늘(빨간 동그라미), 일정 칩 |
| `.cursor` | 마우스 커서. 위치는 `.c2[data-beat="1"] .cursor{left;top}`처럼 박자별 CSS |
| `.ripple` | 클릭 물결 |
| `.popup` > `b` + `small` | 일정 팝업 |
| `.sel` / `.mk` | 파란 선택 / 노랑 형광 훑기 |
| `.doc` | 문서 창 본문 |

예시 장면 6개: 표지 창+웹캠 → 달력 클릭·팝업 → 창 3개 겹쳐 쌓기 → 기사 본문 선택·형광 → 웹캠 크게+메모 창 → 맺음.

## 3. 모션 어휘

| 움직임 | 구현 | 쓸 때 |
|---|---|---|
| 창 팝 | `.win.pop` | 새 자료 등장 |
| 창 쌓기 | 창마다 `data-in` 0,1,2 + 위치 어긋나게 | 자료가 쌓이는 과정 |
| 커서 이동·클릭 | `.cursor` 박자별 위치 + `.ripple` | "여기를 누르면" |
| 월 레일 | `data-mark` | 시간 흐름 |
| 선택·형광 | `.sel` `.mk` | 문서 속 한 줄 강조 |

커서 좌표는 장면 기준 px이다. 달력 칸을 바꾸면 커서·물결·팝업 좌표도 함께 옮긴다.

## 절차

1. 원고를 **장면 → 박자**로 쪼갠다. 박자 하나 = 자막 한 줄 = 화면 변화 하나. 자막은 25자 안팎.
2. 템플릿 예시 장면 중 가장 가까운 것을 복제해 내용만 바꾼다. 쓰지 않는 예시 장면은 지운다.
3. 브라우저로 열어 →로 넘기며 확인한다. 넘침·겹침은 글자 크기보다 **박자를 나눠서** 푼다.
4. 장면별 확인 사진: `node ~/.claude/skills/kbg-발표자료/tools/record.mjs 발표.html --shots 확인 --beats`

node ~/.claude/skills/kbg-발표자료/tools/record.mjs 발표.html 발표.mp4 --fps 30
