# ip-ministry-lens

데이터는 전부 `korean-patent` MCP 도구로 조회한다. 이 스킬은 순서·검증·출력 형식만 정한다. 새 코드 없음.
법률 판단(등록 가능성·침해 여부)은 하지 않는다. 결론은 항상 "조회 결과 요약 + 변리사 확인 필요 여부"까지.

## 0. 입력 확인
- 무엇을: 이름(상표) / 물건 모양(디자인) / 기술·아이디어(특허) / 기관(출원인).
- 용도: 사역명·책·굿즈·앱·설교 예화·강의·지역 브리프.
- 상표면 쓸 영역(책=16류, 앱·전자책=9류, 교육·세미나·출판서비스=41류, 광고·판매=35류)을 먼저 정한다.

## 1. 레시피

| 용도 | 호출 순서 | 산출 |
|---|---|---|
| 이름 상표 사전점검 | `search_trademark(이름)` → 표기 변형 2~3개(띄어쓰기·영문·약칭) 재검색 → 걸린 건 상품류·상태 확인 | 표: 상표·상품류·상태(출원/등록/거절/소멸)·권리자. 판정 3단: 같은 류 등록·출원 있음 / 다른 류만 있음 / 조회 0건 |
| 굿즈·교구 디자인 | `search_design(물품명)` → 비슷한 건 출원번호 기록 | 등록 디자인 목록 + 도면 링크 |
| 설교·강의 예화 | `search_patents(키워드, sortSpec=AD, numOfRows=100)` 페이지 2~3개 → 연도별 건수 직접 집계 | "○○ 관련 국내 출원이 20XX년 n건 → 20YY년 m건" 한 줄 + 조회일·검색식 각주 |
| 통합돌봄·복지 기술 동향 | `search_patents_advanced(abstract=돌봄 등, inventionTitle=…)` → 상위 출원인 `search_by_applicant` | 기술 유형×출원인 표, 슬라이드용 사례 3건(출원번호 포함) |
| AI 도구 선행기술 메모 | `search_patents_advanced(abstract=핵심기능, ipc=G06F/G06Q/G06N)` → 근접 3~5건 `get_patent_detail` | 근접 특허별 청구항 수·상태·차이점 1줄. "선행조사 메모(법률의견 아님)" 표기 |
| 지역 기관 브리프 | `search_by_applicant(대학·기관명)` + `search_by_rightholder` → (보조) `stats-ministry-lens`로 지역 통계 | 기관별 최근 출원 주제, 지역 목회·청년 진로 시사점 |

MCP가 죽었거나 쿼터 초과면 `korean-patent-search` 스킬(KIPRIS_PLUS_API_KEY 필요, 특허 키워드·상세만)로 내려가고, 그것도 안 되면 kipris.or.kr 웹 검색 경로를 안내한다.

## 2. 검증 규칙 (실측 · 2026-10-04)
- **공용 키 쿼터는 무키 사용자 전원이 나눠 쓰는 하루 30회다.** 2026-10-04 오전에 이미 소진돼 3회 호출이 모두 `Shared API daily cap reached`로 거부됐다. 사용자 키(`kipris-key` 헤더)가 없으면 이 오류를 그대로 보고하고 결과를 지어내지 않는다.
- `[NOT_FOUND]`는 "그 검색어로 0건"이지 "아무도 안 씀"이 아니다. 표기 변형으로 다시 찾고, 0건이어도 "미등록 확인"이라고 쓰지 않는다.
- 자유검색어의 `+ * ? ! ^`는 KIPRIS 연산자다. C++, 1+1 같은 이름은 항목검색이나 표기 변형을 쓴다.
- 상표 유사 판단(칭호·외관·관념, 지정상품 유사군)은 AI가 확정하지 않는다. 같은 류에 비슷한 이름이 있으면 "변리사 확인 권장"을 붙인다.
- 상표·디자인 결과가 `resultCode 30`이면 그 키에 해당 서비스 활용신청이 없는 것이다. 사용자에게 KIPRIS Plus에서 서비스 추가 신청을 안내한다.
- 건수·추이는 조회 결과만 쓰고 검색식·조회일을 붙인다. 출처 없는 수치는 "예시"로 표시(CLAUDE.md 규칙 8).
- 남의 특허 문장을 설교·강의에 길게 옮기지 않는다. 요지 한 줄 + 출원번호.

## 3. 출력
- 각주: `KIPRIS(특허청), 출원번호 10-XXXX-XXXXXXX, 조회 YYYY-MM-DD, 검색식 "…"`.
- 저장: `~/Desktop/cysjavis/<주제폴더>/<한글이름>` (CLAUDE.md 규칙 4). 노트화는 옵시디언 `Obsidian 2025/400. Methodologies/에이전트자동화/`의 [[한국특허MCP_KIPRIS_활용노트]]에 링크. 발표자료로 만들면 시작 전 `awesome-ai-motion` 사용 여부를 1회 묻는다.
