# folder-tidy-recipes — 폴더 정리 레시피 3종

2026-10-09 설치. 근거: 클로드 코워크 영상 4편 분석(V1 김묘영 레시피, V3 감자나라 삭제 확인). 설치된 스킬 중 이 세 레시피를 덮는 것이 없어 설치했다.

## 공통 규칙 (모든 레시피)
- **읽기 → 표 → 승인 → 실행** 순서. 표를 보여 주기 전에는 아무것도 옮기거나 바꾸지 않는다.
- 영구 삭제 금지. 지울 것은 휴지통(`~/.Trash`)으로만 옮기고, 비우기는 사용자가 한다.
- 원본은 그대로 두고 결과는 새 파일로.
- 한글 파일명·경로는 python3로 다룬다(NFD 문제). `unicodedata.normalize('NFC', name)`로 비교.
- 결과 표는 `~/Desktop/cysjavis/ledger/<레시피>_<YYYY-MM-DD>.md`에 남긴다.
- 이름·전화번호·계좌번호 등 개인정보는 표에 그대로 옮기지 않는다(마스킹).

## R1. 분류 후 승인 (다운로드·스캔 폴더)
1. 대상 폴더를 읽어 표 작성: 파일명 | 크기 | 수정일 | 분류 | 이유 | 옮길 곳 제안
2. 삭제후보: 압축을 푼 흔적이 있는 zip, `(1)`·`(2)` 중복(해시 동일), `.dmg/.pkg`, 30일 지난 스크린샷
3. 보관추천: `~/Desktop/cysjavis/<주제폴더>/` 중 맞는 곳 제안(없으면 "확인필요")
4. 표 저장 후 멈춘다. 승인 받은 항목만 이동.
5. 표는 스크립트로 만든다(읽기 전용): `python3 -I ~/.claude/skills/folder-tidy-recipes/scripts/r1_triage.py <대상폴더> ~/Desktop/cysjavis/ledger/<이름>_<YYYY-MM-DD>.md`. 주제어 표는 스크립트 위쪽 `TOPICS`에서 고친다.

## R2. 영수증·증빙 → 엑셀
1. 열: 날짜 | 상호 | 품목 | 금액 | 부가세 | 카테고리 | 원본파일명 | 비고
2. 흐린 값은 비우고 비고에 "확인 필요". 날짜·상호·금액이 같으면 "중복 의심". 한 사진에 여러 장이면 여러 줄.
3. 시트2: 카테고리별 합계(수식으로). 시트3: 확인 필요 목록.
4. 저장: 대상 폴더 안 `영수증정리_<YYYY-MM>.xlsx`. 엑셀 작업은 xlsx 스킬 규칙을 따른다.

## R3. 파일명 일괄 변경
1. 규칙을 먼저 확정(예: `YYYY_MM_DD_내용`). 날짜는 EXIF → 파일 수정일 순으로.
2. 전후 대조표(이전 | 이후 | 날짜 출처)를 보여 주고 승인.
3. 충돌(같은 이후 이름)은 `_2`를 붙이고 표에 표시.
4. 실행 후 대조표를 ledger에 저장 — 되돌리기용.

## 검증
- R1: 실행 전후 파일 수 = 이동 수 + 남은 수.
- R2: 시트2 합계 = 시트1 금액 합계.
- R3: 대조표 줄 수 = 바뀐 파일 수, 중복 이름 0.
