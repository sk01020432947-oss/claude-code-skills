# 성안나장학재단 실무 스킬

(재)성안나장학재단은 서울특별시교육청(평생교육과) 관할 **재단법인·공익법인**이다. 이 스킬은 재단이 매년·수시로 만드는 문서를 주무관청 서식과 절차에 맞춰 작성하도록 돕는다.

## 원천자료 (항상 이 자료를 근거로 답한다)

- `templates/budget-settlement-forms.md` — 서울시교육청 「비영리법인 예산서·결산서」 붙임서식 1~19 전체 (사용자가 준 원본 PDF `(서식) 비영리법인 2026년도 예산서 및 2025년도 결산서.pdf`에서 추출)
- `references/operations-manual.md` — 서울시교육청 「2026 공익법인 실무지침서」에서 정관변경, 임원관리, 재산관리(기본재산 허가), 회계관리, 민원사무처리기준(제출기한표), 정관준칙, 회의록 예시, 장학금 지급규정 예시를 추출한 요약 (원본 PDF `서울특별시교육청 2026 공익법인 실무지침서.pdf`, 403페이지)

**서류를 만들거나 절차를 답할 때는 반드시 위 두 참고자료를 먼저 확인하고, 원본 PDF의 표현·기준금액·기한을 그대로 인용한다.** 추측하거나 일반 상식으로 대체하지 않는다. 두 참고자료에 없는 내용이면 "실무지침서에서 확인 필요"라고 명시한다.

## 재단 기본정보 (매 문서에 자동 반영)

| 항목 | 값 |
|---|---|
| 법인명 | 재단법인 성안나장학재단 |
| 법인 형태 | 재단법인 (사단법인 아님 — 회원·회비·총회 개념 없음, 최고의결기구는 **이사회**) |
| 주무관청 | 서울특별시교육감(평생교육과) |

이사장 성명, 설립일, 기본재산액, 주소, 전화, 이사·감사 명단 등은 매번 물어보지 말고, 사용자가 한 번 알려주면 project 메모리로 저장해 재사용을 제안한다. 모르는 값은 원본 서식처럼 `○○○`로 비워두고 채우도록 안내한다.

## 문서 유형별 워크플로우

### 1. 이사회 회의록 (총회 아님 — 재단이므로 이사회가 최고기구)

1. `templates/budget-settlement-forms.md`의 "붙임 13-①" 양식을 기본 틀로 쓴다.
2. 회의일시·장소·안건·참석 이사 수를 사용자에게 확인한다.
3. 안건이 "사업계획·예산(안)" 또는 "사업실적·결산(안)"이면 상정→설명→의결→가결선포의 정형 문구를 그대로 따른다 (임의로 문체를 바꾸지 않는다 — 이 문체가 공증·감사 시 표준으로 통용됨).
4. 불참 이사가 있으면 붙임13-③ 위임장도 함께 만들지 물어본다.
5. `references/operations-manual.md`의 "의사록 인증 제외대상 법인 제도"를 확인해, 성안나장학재단이 공증 의무 대상인지 예외 대상인지 안내한다.
6. 회의록은 각 장마다 간인, 의장 및 출석 이사 전원 기명날인이 필요함을 안내한다(민법 제76조제2항).

### 2. 사업계획서·예산(안) / 사업실적·결산(안)

1. 붙임1(사업계획 총괄표) / 붙임3(사업실적 총괄표) 표를 기준으로 잡는다.
2. 개별 사업은 붙임2 양식(목적·사업내용·시행방법·소요예산·기대효과)으로 사업별 1건씩 작성한다.
3. 수입 합계(A)와 지출 합계(B)가 반드시 일치하는지 검산한다.
4. 전기이월액(⑧)은 전년도 결산서의 차기이월액(⑦)과 반드시 일치시킨다.
5. 재단법인이므로 "회비" 관련 항목은 모두 해당없음으로 표기한다.

### 3. 예결산보고 (교육청 제출용 전체 패키지)

매년 1~2월, 붙임 1~19 전체를 세트로 묶어 제출한다(사단법인 전용 항목인 회원명부 등은 제외). `templates/budget-settlement-forms.md`의 표지 공문 붙임 목록을 체크리스트로 사용해 빠진 서류가 없는지 확인한다. 특히:

- 붙임7 재산목록: 보유 계좌 누락 시 **설립허가 취소 사유**(민법 제38조) — 반드시 전 계좌 확인
- 붙임9 상근인건비: 결산서 총괄표 상근인건비 합계와 반드시 일치
- 붙임14·15(재무상태표·운영성과표): 국세청 홈택스 결산공시 대상이면 홈택스 출력물로 대체, 아니면 자체 작성
- `references/operations-manual.md`의 민원사무처리기준표에서 제출기한·구비서류·근거법령을 재확인

### 4. 정관변경

1. `references/operations-manual.md`의 "정관관리 — 정관의 변경" 절차를 먼저 확인해 **허가 대상**인지 절차를 안내한다.
2. 이사회 의결(정관 관련 조항 및 의결정족수 확인) → 변경 사유서·신·구조문 대비표·이사회 회의록 작성 → 교육청 허가신청.
3. `references/operations-manual.md`의 "정관준칙(공익재단)" 표준 조문을 대조해, 변경하려는 조문이 준칙과 어긋나지 않는지 점검한다.
4. 신·구조문 대비표는 표 형식(조문 | 현행 | 변경(안) | 사유)으로 작성한다.

### 5. 재산관리 관련 문서 (기본재산 취득·처분·담보제공 등)

`references/operations-manual.md`의 "재산관리 — 기본재산의 허가사항"을 확인해 허가 필요 여부, 기준금액, 필요서류, 이사회 의결 요건을 먼저 안내한 뒤 문서를 작성한다.

### 6. 임원(이사·감사) 선임·변경

`references/operations-manual.md`의 "임원관리" 절차(결격사유, 임기, 교육청 보고·승인 필요 여부, 필요서류)를 확인한 뒤, 붙임10(임원현황)과 이사회 회의록(임원 선출안)을 함께 작성한다.

## 작성 원칙

- 원본 서식의 항목·순서·문구를 임의로 재구성하지 않는다. 교육청 제출용 서식은 양식 일치 여부를 심사하므로 구조를 바꾸면 반려될 수 있다.
- 금액·날짜·인원수 등 숫자는 사용자가 준 값만 채우고, 모르면 채우지 말고 되묻는다.
- "○○○" 같은 원본의 빈칸 표기는 실제 값을 모를 때 그대로 유지해 사용자가 채워 넣게 한다.
- 재단법인 특성(회원·회비·총회 없음)을 항상 반영하고, 사단법인 전용 문구가 섞여 들어가지 않게 점검한다.
- 완성된 문서는 사용자가 바로 출력·제출할 수 있도록 공문 형식(수신자/제목/붙임/시행일자/발신 법인명·이사장 직인란)을 갖춘다.
