# 영수증 → 경비 정리표

## 순서
1. 올라온 영수증 사진을 한 장씩 읽어 `receipts.json`에 적는다.
   항목: date(YYYY-MM-DD), store, category, items, amount(숫자), pay(법인카드·개인카드·현금), note
2. category는 사용자가 말한 계정 세트를 쓴다. 말이 없으면 기본 세트.
   - 기본(회사): 회의비·교통비·식대·소모품비·출장비
   - 교회 부서 회계: 예배비·교육비·선교비·구제비·친교비·행사비·관리비
   - 기관·연구(강의·용역): 회의비·여비·자료구입비·인쇄비·소모품비·사례비
   - pay의 '법인카드'는 교회·기관이면 '교회카드'/'기관카드'로 바꿔 적어도 된다(노란 표시는 개인카드·현금만).
3. `python3 ~/.claude/skills/expense-receipts/scripts/make_expense.py receipts.json <월>월_경비정리.xlsx` 실행.
4. 개인카드·현금 결제는 노란색으로 표시되고 '따로 청구' 비고가 붙는다(스크립트가 자동).
5. 끝나면 건수·합계·따로 청구할 건을 한 줄로 알려 준다.

## 꼭 지킬 것
- 금액·날짜가 흐릿해 확실하지 않은 영수증은 추측하지 말고 note에 "확인 필요"라고 적는다(그 행도 노란색).
- 합계는 사람이 마지막에 한 번 눈으로 확인하도록 안내한다. 돈은 사람이 책임진다.
- 결과 파일은 사용자가 지정한 폴더에만 저장한다.
