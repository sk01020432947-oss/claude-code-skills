## 채널 공통 화면 문법

1. **자막이 서사를 끈다.** 화면 제목보다 자막 한 줄이 주인공이다. 자막 한 줄에 화면 변화 하나를 맞춘다. 엔진에서는 이 단위를 박자(beat)로 부른다.
2. **바탕은 거의 흰색이다.** 순백이거나, 미색이거나, 모눈종이다. 강조색은 한 장면에 하나만 쓴다(빨강 또는 파랑, 형광 노랑).
3. **요소는 하나씩 들어온다.** 한꺼번에 보여주지 않고, 말하는 순서대로 하나씩 켠다.
4. **카메라가 움직인다.** 큰 캔버스 한 장을 두고 팬·줌으로 부분 → 전체를 보여준다(스타일 3·5).
5. **손맛을 섞는다.** 손글씨 주석, 손그림 선, 스티커, 크레용 질감으로 딱딱한 도식을 누그러뜨린다.

## 구현에서 바꾼 점

- 원본은 영상 편집 도구로 만든 것이다. 여기서는 HTML + CSS 애니메이션 + 공용 엔진으로 다시 만들었다. 그래서 현장 발표(키보드 진행)와 영상 녹화(MP4)를 한 파일로 함께 쓸 수 있다.
- 인물·소품 라인아트는 SVG 심볼로 단순화했다. 더 정교한 그림이 필요하면 스타일 2의 이미지 생성 프롬프트를 쓴다.
- 원본 영상의 내용과 문구는 옮기지 않았다. 예시 문구는 설교 준비와 AI라는 가상의 주제로 새로 썼고, 수치에는 "(예시)"를 붙였다.
