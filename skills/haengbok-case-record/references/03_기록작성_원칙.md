# 기록 작성 원칙

출처: 2025·2021 업무안내, 2014 통합사례관리 실천가이드.

## 1. 공식 원칙

| 원칙 | 출처 |
|---|---|
| 약식 표현·축약 금지, 다른 업무 관련자가 이해할 수 있게 구체적으로 | 2025 |
| 원하는 도움 = 피면담자가 한 말 중심 / 주요문제 = 면담자가 파악한 잠재 욕구 | 2021 서식1 |
| 상담자 종합의견은 상담자 의견 중심. 건강·복지·주거는 사실을 쓰고 의견은 따로 | 2021·2025 |
| 면담 후 짧은 시간 안에, 대상자 말을 자세히. 불명확한 건 전화로 확인 후 기록 | 2021 |
| 주관적 욕구와 전문적 판단 구분. 원인 없이 현상만 쓰기, 추측·사실 섞기는 "자주 하는 실수" | 2014 p.13 |
| 대상자 욕구와 가족 욕구 구분 | 2014 p.13 |
| 회의록은 사례별로, 식별정보(성명·주민번호·연락처) 삭제 | 2025 |
| 상담 전 기록 동의, 행복이음으로 관리된다는 고지 | 2025 |

## 2. 상담내용 쓰는 법

- 시간 순서, 사회복지 기록 문체(~함, ~하였음).
- 대상자 말은 따옴표로 직접 인용하거나 "~라고 함"으로 구분.
- 관찰(표정·주거 상태 등)은 "관찰됨"으로, 사례관리자 해석은 소견란으로 보낸다.
- 개입 행위 용어(2014 p.25): 경청, 공감, 지지, 동기부여, 직면, 재명명, 환기, 해석, 정보제공, 연계.

## 3. 상담자 종합의견(소견) 구조

종합의견에 들어갈 것(2014 p.11): 사례관리 요청 사유에 대한 견해, 대상 유형 분류 사유, 향후 필요한 서비스.

권장 문단 구조(SOAP/DAP을 국내 서식에 맞춤 — 구조 참고는 영문 실무 자료, 국내 교재 원문 미확인):
1. 근거(사실·관찰) — "○○라고 진술함", "○○이 관찰됨"
2. 사정(해석) — 어떤 욕구영역의 어떤 문제인지, 강점·위험요인
3. 판단 — 대상 구분(사례관리/서비스연계), 긴급·고난도 해당 여부
4. 필요한 개입 — 서비스·연계 기관·재사정 필요

금지: 근거 없는 진단명("우울증으로 보임" → "우울감 호소, 정신건강 선별 필요"), 가치판단("게으름").

## 4. 향후계획·목표 7원칙 (2014 p.22)

동사형 / 긍정어 / 성과형 / 달성 가능한 크기로 쪼개기 / 측정 가능(예: "주 3회 방 닦기") / 쉬운 말 / 대상자 관점.

자주 하는 오류: 단순 연계를 목표로 쓰기("이동지원 연계"), 제공자 관점("방문하여 지도함"), 장·단기 목표 단절.

좋은 예: "(단기, 1개월) 이동지원 서비스를 이용해 정형외과 진료를 월 1회 받는다."

단기 3~6개월(2014) / 서식6은 단기 3개월 이내, 장기 3~6개월 이상(2021). 기관 서식 기준을 따른다.
