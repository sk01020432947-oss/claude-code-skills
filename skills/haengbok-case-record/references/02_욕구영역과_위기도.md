# 욕구영역과 위기도

출처: 2021 희망복지지원단 업무안내 서식1 주요문제·서식4 위기도 조사지, 2014 통합사례관리 실천가이드(https://www.korea.kr/archive/expDocView.do?docId=36408), 2026 노인맞춤돌봄서비스 사업안내.

## 1. 10개 욕구영역 (서식1 주요문제 정의 요약)

| 영역(위기도 조사지 명칭) | 해당하는 경우 |
|---|---|
| 안전 | 생명 위협, 가족 내 폭력·학대·방임, 가족 내외의 안전 위협 |
| 건강 | 심각한 신체 질환, 정신질환, 자살 문제, 술·약물, 인터넷·게임·도박 중독 |
| 일상생활유지 | 식사·용변·옷입기·세탁·씻기·장보기, 전화·교통·복약관리, 외출, 여가 부족 |
| 가족관계 | 부부·부모자녀 갈등·단절, 양육·보육, 가족 돌봄·간병 부담 |
| 사회관계 | 친척·친구·이웃 관계 갈등·단절, 비공식 지지망 활용 문제 |
| 경제 | 의식주 자원 부족, 저축·부채 등 자산관리 |
| 교육 | 일상생활에 필요한 기초교육 습득 문제 |
| 고용 | 기술·경력 부족, 양육·돌봄·건강으로 취업 곤란, 고용 불안정 |
| 생활환경 | 주거·주거환경, 누수·가스누출 등 거주지 안전 |
| 법률 및 권익보장 | 법·옹호·인권 관련 권리보장 어려움 |

**애매할 때 분류 규칙(2014 p.14)**: 원인이 아니라 해결해야 할 행위로 나눈다. 수술비 부족 → 경제, 수술 자체가 필요 → 건강, 심각한 게임중독 → 건강(정신).

**우선순위**: 문제 심각성 순으로 장·단기 목표 설정. 욕구조사표에 우선순위 1~5.

**강점관점**: 좋아하는 것·잘하는 것·하고 싶은 것, 공식·비공식 자원(가족·이웃·종교단체)을 함께 적는다.

## 2. 위기도 조사지(서식4) 구조

문항마다 0~3점. 영역 배점: 안전 12, 건강 18, 일상생활유지 9, 가족관계 9, 사회관계 12, 경제 9, 교육 9, 고용 6, 생활환경 12, 법률 및 권익보장 6 (합계 102). 더 심각한 가구원·더 심각한 점수 기준으로 기입.

- 실시 시기: 욕구조사 때, 종결심사 때, 변화가 예상될 때. 욕구·위기도 조사가 끝나야 다음 단계 진행 가능(의무).
- 총점 판정 구간: 공식 기준 **없음/미확인**. 종결 기준은 "사례관리 전후 @점 이상 향상"으로 기관이 정한다.
- **AI 사용 원칙**: 상담 한 번의 녹취로 점수를 매기지 않는다. 영역별 "위기 단서"(녹취 근거)와 "위기도 재조사 필요" 여부만 제시한다.

## 3. 긴급·고난도 판단

| 구분 | 기준 |
|---|---|
| 긴급사례 | 정신질환 응급입원 필요, 학대·가정폭력 긴급 분리 필요, 무연고·노숙 등 긴급 주거지원 필요(2014 p.9) |
| 고난도 의뢰 검토 | 안전(학대·폭력·방임) + 정신건강 동시 해당(2021) |
| 긴급지원 | 주요문제별 서비스 수행방법에 긴급지원이 선택된 경우 긴급지원대상자 |

## 4. 2차 사정 척도 (판정 구간만, 문항은 원문 참조)

| 척도 | 범위 | 판정 |
|---|---|---|
| Beck 자살사고척도(SSI) 19문항 | 0~38 | ≤9 정상, 10~11 잠재적 위험, 12~14 위험, ≥15 고위험 |
| 우울 자가진단 21문항(BDI 계열) | 0~63 | 0~10 정상, 11~20 가벼운, 21~30 중한, ≥31 심한 우울 |
| Beck 불안척도(BAI) 21문항 | 0~63 | 22~26 불안, 27~31 심한, ≥32 극심 |
| BPRS 18문항 | 18~126 | ≤54 / 55~90 / ≥91 |

출처: 2014 실천가이드 p.115~127(서울대 「사회복지척도집」 재구성). 척도는 훈련받은 사람이 직접 실시한다. AI가 대화로 점수를 추정하지 않는다.

## 5. 노인 대상(노인맞춤돌봄 선정조사, 2026)

사회(S) 40·신체(P) 30·정신(M) 30점, 23개 지표. '상' 기준: 사회 ≥25, 신체 ≥15, 정신 ≥15 / '중': 사회 ≥12, 신체 ≥5, 정신 ≥6. 중점돌봄군 = 신체 상 + 사회 또는 정신 중 이상. 우울감 '예_심각' 또는 자살생각 '예_자주'면 심화조사 가능. 재사정 연 1회, 종결 후 사후관리 6개월.
