## 2. 초기상담 판정의견의 공공서비스 유형 (2021 서식1)

기초생활보장, 영유아, 아동, 청소년, 한부모가족, 장애인복지, 노인복지, 사회복지서비스(바우처), 긴급복지, 기타 사회복지서비스.

## 3. 연계 기관 예 (2014 p.4~6)

- 공공: 고용센터, 보건소, 교육청, 건강보험공단, 국민연금공단, 신용회복위원회
- 민간: 사회복지관, 지역자활센터, 정신건강복지센터, 노인보호전문기관
- 노인맞춤돌봄 연계 분류: 생활지원·주거지원·건강지원·기타지원(2026)

## 4. 연계 상태와 점검

- 서비스점검 이행상태: 이행종료 / 이행중 / 불이행. 점검방법: 전화·내방·방문(·시스템).
- 점검 관점(2014 p.24): 대상자 쪽(변화, 재사정 필요, 참여, 만족도), 제공기관 쪽(계획 대비 실제, 여건 변화, 협력 정도).
- 점검 결과 조치: 새 욕구·환경 변화 → 욕구 재조사 / 서비스 양·종류 변경 → 계획 재수립 / 호전·연락두절·1개월 이상 거부 → 종결 평가.
- 서비스연계 가구: 연계 시작 후 1~3개월 안에 참여 여부·제공 상황 점검 가능(2025).
