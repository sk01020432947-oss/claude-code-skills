# 위기 발언 대응 (일지 작성보다 먼저)

AI 초안 도구는 위기를 "판정"하지 않는다. 단서를 찾아 사람에게 즉시 알리는 역할만 한다.

## 1. 즉시 알림 단서

| 단서 | 예 |
|---|---|
| 자살·자해 | "죽고 싶다", "없어지고 싶다", 방법·시기 언급, 약 모아둠 |
| 학대·폭력 | 맞았다, 때린다, 위협, 감금, 돈을 빼앗김(경제적 학대) |
| 방임 | 식사 거름, 병원·약 중단, 돌봄 공백, 위생 극도 불량 |
| 긴급 주거 | 퇴거·단전단수 임박, 노숙 |
| 정신 응급 | 환청·망상 언급과 위험 행동 |

## 2. 절차 (기관 규정이 우선)

1. 담당자·팀장에게 즉시 보고. 일지 승인 전이라도 알린다.
2. 자살 위험: 대상자 안전 확인 → 정신건강복지센터·자살예방상담전화 109(복지부 통합번호) 등 전문기관 연계. 선별은 훈련받은 사람이 척도로(→ `02` 4절).
3. 학대 의심: 신고의무자 해당 여부를 확인하고(아동학대처벌법·노인복지법·장애인복지법 등) 아동보호전문기관·노인보호전문기관·112 신고 절차를 따른다. 조문은 신고 전 다시 확인.
4. 긴급사례 기준 해당 시 희망복지지원단·긴급복지 검토(→ `02` 3절).
5. 기록: 진술은 대상자 표현 그대로, 조치 시각·연락 기관·담당자를 남긴다.

## 3. AI 오류 주의

영국 Ada Lovelace Institute 보고서(2026-02)는 AI 전사 도구가 **실제 없던 자살사고를 기록한** 사례를 보고했다. 위기 단서는 반드시 녹음 원본·녹취록 원문과 대조한다.
