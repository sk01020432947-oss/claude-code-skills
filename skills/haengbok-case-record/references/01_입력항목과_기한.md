# 행복이음 입력 항목과 기한

출처: 2025 찾아가는 보건복지서비스 업무안내(복지부, 2025-02, https://www.mohw.go.kr/board.es?mid=a10411010100&bid=0019&act=view&list_no=1484711), 2021 희망복지지원단 업무안내(https://www.korea.kr/archive/expDocView.do?docId=39377). 메뉴 경로는 2021판 기준이며 2025년에 일부 명칭이 바뀌었을 수 있다(추정).

## 1. 단계별 기한

| 단계 | 기한 | 행복이음 |
|---|---|---|
| 초기상담 | 의뢰일로부터 5일 이내 | 상담 중엔 수기 기록 후 입력. 2025: 상담 ‣ 상담관리 ‣ 초기상담 등록 |
| 접수 | 의뢰 즉시 | 초기상담 내용 입력, 개인정보활용 동의서 첨부 |
| 욕구·위기도 조사 | 요청일로부터 10일 내외. 2021판: 욕구조사 실시 익일까지 입력 | 사례관리 ‣ 사례관리 업무지원 ‣ 욕구조사 / 위기도 조사 |
| 대상자 선정·유형분류 | 욕구조사 등록 후 5일 내외 | …업무지원 ‣ 대상자 선정 및 유형분류 |
| 서비스 제공계획 | 결정 후 15일 내외, 접수부터 30일 이내 | …업무지원 ‣ 서비스 제공계획 관리, 팀장 승인 |
| 서비스 점검 | 계획 수립 후 종결까지 | …업무지원 ‣ 서비스점검 관리(점검방법·이행상태·변경내용·변경사유, 1일 1회 등록) |
| 종결 | 사례회의 후 5일 이내 종결심사 등록 | 위기도 재조사 + 종결심사서 |
| 사후관리 | 종결 후 9개월 내 2회(첫 회는 3개월 이내). 서비스연계 가구는 연계 종료 후 3개월 이내 1회 | 상담 ‣ 안내상담 ‣ 상담등록 ‣ 모니터 상담관리 |
| 상시관리대상자 | 3개월 넘게 상담 없으면 미상담 알림 | 알림 항목: 상담일자·상담구분·상담유형 |

10일·5일·15일은 "통상 소요 기간, 상황에 따라 조정 가능"(2025). 연락두절 3개월 이상은 종결 검토 사유(2014 실천가이드).

일반 사례관리 상담 후 "○일 이내 입력" 규정은 **미확인**. 사례관리 가구의 정기 상담 주기도 **미확인**("주기적으로 점검"). 기관 내부 기준을 따른다.

## 2. 초기상담지(서식1) 항목

①상담번호(기관번호-YYYYMMDD-일련번호) ②상담일자 ③상담차수 ④상담자 ⑤상담경로 ⑥**상담유형: 지역사회기관 방문 / 가정방문 / 내방 / 전화** ⑦인적사항 ⑧가구유형 ⑨주거유형 ⑩가족사항 ⑪상담내용(원하는 도움 = 대상자 말 중심) ⑫주요문제(10개 영역, 면담자가 파악) ⑬상담결과 판정의견 ⑭상담자 종합의견

상담경로 예: 대상자 요청, 사례관리자 발굴, 기관 내 의뢰, 타 기관 의뢰, 통장·이웃, 129 이관, 복지사각지대 발굴, 위기아동, 기타.

판정의견: 공공서비스 가능 → 기초생활보장·긴급복지 등 유형 표기 / 민간 서비스 하나라도 있으면 서비스연계·사례관리 대상 / 단순 정보제공·거절은 서비스 제외.

## 3. 그 밖의 서식 항목

| 서식 | 핵심 항목 |
|---|---|
| 욕구조사표(3) | 신규/재조사 차수, 10대 영역·20개 세부항목별 현상·원인(최대 3)·원인제공자·우선순위(1~5), 강점·장애물, 사회적 지지자원, 가계도, 가족력·개인력, 요청 서비스, 종합의견 |
| 위기도 조사지(4) | 영역별 문항 0~3점(→ `02`) |
| 사례회의록(5) | 회의차수·일시·참석자·회의내용·회의결과. 사례별로 따로 |
| 서비스 제공계획 및 점검표(6) | 단기(3개월 이내)·장기(3~6개월 이상) 성과목표, 영역별 개입목표, 서비스명, 우선순위, 개입시기, 기간·횟수, 제공기관, 점검방법(내방·전화·방문·시스템), 이행여부, 변경내역·사유, 공동 서명 |
| 종결심사서(8) | 목표별 성과구분(5단계)·성과내역, 대상자 변화, 종결심사 의견·결과 |
| 모니터 상담지(9) | 방문일시·상담자, 세대정보, 욕구확인·주요문제, 주변관계, 상담내용 및 조치사항, 건강상태, 복지서비스, 주거환경 |

사례관리 상담일지 화면의 전체 필드와 "상담구분" 코드값은 **미확인**(원문에 캡처만 있음). 기관 화면을 보고 맞춘다.

## 4. 대상 구분

| 구분 | 정의 |
|---|---|
| 사례관리 가구 | 개입 1개월 이상 예상 또는 복합 서비스 |
| 서비스연계 가구 | 1개월 미만·단순 연계. 선정 후 5일 이내 연계, 사례회의·계획 생략 가능 |
| 미선정 가구 | 불필요, 연락두절·거부. 사유 서면 통보 |
| 사례유형(예시) | 일반(단순, 읍면동) / 집중(민간, 장기) / 위기(희망복지지원단, 복합 위기) |
| 고난도 사례 | 읍면동 → 시군구 희망복지지원단 의뢰. 예: 주요문제에 안전(학대·폭력·방임)과 정신건강이 함께 있을 때 |

행복이음으로 의뢰 가능: 드림스타트(12세 이하), 의료급여사례관리, 고난도 사례.
