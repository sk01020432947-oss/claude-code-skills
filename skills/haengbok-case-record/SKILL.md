# 행복이음 사례관리 기록

기준은 복지부 업무안내 원문이다. 기억으로 채우지 않는다. 확인 안 된 것은 "미확인"이라 쓴다.

## 작업 순서 (상담일지 작성·검토)

1. **위기 먼저**: 녹취·메모에 자살·자해·학대·폭력·방임·식사/의료 중단 표현이 있으면 `05_위기대응.md` 절차를 일지보다 먼저 안내한다.
2. **사실과 판단 분리**: "원하는 도움"은 대상자가 한 말 중심, "주요문제"는 사례관리자가 파악한 잠재 욕구로 쓴다.
3. **영역 매핑**: 10개 욕구영역 중 근거가 있는 영역만 고른다. 애매하면 `02` 분류 규칙을 따른다.
4. **위기도는 판단하지 않고 단서만**: 위기도 점수는 위기도 조사지(0~3점 문항, 영역별 배점)로 사람이 측정한다. AI는 영역별 위기 단서와 "위기도 재조사 필요" 여부만 제시한다.
5. **소견**: 근거(사실) → 해석 → 필요한 개입 순서. 추측은 "추정"으로 표시.
6. **향후계획**: 대상자 관점, 동사형·측정 가능한 목표. 단순 "연계"만 목표로 쓰지 않는다.
7. **다음 상담일**: 녹취에 약속된 날짜를 우선. 없으면 `01`의 기한 규칙(사후관리 등)과 기관 기준으로 제안하고 "제안"이라 표시한다.
8. **개인정보**: 상담내역은 행복이음상 민감정보. 회의자료에는 성명·주민번호·연락처를 쓰지 않는다. 여러 사례를 한 기록에 섞지 않는다.
