# 병렬 에이전트 프롬프트 (general-purpose, run_in_background)

`<폴더>`=정본 폴더 절대경로, `<제목>`·`<부제>`는 골격에서. 셋을 한 메시지로 띄운다.

## A. 논고
```
한국어로 전문 논고 한 편을 써서 파일로 저장하라.
먼저 읽을 것(반드시 전부): <폴더>/_공통골격.md (용어·테제·검증된 참고문헌 — 목록 밖 서지 금지), <폴더>/영상자막_*.txt
저장: <폴더>/논고_<제목>.md (Write 도구로 직접, 셸 글롭 금지)
- 제목: 「<제목> — <부제>」. 저자 김병곤(우리동네작은교회). 날짜 <오늘>.
- 본문 12,000~16,000자(공백 제외). '-다'체 학술 에세이, 본문 (저자, 연도) APA 인용 + 말미 참고문헌(APA 7). 영상은 (발화자, 연도, MM:SS)로 인용하고 참고문헌에도 넣는다.
- 구성: 초록·주제어 / 1 문제 제기 / 2~5 골격 테제를 층위별 장으로 / 6 실천 제언(층위별 4~5개, 구체적) / 7 한계와 과제 / 결론 / 참고문헌 / 부록(실무 양식 표 1장).
- 영상 속 재인용은 "1차 출처 미확인", 영상 속 수치는 "발화자의 경험적 추정". 확인 안 된 통계 금지.
- AI 상투구("~라고 할 수 있다", "결론적으로", 과도한 3항 나열, 이모지) 금지.
완료 후 저장 경로와 글자 수만 짧게 보고.
```

## B. 소책자
```
한국어 소책자(인쇄용 HTML 한 파일)를 만들어 저장하라.
먼저 읽을 것(반드시 전부): <폴더>/_공통골격.md, <폴더>/영상자막_*.txt
저장: <폴더>/소책자_<제목>.html
대상: <골격의 독자>. 발행: 우리동네작은교회 김병곤, <YYYY-MM>.
- 단일 HTML, 외부 의존은 Google Fonts(Noto Serif KR, Noto Sans KR)만. @page{size:A5;margin:14mm}, 장마다 page-break. 화면에서는 A5 종이 카드가 세로로, 모바일 폭에서 깨지지 않게. body 배경 명시.
- 24~32쪽: 표지 / 여는 글 / 차례(쪽 번호 실제와 일치) / 본문 장 6~8개(테제별, 성경 짝이 있으면 한 장씩) / 진단 워크시트 / 4주 소그룹(또는 팀) 나눔 가이드 / 부록(용어집, 더 읽을 책 6~8권은 골격 목록에서, 출처) / 뒤표지.
- 각 장: 쪽당 600~900자 + 인용 박스 + "생각해 볼 질문" 2~3개. 영상 인용은 타임스탬프.
- 미색 종이, 짙은 남색 본문, 포인트 1색. 장식·이모지 금지. 확인 안 된 통계 금지. '-습니다'체.
- 헤드리스 크롬으로 PDF를 뽑아 넘침 없는지 확인.
완료 후 저장 경로와 쪽수만 짧게 보고.
```

## C. 강의안
```
한국어 강의안(HTML 한 파일: 슬라이드 + 강사 노트 + 진행 계획)을 만들어 저장하라. 모션 스킬은 쓰지 않는다(정적 슬라이드). ← 사용자가 모션을 택했으면 이 줄 대신 awesome-ai-motion 순서를 따르라고 쓴다.
먼저 읽을 것(반드시 전부): <폴더>/_공통골격.md, <폴더>/영상자막_*.txt
저장: <폴더>/강의안_<제목>.html
강의: 「<제목> — <부제>」, 강사 김병곤 목사(우리동네작은교회, AI·미래시대 강사). 기본 120분(55+휴식10+55), 90분 축약안 병기. 대상: <대상>.
- 단일 HTML, Google Fonts(Noto Sans KR)만. 16:9 슬라이드를 ←/→/스페이스로 넘김, N 강사노트 토글, @media print로 슬라이드+노트 한 장씩. 맨 앞 '강의 계획서'(학습목표·진행표·준비물·조작법·표기 원칙). 바닐라 JS.
- 32~40장: 표지 / 오프닝 질문 / 1부 영상이 말한 것 / 2부 이론 연결 / 3부 성경(또는 사례) / 4부 현장 적용 / 워크숍 20분(진행 방법·질문·산출물) / 정리·실천 3가지 / 참고문헌.
- 슬라이드는 큰 제목 + 1~3줄 또는 HTML/CSS·SVG 도식. 노트는 슬라이드마다 3~6문장 + 예상 Q/A + 시간.
- 흰 바탕/짙은 남색, 포인트 1색(본문 대비 4.5:1 이상). 이모지 금지. 확인 안 된 통계 금지. 모바일 폭에서 축소.
완료 후 저장 경로와 슬라이드 수, 렌더 확인한 범위를 짧게 보고.
```
