# 드라마 모드 — 대사형 숏드라마(30~60초)

출처: 조팀장의 AI 공략집 「역대급 성능 클로드 페이블 5.2 출시! 클로드 시니어 쇼츠 자동화 가이드」(2026-11-18, x40wMZlka28).
본편(나레이션 해설)과 다른 점만 적는다. 견적 게이트·QA·금지 규칙은 본편 그대로 지킨다.

## 다른 점
| 단계 | 본편(해설) | 드라마 모드 |
|---|---|---|
| 0 주제 | 사용자가 준다 | **트렌드 조사**: 최근 30일 같은 장르 쇼츠를 모아(영상에선 211편) 잘된 공통 갈등 6개를 제시. "다시 뽑기"면 겹치지 않게 6개 더. 베끼지 말고 갈등 구조만 가져온다 |
| 1 장부 | 사실장부 A/B/C/X | **허구 표시 장부**: 실화가 아님을 밝힘, 실존 인물·상호·지명 없음, 혐오·조롱 대상 없음 |
| 2 기획 | 질문형 제목·장면표 | 줄거리 → 반전 포인트 → 등장인물 카드(외형 고정 토큰) → 대사 대본 → **AI로 만들기 어려운 장면 검수** |
| 3 견적 | 장면별 비용 | **화질 두 안**: 고화질(720p) / 절약(480p, 약 3배 저렴). 사용자가 크레딧 수를 말하면 그때 생성 |
| 4 음성 | 나레이터 1명 | 인물별 목소리, 립싱크가 되는 영상 모델 |
| 6 합성 | 나레이션+자막 | 상단 표시자막(제목 띠), 중간 참여 유도 문구, 끝 구독 스티커 — `~/Desktop/cysjavis/모션그래픽/드라마쇼츠_페이블5.2_조팀장/실습/쇼츠_마감.py` (`--test`로 자체 점검) |

## 사람이 하는 일 (영상 화자 기준 두 가지 + 이 스킬이 더한 하나)
1. 주제 고르기와 길이 지정("1번, 30초")
2. 크레딧 상한 정하기("113 크레딧")
3. 대본 검수 — 화자도 "대본을 보고 괜찮은지 보는 게 핵심"이라 했다. 생성 전에 고치면 크레딧이 안 샌다

## 출고 전 확인
- 유튜브 업로드 시 '변경되거나 합성된 콘텐츠'(AI 사용) 표시: 사실적인 장면이면 "예".
- 같은 틀·같은 음악·같은 그림체로 대량 생산하면 YPP '진정성 없는 콘텐츠'(2025-07-15 개정) 대상이 될 수 있다. 편마다 내 관점(해설 한 줄, 결말 질문)을 넣는다.
- 결과물 흠(문 어색함, 음성-자막 싱크 1~2곳)은 영상 화자도 인정했다. QA 리포트에 시각·싱크 항목을 둔다.
