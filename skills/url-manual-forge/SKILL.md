# url-manual-forge — URL 한 줄 → 매뉴얼·응용·나의 적용·스킬 판정·옵시디언·아티팩트

근거: 2026-10-04 작업 학습집 §3①·승인 2번, 공유 기억 `url-manual-pipeline-defaults`.
오너가 같은 긴 지시문을 하루 18회 넘게 반복하고, 결과를 받은 뒤 "아티팩트로 올려줘"를 따로 요청했다.
이 스킬은 그 기본 묶음을 한 번에 처리한다. URL만 받으면 아래 순서대로 끝까지 간다(중간에 "계속?"을 묻지 않는다).

## 0. 시작 전

- URL이 여러 개면 중복을 제거하고 개수를 알린다. 영상 2편 이상을 묶어 비교해야 하면 video-to-playbook으로 넘긴다.
- 이미 만든 매뉴얼이 있는지 먼저 본다: `~/Desktop/cysjavis/매뉴얼/`, `~/Desktop/cysjavis/AI동향_검토/`. 있으면 새로 만들지 말고 기존 정본을 고쳐 같은 아티팩트 URL로 재발행한다.
- 산출물에 발표자료·카드뉴스·쇼츠가 들어가면 `awesome-ai-motion` 사용 여부를 시작 전에 한 번만 묻는다(CLAUDE.md 규칙 8).

## 1. 원천 판별과 본문 확보 (근거 없으면 멈춘다)

| 원천 | 방법 |
|---|---|
| YouTube | `/watch` 또는 `yt-dlp --skip-download --write-subs --write-auto-subs --sub-langs "ko-orig,ko" --sub-format vtt`. 실제 자막을 확인한다. 자막이 없으면 로컬 `whisper-cli`. 둘 다 안 되면 설명란만으로 쓰지 말고 알린다. |
| GitHub | `gh repo view <owner/repo>`·README·주요 폴더 구조·최근 릴리스. 설치 명령은 읽기만 하고 실행하지 않는다. |
| X·웹 글 | defuddle 스킬로 본문 추출. 막히면 insane-search. |

노트마다 근거 수준을 적는다: `전체 자막 / 설명란만 / 부분 / README만`.

## 2. 산출물 다섯 묶음

1. **따라 하는 매뉴얼** — 준비물 → 단계별 따라 하기(명령·화면) → 자주 막히는 곳 → 원천 링크. 원천에 없는 단계는 "(추가)"로 표시한다.
2. **응용·확장 아이디어와 사례** — 일반 패턴 → 다른 분야 사례 → 추가 자료(검색으로 확인한 것만).
3. **나에게 적용하는 법과 사용 실례** — 사용자의 실제 자산(폴더·스킬·도구는 `ls`·`which`로 확인한 것만)에 대응. 항목마다 근거 / 내 자산 / 사용 실례 / 시작 / 주의. 직업·소속을 추정해 단정하지 않는다.
4. **스킬·설치 가치 판정표** — 매뉴얼마다 같은 표를 남겨 나란히 비교할 수 있게 한다.

   | 항목 | 내용 |
   |---|---|
   | 기존 자산과 중복 | 설치된 스킬 description 대조 결과(덮이면 설치하지 않는다, CLAUDE.md 규칙 7) |
   | 비용 | 무료 / 종량제 / 구독 |
   | 위험 | 외부 전송·권한·설치 스크립트 |
   | 결론 | 설치 / 보류 / 불필요 |

   새 스킬이 필요하면 초안만 `~/Desktop/cysjavis/매뉴얼/클로드_스킬/<이름>/SKILL.md`에 둔다(미설치). 설치는 skill-install, 기존 스킬 수정은 제안으로만.
5. **옵시디언 노트** — 아래 저장 규칙대로.

## 3. 저장 위치 (한 규칙)

| 산출물 | 위치 |
|---|---|
| HTML 정본(한글 이름) | `~/Desktop/cysjavis/매뉴얼/<주제>_매뉴얼.html` |
| 옵시디언 | `~/obsidian/AI 관련자료/<주제>/` — `00_허브`, `01_따라하기`, `02_응용사례`, `03_나의적용`, `04_스킬점검` |
| 아티팩트 | HTML 사본을 비공개로 바로 발행하고 링크를 준다. 재발행은 기록된 URL을 `url`로 넘긴다(새 URL 금지, CLAUDE.md 규칙 1). |

## 4. 끝낼 때

- 파일과 아티팩트를 클릭 가능한 링크로 제시한다(CLAUDE.md 규칙 2).
- 미확인 주장·설치하지 않은 것·사용자 결정 사항을 따로 적는다.
- 학습 효과 측정용으로 "이 URL 처리 중 사용자가 추가로 입력한 지시 수"를 한 줄 기록한다(기준값: 2026-10-04 세션당 평균 2~3건).
