# school-ministry-radar

데이터는 전부 `korean-school` MCP 도구로 조회한다. 이 스킬은 순서와 출력 형식만 정한다. 새 코드·키 없음.

## 0. 입력 확인
- 지역(시도·시군구), 대상 학교 목록(학생 명단의 학교명만 — 학생 이름·연락처는 받지도 저장하지도 않는다), 기간.
- 학교명이 모호하면 `find_school`로 확정한다. 2026 개편 지역명(예: 전남광주통합특별시)을 쓴다. `전남`으로 넣으면 `get_exam_calendar`가 학교를 못 찾는다(2026-10-04 실측).

## 1. 레시피

| 요청 | 호출 순서 | 산출 |
|---|---|---|
| 행사 일정 충돌 점검 | `get_exam_calendar(sido, names[])` → 필요 시 `get_school_schedule`(방학·체험학습) | 후보 날짜별 "시험 겹치는 학교 수" 표 + 추천 주간 |
| 시험 응원 | `get_exam_calendar` | 시험 시작 D-3 기도 제목·응원 문자 초안(학교별) |
| 학부모 상담 준비 | `get_parent_digest` → `get_evaluation_plan(학년, subject)` | 1쪽 브리핑: 학교 규모·수행평가 시기·상담 질문 3개 |
| 다음세대 지역 현황 | `get_school_report`(초·중·고 각각) | 학생수·학급당 인원 표, 학급당 10명 이하 작은 학교 목록, 사역 시사점 |
| 진로 코칭 | `get_admission_subjects` (+ `vision-school-major-info` 스킬) | 희망 학과 권장 이수과목 ↔ 현재 선택과목 대조 |

## 2. 규칙
- 수치는 조회 결과만 쓰고 조회일을 붙인다. 출처: 학교알리미 공시(공공누리 1유형)·NEIS 학사일정.
- 시험 미기재 학교는 "학교 확인 필요"로 표시하고 추정하지 않는다.
- 학교 비교 수치는 우열 평가로 쓰지 않는다(설교·광고 문구에 학교 순위 금지).
- 연간 일정표로 넘길 때는 `churchplan-ministry-calendar`의 events 형식에 맞춘다.
- 결과물 저장: `~/Desktop/cysjavis/교회학교/<한글이름>` (CLAUDE.md 규칙 4).
