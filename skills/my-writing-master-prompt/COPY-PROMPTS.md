# 복사용 프롬프트 모음 — 마스터 프롬프트 역설계

> 출처: 우석지니, 「AI가 나처럼 글을 쓰는 마스터 프롬프트 역설계」 (lilys.ai digest 10591962/12396598)
> 아래 블록을 그대로 복사해 어떤 AI(Claude, ChatGPT, Gemini 등)에든 붙여넣어 사용한다.
> Claude Code에서는 이 과정을 `my-writing-master-prompt` 스킬이 자동으로 수행한다.

---

## 준비물 (1단계)

대표 문장 유형 5종 × "AI 원본 ↔ 내 수정본" 쌍을 **유형별 최소 5개, 가능하면 10개** 준비한다.

1. 헤드라인 제목
2. 핵심 문구 (제목 아래 1~2줄)
3. 거버닝 메시지
4. 본문 소제목
5. 본문 내용 (서술형 / 개조식)

---

## 프롬프트 1. 비교 분석 & 규칙 도출 (2단계)

```
AI가 쓴 문장(원본)과 내가 수정한 문장을 쌍으로 업로드할게.
두 문장을 비교 분석해 줘. 분석 항목:

1. 순서 — 문장 구성 순서가 어떻게 바뀌었는지
2. 문장 구조 — 어떤 구조로 바뀌었는지
3. 어휘·종결형 — 어떤 어휘와 종결형을 사용하는지, 왜 바뀌었는지
4. 패턴 — 반복적으로 삭제되거나 추가되는 표현
5. 정보 배치 — 결론이 앞인지 뒤인지, 근거는 어디에 배치되는지

그 차이를 "재사용 가능한 규칙"으로 만들어 줘.
그다음 그 규칙으로 샘플 문장을 하나 써 봐.
```

샘플이 어긋나면 → 어긋난 부분을 알려주고 규칙 수정 → 다시 샘플 생성. 반복할수록 밀도가 올라간다.

---

## 프롬프트 2. 마스터 프롬프트 생성 (3단계)

```
위에서 도출한 문장 규칙들을 바탕으로 "마스터 프롬프트"를 작성해 줘.
추상적 규칙("간결하게", "논리적으로")은 전부 구체적 지침으로 바꿔야 한다. 예:
- 최상급 표현은 쓰지 마라
- 형용사·부사는 빼고, 핵심 정보는 수치와 결론을 반드시 넣어라
- 문장 앞에 결론을 배치해라
- 부연 설명은 괄호 또는 쉼표를 사용해라
- 개조식은 마침표 없이, 서술형 끝에는 마침표를 찍어라

마스터 프롬프트 구성:
1. 문장 구조 및 종결형 규칙
2. 절대 쓰지 않아야 하는 표현 목록
3. 제목 및 소제목 규칙
4. 거버닝 메시지 작성 규칙
5. 출력 전 자가 점검 체크리스트
6. 개인 보정 영역 (예: m-대시 → 대시·콜론·쉼표로 치환 등, 계속 추가)
```

## 프롬프트 3. 제안서 문장 규칙 (바로 붙여넣기용)

```
[제안서 문장 규칙 — 이 규칙대로 작성하라]

■ 제목
- 최상급·추상 수식어 전면 삭제
- 구성 = 핵심 수단 + 핵심 결과 수치
- 결과는 가능하면 정량 지표로 명시
예) "업무 처리 시간을 40% 단축하는 AI 기반 통합 플랫폼 구축"

■ 거버닝 메시지
- 구조: 현재 문제·상태 → 핵심 해결 방안 → 정량적 결과 (3단계)
- 현황·문제 제기 없는 자기주장형 선언으로 시작 금지
- 접속어 연쇄 금지 ("~하며, ~하고, ~함으로써" → 1개까지만)
- 모호한 수식어는 삭제하거나 구체적 단어로 치환

■ 소제목
- 짧고 강력하게 핵심만. 최상급·모호 표현 금지
예) "국제 표준 기반 11개 분산 시스템 통합"

■ 본문 서술형
- 구조: 현황 → 원인 → 메커니즘 → 영향 → 결과
- 접속구는 문장당 1개까지
- 관용구("종합적", "다양한", "여러 가지") 삭제
- "얼마나/어떻게"류 표현은 전부 수치로 변경

■ 본문 개조식
- 구조: 구체적 대상·주체 + 조치 + 결과(수치)
예) "발주처·수요기관·현업 3자 협의체 구성, 월 1회 정기 협의"
```

## 프롬프트 4. 보고서 문장 규칙 (바로 붙여넣기용)

```
[보고서 문장 규칙 — 이 규칙대로 작성하라]

■ 제목
- 최우선 정보를 앞에 배치
- 보고 대상·기간 + 핵심 결과·변화 수치 제시
- 의미 없는 수식어 삭제, 정량 지표 중심
예) "3분기 운영 현황 보고 — 처리 지연 32% 개선"

■ 거버닝 메시지
- 전기 현황 수치 1문장 + 핵심 조치 1문장 + 금기(今期) 결과 수치 1문장 = 총 2~3문장
- 숫자로 출발 (상사·임원은 숫자에 민감)
- Before → After 대비 포인트 제시
- 접속어 연쇄 금지, 모호한 수식어는 숫자로 대체

■ 소제목
- 구체적 조치 + 변경 사항 + 현재 상태, 명사형 종결
예) "승인 단계 축소: 3단계 → 2단계 전환 현황"

■ 본문 서술형
- 1문장 1메시지, 최대 2문장
- 접속어로 묶지 말고 쉼표·마침표로 분리
- 현황 서술 시 구체적 근거 1개 이상 포함
- 상황 보고: 현황 → 원인 → 메커니즘 → 영향 → 결과
- 문제 해결 보고: 문제 → 해결책 → 결과 → 효과
- 필요시 화살표(→) 등 특수문자 허용

■ 본문 개조식
- 구체적 조치 현황 + 수치 구조
예) "팀장 단계 병목 확인 → 승인 3→2단계 전환 → 처리 지연 32% 감소 → 인력 5명 중 2명 전담 배치"
```

## 프롬프트 5. 타사 AI 이식 절차 (편차 관리)

```
[마스터 프롬프트 이식 절차 — 타사 AI 사용 시]
1. 기존 마스터 프롬프트로 샘플 문장을 먼저 생성해 본다
2. 샘플을 보고 어긋나는 부분 기준으로 마스터 프롬프트를 수정한다
3. 수정된 버전을 실사용한다

※ 같은 회사 모델 간(예: Claude 계열)은 편차가 작아 그대로 사용 가능.
   타사 AI는 문체 기본값·습관이 달라 반드시 위 절차를 거친다.
```

---

## 핵심 전제

- AI는 사용자의 문장을 따라간다. "이건 틀렸다"고 판단해 스스로 고칠 수 있어야 역설계가 작동한다.
- 규칙 도출 → 샘플 생성 → 검증을 반복할수록 밀도가 올라간다.
