# kbg-문서양식(1) — A4 한 장 정리 시트

출처: 「한 장으로 읽는 가톨릭 성경 73권」 판매 페이지의 견본 이미지(창세기·로마서 쪽, 1000×1416px)를 픽셀 실측했다. 원본 문구는 쓰지 않았고 양식만 가져왔다.
[template.html](template.html)이 정본 틀이다(예시: 룻기). **구조와 클래스는 그대로 두고 내용만 바꾼다.**

## 0. 언제 쓰나

- 사용자가 문서 출력 형태를 따로 정하지 않았고, 결과물이 "한 주제를 한 장에 정리"하는 성격이면 이 양식을 기본으로 쓴다.
- 발표 화면은 `kbg-발표자료(1)`, 공문은 `hwpx`·`gongik-seosik` 쪽이다. 여기는 **인쇄·배포용 한 장 문서**다.
- 결과물은 `~/Desktop/cysjavis/<주제폴더>/<한글이름>.html`(정본)과 같은 이름의 `.pdf`로 만든다. 아티팩트로 올리면 그건 사본이다.

## 1. 양식 사양 (견본 실측)

### 쪽
A4 세로(210×297mm) 한 장. 종이색 `#FEFDF7`(웜 오프화이트). 여백 좌우 34px·위 30px. 블록 사이 9px. **한 장을 넘기지 않는다** — 넘치면 글을 줄인다(원본 로마서 쪽은 질문 박스가 바닥글을 덮는 결함이 있었다. 따라 하지 않는다).

### 색 — 테마색 하나 + 금색 하나
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--t` 테마 | 갈색 `#8A5829` · 남색 `#494EA1` · 보라 `#5E3F86` · 초록 `#2F7A55` · 슬레이트 `#46586B` | 머리띠, 요지 띠 왼쪽 선, 카드 라벨, 목록 점, 장절 표기, 구조 막대, 질문 박스 테두리·번호 |
| `--tint` | 테마 11% | 요지 띠 바탕 |
| `--line` | 테마 24% | 카드 테두리, 질문 사이 점선 |
| `--tag` | 테마 14% | "전통적 견해/학계 견해" 같은 작은 견해 태그 |
| `--gold` / `--goldbg` | `#C9A24C` / `#FAF4E3` | **강조 카드 하나만**(원본: 그리스도와의 연결). 테마와 상관없이 금색 |
| `--ink` / `--mut` | `#2A2622` / `#6B655D` | 본문 / 바닥글·보조 |

테마는 `<body data-theme="brown|indigo|violet|green|slate">` 하나로 바꾼다. 원본 규칙: 갈래(구약 오경·역사서 = 갈색, 신약 서간 = 남색, 전례 = 보라)마다 색이 다르고 한 갈래 안에서는 같다. 여러 장 묶음이면 갈래별로 테마를 나눈다.

### 글꼴
- 본문·제목: Pretendard Variable. 제목 33px/800, 번호 34px/800, 라벨 11.5px/700, 본문 12.3px/1.62.
- **한 줄 요지만 나눔명조** 17px/400 — 이 양식의 인상을 만드는 유일한 세리프.
- 한국어 줄바꿈은 `word-break:keep-all`.

### 블록 순서 (위→아래)
1. **머리띠** `.hd` — 테마색 둥근 띠(반경 14px). 왼쪽 큰 번호와 `n / N`, 세로 구분선, 작은 분류(“구약 · 역사서”) + 큰 제목, 오른쪽 반투명 알약 2개(분량·약어).
2. **한 줄 요지** `.gist` — 옅은 테마 바탕 + 왼쪽 5px 테마 선. 명조 한 문장.
3. **기본 정보 3칸** `.row.c3` — 짧은 사실(누가·언제·누구에게). 견해가 갈리면 `.tg` 태그를 앞에 붙인다.
4. **배경 | 요약 2칸** `.row.c2` — 오른쪽(요약)이 조금 넓다(1 : 1.13).
5. **구조 막대** — `.bar` 칸 너비 = `flex` 값(장 수·분량 비례). 4색 순환(진함·중간·옅음·짙음), 옅은 칸은 어두운 글씨. 아래 `.legend` 2열 범례(범위 굵은 테마색 + 설명).
6. **목록 3칸** `.row.c3` + `ul.dot` — 주제·인물·상징. 항목은 "낱말 — 한 줄 풀이" 꼴, 4~5개.
7. **인용 | 강조 2칸** — 왼쪽 `.ref`(장절 테마색 굵게) + 풀어 쓴 요지 3개, 오른쪽 `.card.gold` 강조 카드.
8. **질문·실행 박스** `.qs` — 테마 테두리, 번호 매긴 질문 3개, 사이 점선.
9. **바닥글** `.ft` — 왼쪽 출처·주의 문구, 오른쪽 시리즈명 · 쪽번호. 9px 회색.

### 다른 주제에 옮길 때 (칸 이름만 바꾼다)
| 칸 | 성경 한 장(원본) | 설교 요약 | 강의안 | 보고서 요약 |
|---|---|---|---|---|
| 번호·분류 | 08 / 구약·역사서 | 주차 / 시리즈명 | 차시 / 과목 | 문서번호 / 부서 |
| 알약 2개 | 분량 · 약어 | 본문 · 날짜 | 시간 · 대상 | 기간 · 상태 |
| 3칸 | 저자·시기·독자 | 본문·청중·상황 | 목표·준비물·평가 | 목적·범위·기간 |
| 2칸 | 배경·요약 | 본문 배경·대지 요약 | 개념 배경·핵심 요약 | 현황·결론 |
| 막대 | 장 구분 | 설교 흐름(서론~적용) | 시간 배분 | 일정 단계 |
| 목록 3칸 | 주제·인물·상징 | 대지 3개 | 핵심어·사례·오개념 | 성과·문제·위험 |

| 금색 카드 | 그리스도와의 연결 | 복음의 초점 | 한 문장 정리 | 결정 요청 |

칸이 필요 없으면 행을 통째로 빼고, 남는 자리는 비운다(채우려고 내용을 만들지 않는다). 수치는 출처 있는 값만, 없으면 "(예시)".

## 2. 절차

1. 원문을 다 읽는다. 원문에 없는 사실·수치는 쓰지 않는다. 성경 본문은 옮기지 않고 풀어 쓰며 장절 표기는 가톨릭식(`룻 1,16`).
2. [template.html](template.html)을 `~/Desktop/cysjavis/<주제>/<한글이름>.html`로 복사하고 테마를 고른다.
3. 칸을 채운다. 여러 장이면 `<section class="page">` 블록을 복사한다(쪽마다 번호·바닥글 쪽수 갱신).
4. PDF로 뽑고 **쪽 수를 확인**한다(장 수와 같아야 한다):
   ```bash
   "/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --virtual-time-budget=6000 --no-pdf-header-footer --print-to-pdf="<같은경로>.pdf" "file://<정본>.html"
   ```
   쪽 수 확인: `python3 -c "import re,sys;print(re.findall(rb'/Count \d+',open(sys.argv[1],'rb').read()))" <pdf>`
5. 스크린샷이나 PDF를 눈으로 보고 넘침·빈 카드·두 줄 넘는 제목이 없는지 본다.

## 3. 변형 B — 세로 스크롤 웹 문서 (같은 페이지의 본문 양식)

한 장이 아니라 긴 안내·소개 글을 웹으로 낼 때. 같은 색 계열로 맞춘다.
- 가운데 680px 단, 흰 바탕과 크림(`#FBF6EC`) 바탕 구역을 번갈아 둔다(구역 패딩 36px 16px).
- h1·h2는 나눔명조 800, h2는 가운데 정렬, 강조어는 금갈색(`#B8862E`) 글자색으로만.
- 구역 위 작은 알약 라벨(`#F3EBDC` 바탕, `#6B4A22` 글씨, 반경 20px).
- 부품: 번호 원(갈색 원 34px) 목록, 2열 정보 카드, 3열 상단 색띠 카드, 금색 번호 원 단계 카드, 왼쪽 금색 선 카드, 2열 표(첫 열 갈색 굵게), 접는 FAQ(`details`), 크림 안내 상자.
- 맨 위 짙은 갈색(`#2B2117`) 한 줄 띠. 판매용 초록 버튼·고정 하단 바는 판매 페이지가 아니면 뺀다.

## 4. 하지 말 것

- 테마색 두 개 섞기, 금색 카드 두 개 이상, 빨강·형광 강조.
- 한 장 넘김, 카드 안 글머리 6개 이상, 본문 11px 미만으로 줄여 우겨넣기.
- 명조를 요지 띠 밖에서 쓰기(변형 B의 제목은 예외).
- 원본 판매 페이지의 문구·이미지를 그대로 가져다 쓰기.
