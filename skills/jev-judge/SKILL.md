# jev-judge — "use Jev" 일괄 판정기

영상(잔재미코딩, 2026-09-29) 방식: Claude가 규칙으로 걸러낼 수 있는 건 코드로 하고, **텍스트 판단만 Jev에 하나씩** 묻는다. 결정·실행은 Claude/사람이 한다.

## 언제 쓰나
- 수백~수천 건을 **같은 질문**으로 빠짐없이 판정(노트 분류, 제목-본문 일치, 인용 지지 여부, 댓글 선별, SEO 점검).
- 결과가 틀려도 되돌릴 수 있는 일. 삭제·발송·결제·파일 이동 같은 비가역 결정은 **금지**(Jev는 확신하며 틀릴 수 있다). **판정은 경고·보조 표시로만** 쓴다.
- **클라우드 jev는 오너 별도 승인 시에만**(오너 결정 2026-10-16: 종량제 추가 지출 금지). `--yes` 실행 시 스크립트가 `cys feed push --wait` 로 오너 승인을 묻고 종료코드 0(허용)일 때만 호출한다 — 거부·시간 초과·feed 오류는 전부 호출하지 않는다. 승인이 없으면 로컬 Nimble·`laya-decide` 또는 Claude.

## 쓰지 않을 때
- **민감 자료는 클라우드 금지**(오너 결정 2026-10-16): 교인·개인정보·법률 사안·미공개 논문 원고·키·내부 기밀 → 외부 서버로 나간다. `laya-decide`·로컬 Nimble 또는 Claude 직접. 판별 기준은 `~/Desktop/cysjavis/JEV_조사/jev_사용지침.md` §4.
- 수 세기·계산·날짜 비교 → 코드로.
- 근거 글·수정안이 필요한 판단 → Claude.

## 절차
1. 질문 설계: 한 질문 = 한 조건. 분기는 choice, 정도는 score(2~10단계, 서술형 레벨), 예/아니오는 noul(높을수록 '예'가 되게).
2. `items.jsonl`(`{"id","state"}`)과 `questions.json`을 만든다.
3. **dry-run으로 비용 먼저 보여 주기**(호출 0회):
   ```bash
   python3 ~/.claude/skills/jev-judge/jev_batch.py --items items.jsonl --questions questions.json
   ```
4. `--yes --gate 0.8 --out out.jsonl` 로 실행하면 dry-run 수치를 담아 오너 feed 승인을 묻고, 허용(종료코드 0)일 때만 호출한다. 승인 없으면 종료코드 2로 끝난다.
5. `needs_review: true` 건만 Claude가 다시 판단하거나 사용자에게 보인다. 자동 처리 건은 표본 10건을 눈으로 확인.

단건: `--text "..." --questions '{...}' --yes` (같은 승인 절차)

## 고정 사항
- 키: `~/.config/typesafe/.env`(`TYPESAFE_API_KEY`). 대화창·명령줄에 키를 붙이지 않는다.
- SDK: `~/.cys/local/venv-typesafe`(typesafe-sdk 0.7.2 고정, 스크립트가 자동 전환). 디버그 로그는 끈다(state 원문이 로그에 남음).
- 비용: 입력 100만 토큰당 $0.042, 출력 무료. 2026-10-04 시험 1건 410토큰 $0.00002.

## 실측 근거(2026-10-02, `~/Desktop/cysjavis/JEV_조사/jev_종합판단_보고서.md`)
- 스킬 선택: jev 0.625 vs Haiku 0.521, 잘못된 스킬 로드 0.281 vs 0.417 → 선택 보조로 채택 검토.

- 숨은 지시 삽입 시 답 변경 10~15% → 외부 글(댓글·메일)을 판정할 때 결과로 행동을 자동 실행하지 않는다.
