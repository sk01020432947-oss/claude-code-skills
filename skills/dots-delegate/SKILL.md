# dots-delegate — 위임 브리프와 완료 판정

세 모드. 사용자 요청에서 모드를 고른다.

## 모드 A. 브리프 작성
사용자가 맡길 일을 말하면 아래 6항목을 채워 한 덩어리로 출력한다. 비어 있는 항목은 추측하지 말고 한 번에 모아서 묻는다.

```
[목표] 결과 한 문장
[맥락] 누구를 위한 일 / 참조할 기준 문서
[조건] 지켜야 할 것(예산·정책·기한·금지) / 건드리면 안 되는 것
[완료 증거] 끝났다고 인정할 증거(영수증·파일·스레드 링크·캘린더 항목)
[사람이 결정] 내가 직접 고를 단계(발송 직전, 결제 직전, 삭제 직전은 항상 포함)
[보고] 진행 보고 채널, "준비됨"과 "완료"를 구분해서 말할 것
[실패 시] 막히면(로그인·차단·권한) 추측 금지, 막힌 지점만 보고
```

규칙:
- 외부 발송·결제·삭제·개인정보 입력은 항상 [사람이 결정]에 넣는다.
- 로그인·인증이 필요한 연결은 사람이 하는 것으로 적는다.
- 자동 접속을 막는 사이트는 우회 지시를 쓰지 말고 공식 API·데이터 대안을 적는다.

## 모드 B. 결과 판정
에이전트의 보고문을 받으면 문장마다 단계를 표시한다.

| 표현 | 판정 |
|---|---|
| 찾았다/후보 | 선택 전 |
| 준비 중/확인 중 | 진행 중 |
| 초안 저장 | 발송 아님 |
| 발송함 | 스레드 링크 필요 |
| 예약 준비 | 확정 아님(영수증·확정번호 필요) |
| 완료 | 증거가 있을 때만 |

증거가 없는 "완료"는 "미확인"으로 돌려보내고, 에이전트에게 보낼 확인 질문 1~2개를 쓴다.

## 예시 — 회의 준비 위임 (출처: 단태랩스 Dots 영상 m8f5kcQZU_A)

```
[목표] 오늘 16:00 회의용 구글 슬라이드 덱(주제 N개 한 장씩 + 마지막 장 "오늘 정할 것")
[맥락] 자료: 드라이브 <폴더명>, 최근 메일, 캘린더 <일정명>. 고유명(기관·브랜드)은 먼저 알려 줌. 브랜드 가이드·로고 위치
[조건] 자료끼리 날짜·금액·담당이 어긋나면 고치지 말고 마지막 장에 [항목|자료A|자료B|정할 질문]으로 모은다. 개인정보·사례 실명 금지
[완료 증거] 덱 링크, 캘린더 설명에 안건+링크 반영 화면, 보낸 편지함 항목
[사람이 결정] 캘린더 설명 수정 직전, 참가자 메일 발송·공유 권한 추가 직전(수신자·본문·권한을 먼저 보여 줄 것)
[보고] 중간 1회 + 완료 시 슬랙/텔레그램으로 링크와 불일치 목록. "보냈다"와 "상대가 받았다"를 구분
[실패 시] 파일(로고 등)을 못 찾으면 임시본으로 표시하고 못 찾은 것만 보고
```

## 모드 C. 생활 에이전트 위임선
결제·예약·전화까지 하는 개인 에이전트를 쓰기 전에 한 번 만든다. 기준은 제품 공식 약관·처리방침을 읽고 적는다(원문이 없으면 "미확인"으로 표시).

1. **일거리를 세 칸으로 나눈다**: 그냥 해 / 물어봐 / 안 함. 칸마다 실제 일을 적는다.
2. **계정 3등급**: 1등급 연결 없는 공개 조회. 2등급 수습 가능한 개인 일상 계정. 3등급 금융·교회·연구·타인 정보 계정은 연결 금지.
3. **결제 문구**: 금액 상한을 쓰고 "승인 전에 카드로 보여 줘"를 넣는다. 일부 제품은 "얼마에 사라"는 말 자체를 동의로 처리한다(피클 도움말 확인 사례).
4. **전화**: AI임을 밝히는지, 기록이 어디 남는지 확인한다. 상대가 끊으면 재발신 금지. 돌봄·사과·조문 등 관계의 전화는 맡기지 않는다.
5. **타인 정보**: 연락처 대조·성도 정보·기도제목·건강 정보는 입력 금지. 필요하면 `pastor-ai-safety-guide`로 가명 처리한 뒤 내 도구에서 다룬다.
6. **약관 네 가지를 적는다**: 결과 책임 주체, 자동화 금지 사이트 확인 책임, 대리 계정 허용 여부와 연령, 운영자·모델 제공사의 열람 범위.
7. **거절 시험**: 안 함 항목을 가상 내용으로 시켜 멈추는지 본다. 지시문을 줬다고 지켜진다고 쓰지 않는다.
8. **판정과 출구**: 시간·개입 횟수·오류를 기록해 모드 B로 판정한다. 끊는 방법과 삭제 뒤 남는 기록도 함께 적는다.

출력: 위임선 표, 붙여 넣을 지시문, 확인 못 한 항목. 설치·로그인·결제·계정 연결은 사람이 한다. 법률 판단은 단정하지 않는다.

## 하지 않는 것
- 에이전트 대신 외부 서비스에 로그인하거나 결제하지 않는다.
- 조직 차원의 에이전트 도입 전략은 `agent-leadership`이 담당한다.
