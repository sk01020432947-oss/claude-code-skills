# video-to-playbook — 영상 묶음 → 설명서·응용·점검·학습지시문

2026-10-09 설치. 근거 작업: 2026-10-09 클로드 코워크 영상 4편, 2026-10-02 JEV 분석, 2026-10-04 원소스 멀티채널, 2026-10-04 AI 네이티브 영상 6편, 2026-10-06 메타 뮤즈 영상 5편, 2026-10-09 베비투스 채널 29편. `repeat-to-skill` 스캔에서 같은 요청이 60일간 12개 세션에 나왔다. 순서가 매번 같아서 절차만 고정한다. 집필·시각화·적재는 **기존 스킬에 위임**하고 새 에이전트를 만들지 않는다.

## 0. 시작 전

- 입력 URL에서 **중복을 먼저 제거**하고 편수를 사용자에게 알린다.
- 이미 분석한 영상이 있으면(`~/Desktop/cysjavis/AI동향_검토/`를 `ls`) **재분석하지 않고 기존 결론을 인용**한다.
- 발표자료·카드뉴스·쇼츠가 산출물에 들어가면 `awesome-ai-motion` 사용 여부를 한 번만 묻는다.

## 1. 자막 확보 (대본 없으면 멈춘다)

채널·재생목록 전체면 youtube-wiki-ingest의 스크립트를 먼저 쓴다(쇼츠는 `/shorts` 탭을 따로 나열):

```bash
Y=~/.claude/skills/youtube-wiki-ingest/scripts/yt_wiki.py
python3 $Y list "<채널>/videos" --out raw --min-duration 0
python3 $Y fetch --out raw --lang ko --window 60 -- <video_id>   # ID가 '-'로 시작해도 안전
```

1. `yt-dlp --skip-download --write-subs --write-auto-subs --sub-langs "ko-orig,ko" --sub-format vtt` 로 한국어 자막을 받는다. `/watch`의 기본 자막은 영어 번역본일 수 있어 한국어를 직접 지정한다.
2. VTT를 텍스트로 합친다(태그 제거, 연속 중복 줄 제거).
3. 자막이 없고 `/watch` Whisper 키도 없으면 `whisper-cli`(로컬)로 받아 적는다. 둘 다 안 되면 설명란만으로 쓰지 말고 사용자에게 알린다.
4. 근거 수준을 노트마다 적는다: `전체 자막 / 설명란만 / 부분`.

## 2. 영상별 노트 (병렬)

영상 1편당 서브에이전트 1개. 형식 고정: 한 줄 요약 / 화자·맥락 / 흐름 / 핵심 주장 / 구체 사례·수치·도구 / 인상적인 발언(의역) / 한계·주의 / 재사용 패턴. 자막 오인식은 문맥으로 보정하고 불확실하면 "(추정)".

## 3. 교차 분석

- 공통 원리 × 영상 매트릭스, 영상끼리 부딪히는 곳, 용어표.
- **수치 검증표**: 영상이 인용한 통계마다 확인 / 미확인 / 화자 체감으로 분류한다. 검색으로 확인한 것만 "확인". 원문 수치와 다르면 둘 다 적는다.

## 4. 응용·확장, 내게 쓰는 법

- 일반 패턴 → 다른 분야 사례 → **사용자의 실제 자산**(폴더·스킬·도구는 `ls`·`which`로 확인한 것만)에 대응.
- 항목마다: 영상 근거 / 내 자산 / 사용 실례 / 시작 / 주의. "이번 주 시작 3가지"는 비용·위험 낮은 순.
- 사용자의 직업·소속을 추정해서 단정하지 않는다. 확인된 자산 범위로만 쓴다.

## 5. 스킬·설치 점검

- **중복 판정이 먼저**: 설치된 스킬 description을 대조해 덮이는지 표로 낸다. 덮이면 설치하지 않는다.
- 외부 도구는 `which`로 현재 상태를 확인하고, 설치 스크립트는 **실행하지 않고** 사용자 결정으로 남긴다.
- 새 스킬은 초안만 `~/Desktop/cysjavis/매뉴얼/클로드_스킬/<이름>/SKILL.md`에 저장(미설치). 기존 스킬 수정은 제안으로만.

## 6. 산출물과 저장

| 산출물 | 위치 |
|---|---|
| HTML 정본(한글 이름) | `~/Desktop/cysjavis/AI동향_검토/<주제>_종합설명서.html` |
| 자비스 학습지시문 | `~/Desktop/cysjavis/AI동향_검토/자비스_학습지시문_<주제>.md` |
| 옵시디언 | `~/obsidian/AI 관련자료/<주제>/` — `00_허브`, `01_종합정리`, `02_응용_아이디어_사례`, `03_스킬_점검`, `04_자비스_학습지시문`, `영상노트/V*.md` |
| 아티팩트 | HTML 사본. **재발행은 기록된 URL을 `url`로 넘긴다** |

## 7. 자비스 학습지시문 규칙

- 영상은 전부 "주장". 후보 주장(C1…)마다 영상 밖 독립 출처 2개 이상.
- 평가 기준은 검색 **전에** 동결. 채점은 생산자와 분리.
- 통과분만 provisional 저장. soul·directive 변경은 승인 요청으로만.
- 기존 규칙과 중복이면 저장하지 않고 출처만 추가한다. 영상 수치는 그대로 저장하지 않는다.
- 금지: CSO·리뷰어 좌석 대체, 비가역 판단 위임, 외부 설치 스크립트 실행 제안.

## 8. 끝낼 때

파일 목록을 클릭 가능한 링크로 제시하고, 미확인·미설치·사용자 결정 사항을 따로 적는다.
