# 로마서 전체 구조 지도

출처: 《묵상을 위한 로마서 주해》 상세 목차(책 25-31p) + 이진섭 〈로마서의 흐름과 메시지〉.
구조 원리: 서신 전체를 수사학적 6부로 나누고, '이론'부 내부를 옛 인류/새 인류의 대칭으로, 각 논증 블록을 **디아트리베 3단 [논지 → Q&A → 정리]** 패턴으로 재귀적으로 분해한다.

## 대칭(교차) 구조 요약

```
1:1-7 (머리말) ←———————————————→ 16:1-27 (맺음말)
    1:8-17 (도입) ←———————————→ 15:14-33 (정리)
        1:18-11:36 (이론) ←——→ 12:1-15:13 (실제)
            1:18-3:20 (옛 인류) ↔ 3:21-11:36 (새 인류)
                3:21-8:39 (새 사람) — 3:21-4:25 (칭의) / 5:1-8:39 (성화)
                9:1-11:36 (새 이스라엘)
```

- 머리말↔맺음말: '복음'이 1:1-4와 16:25에 압축 등장, '믿음의 순종'(1:5; 16:26)이 이 두 곳에만 반복, 선지자·모든 민족 표현 반복 — 수미쌍관.
- 도입↔정리: 둘 다 방문 계획·복음 전하려는 의도·성도 칭찬을 담되 15장이 더 구체적(과거·현재·미래 사역까지).
- 이론↔실제: 이론이 복음의 논리적 설명이라면 실제는 "그것이 현실 속에서 나타나는 것"(복음에 합당한 삶).

## 상세 구조 트리

```
I   머리말 1:1-7
      A. 1-5절  발신자와 하나님의 아들의 복음에 대한 정의
      B. 6-7b절 수신자
      C. 7c절   인사말
II  도입 1:8-17  로마에 가서 복음을 전하고 싶음과 그 이유
      A. 1:8-15 바울의 감사기도와 로마 방문계획
           1. 감사와 기도 1:8-13 (감사 1:8 / 기도 1:9-10 / 방문 목적 1:11-13)
           2. 로마 방문 계획 1:14-15
      B. 1:16-17 복음 전하기를 원하는 이유
           1. 소극: 복음을 부끄러워하지 않음 1:16 (복음의 능력)
           2. 적극: 복음은 구원의 능력 1:17 (하나님의 의)
III 이론 1:18-11:36
      A. 옛 인류 1:18-3:20  — 행위 보응의 원리(2:6-11), 율법→죄, 심판 선언
           1. 주장 1:18-2:16
                1) 하나님의 진노가 나타남과 그 이유 1:18-23
                     (1) 진노는 불의한 사람들에게 1:18
                     (2) 이유: 보여주셨지만 섬기지 않음 1:19-23 ('왜냐하면' 반복)
                2) 진노의 방식: 유기와 최종심판 1:24-2:16
                     (1) 진노 1 — 유기 1:24-32
                          - 특별한 모습 1:26-27 / 일반적 모습 1:28-31
                          - 사람들의 반응: 자기들이 옳다고 함 1:32
                     (2) 진노 2 — 최종심판 2:1-16
                          - 핑계하지 못함 2:1-5
                          - 심판의 준거: 행위 보응의 원리 2:6-11
                          - 율법과 양심 2:12-16
           2. Q&A 2:17-3:8
                1) 유대인이 바른가? 율법을 지키는가?(못 지킨다) 2:17-29
                2) 그렇다면 유대인의 유익이 없는가? — 있다 3:1-2
                3) 책임이 하나님께 있지 않은가? 3:3-8
           3. 정리 3:9-20  모든 사람은 죄 아래(3:9) → 성경의 증언(3:10-18) → 심판(3:19-20)
      B. 새 인류 3:21-11:36
           1. 새 사람 3:21-8:39
                1) 칭의 3:21-4:25
                     (1) 주장 3:21-26  믿음의 원리·믿음의 법의 선언(3:27)
                     (2) Q&A 3:27-4:15  세 가지 질문 (짧은 답 = 긴 설명 대응)
                          ① 3:27-28 = 4:1-8   자랑할 수 있는가?
                          ② 3:29-30 = 4:9-12  이방인도 포함되나?
                          ③ 3:31   = 4:13-15  율법은 파기되는가?
                     (3) 정리 4:16-25  "믿음의 법으로 되는 것이다"(4:16a διὰ τοῦτο + ἐκ πίστεως)
                2) 성화 5:1-8:39  칭의의 모습[성격]
                     (1) 논지: 5장  칭의의 효과와 기능
                          ① 5:1-11  화평·소망·화목
                          ② 5:12-21 그리스도로 인한 생명
                               (아담: 사망 5:12-14 / 그리스도: 생명 5:15-17
                                / 결론 5:18-19 / 부가 논제: 율법·죄와 은혜 5:20-21)
                     (2) Q&A: 6-7장  (5:20-21의 엇갈린 예고를 풀이)
                          ① 6장 죄와 은혜: 죄를 지어도 되는가? (6:1-14 / 6:15-23)
                          ② 7장 율법: 율법의 참 기능은? (7:1-6 새 법으로 이동 / 7:7-25 율법은 죄의 원인이 아님)
                     (3) 정리: 8장  믿음의 법의 기능과 효과
                          ① 8:1-11  그리스도의 영으로 말미암은 생명 — 5:12-21과 연결
                          ② 8:12-39 하나님과 살아있는 관계 — 5:1-11과 연결
                               (고난과 영광 8:18-30 / 확신 선언 8:31-39)
           2. 새 이스라엘 9:1-11:36
                1) 도입: 이스라엘 민족으로 근심 9:1-5
                2) Q&A 9:6-11:32
                     (1) 논리적 문제: 약속과 선택으로 나는 참 이스라엘 9:6-29
                     (2) 역사적 현실: 민족의 실패 9:30-10:21 / 남은 자와 회복 11:1-32
                3) 정리: 하나님의 구원 방법 찬양 11:33-36
IV  실제 12:1-15:13  — 새 인류의 삶
      A. 새 백성의 마땅한 삶: 영적 예배 12:1-2
      B. 구체적 모습 12:3-15:13
           1. 원리 제시 12:3-21
                1) 공동체 측면: 지체의 원리 12:3-8 (공동체가 개별보다 먼저!)
                2) 개별 측면: 사랑의 원리 12:9-21
                     (교회 내적 12:10-13 / 교회 외적: 핍박자에게 사랑으로 12:14-21)
           2. 구체적 권면 13:1-15:13
                1) 로마 사회에서 사는 문제 13:1-14
                     (권세에 굴복 13:1-7 / 이웃 사랑 = 율법의 완성 13:8-10 / 빛의 갑옷 13:11-14)
                2) 교회 안의 문제(음식): 믿음이 연약한 자를 받으라 14:1-15:13
                     (비판 말고 받으라 14:1-23 / 그리스도 모델 15:1-13)
V   정리 15:14-33
      A. 편지 목적: 복음 설명 15:14-16
      B. 사역 소개: 과거 동반구 15:16-19 / 미래 서바나·로마 15:20-24 / 현재 예루살렘 구제헌금 15:25-29 / 기도 부탁 15:30-32
      C. 축복 기도 15:33
VI  맺음말 16:1-27
      A. 문안과 권고 16:1-23 (뵈뵈 추천 16:1-2 / 26명 인사 / 거짓 교사 경계 16:17-20 / 동역자 인사 16:21-23)
      B. 송영 16:25-27 (1:1-7과 수미쌍관 — "복음이 교회를 견고하게 세운다"로 수렴)
```

## 산출 시 구조 표기 규칙

- 단락 표제는 `로마서 01:18-32 옛 인류_하나님의 진노1_유기` 형식: 장:절 + 구조상 위치 + 주제어.
- 해당 본문이 속한 디아트리베 블록의 3단 개요를 산출물 앞부분에 상자로 재게시한다 (예: 〈1:18-3:20 디아트리베 논지〉 논제 제시(1:18-2:16) → 질문·답변(2:17-3:8) → 정리(3:9-20)).
- Q&A 단락은 "3:27-28 = 4:1-8"처럼 짧은 답과 긴 설명의 등호 대응을 명시한다.
