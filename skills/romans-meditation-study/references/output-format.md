# 산출 형식 — 이중 트랙 템플릿

이 책의 형식적 정체성: **묵상 트랙(블록 A)과 학술 트랙(블록 B)의 병렬**. A가 경어체 설교문이라면 B는 평서체 연구 노트다. 독자는 A로 묵상하고 B로 근거를 확인한다. 학술 장치(원어·문법·번역 비평)는 본문 흐름에 섞지 않고 B와 각주로 '분리 수납'한다.

## 블록 A — 묵상 트랙 (경어체 '합니다'체)

순서 고정:

```markdown
# 로마서 05:12-21 새 인류_그리스도로 말미암는 생명
(형식: 장:절 + 구조상 위치 + 주제어. 부제를 붙일 수 있음 — 예: "껍데기는 가라")

[개관: 단락 전체를 2-4문장으로]

# 한 줄 묵상
[단락의 메시지를 한 문장으로 압축한 굵은 문장]

# 문맥과 구조
[이 단락이 전체 논증 어디에 위치하는지 — structure-map.md의 해당 디아트리베
3단 개요를 상자로 재게시. "○○은 ○○와 대비되는 이야기입니다" 형식]

## 12-14절  [절 범위 + 명제 문장 형식의 소제목]
[1층: 본문 내용의 석의적 요약 — 절 번호 병기]
*
[2층: 신학적 확장 — 원어(음역 병기)·수사법·전후 참조 연결]
*
[3층: 오늘의 적용 — 1인칭 전환, 성찰 질문으로 착지.
"지금 나는 ~하고 있습니까?" 형식 필수]

## 15-17절  [다음 소단락, 동일 3층 구조 반복]
...

# 기도
[주해에서 쓴 어휘를 그대로 재사용한 행갈이 운문 기도.
주해의 결론을 명제가 아니라 기도 언어로 내면화하는 장치]
```

작성 규칙:
- 소제목은 반드시 **명제 문장**: "18-23절 불의로 진리를 막는 사람들에게는 하나님의 진노가 나타납니다" (절 범위만 쓰지 않는다).
- 원어는 본문 안에 음역으로: "에크 피스테오스(믿음의 법)", "히라스테리온". 수사법 용어(제유법·환유법)는 각주로 정의.
- 적용은 한국교회 현실을 향해 구체적으로("싸구려 복음", "교회만 다니면 뭐하냐는 비난은 스스로 자초한 것") — 단 정죄가 아니라 자기 성찰로.
- 사용자가 목회 현장 정보를 제공했으면(교회명·회중 상황) 적용을 그 상황으로 구체화한다.

## 블록 B — 학술 트랙 (평서체, 고딕체 상당)

```markdown
---
**로마서 5:12-21 : 아담과 그리스도**
[2-3문장 단락 요약]

**성경 이해**
[단락의 논리 흐름을 절 번호를 촘촘히 달아 산문으로 추적.
"먼저는 ~라는 사실입니다(19-20절). 그 다음은 ~(24-27절). 첫째, ~. 둘째, ~" 형식]

**☞ Tip**
- 5:12 '이러므로'로 번역된 헬라어 '디아 투토'는 ~ [원어 어휘·접속사 기능]
- 5:13 [번역 비평 — "NRSV는 'for'로 옮겼다" 식의 역본 비교]
- 5:14 [역사 배경·유대 문헌·사본 문제]
```

Tip 작성 규칙: 절 단위 기술 노트로, ①원어 어휘의 용례(다른 등장 구절 병기) ②접속사·소사의 기능 판정 ③번역 대안 제시 ④역사·문화 배경 ⑤구조 관찰(병치·카이아즘) 중 해당되는 것을 3-7개.

## 적용 도출 원리 9가지 (12-16장 및 설교 준비 시 전부 검토)

1. **정체성 → 합당성**: 모든 적용은 "새 인류가 되었으니 → 그 정체성에 합당하게"의 직설법→명령법 구조로. 행위 요구가 먼저가 아니라 은혜(하나님의 자비)가 근거.
2. **소극/적극 양면 제시**: "이 세대를 본받지 말라"(소극) ↔ "마음을 새롭게 함으로 변화를 받으라"(적극)의 이항 구조.
3. **삼중 예배 균형**: 공동체 예배(공예배)·개인 예배(묵상)·삶의 예배(실천) — 하나라도 빠지면 각각 개인주의 신앙 / 이중적 그리스도인 / 외식 신앙이 된다.
4. **성령 의존**: 적용은 자기 노력이 아니라 "하나님께서 그리스도로 말미암아 성령을 통해서 하시는" 것. 마음의 할례(겔 36장)와 연결.
5. **분별의 복합성**: 하나님의 뜻("선하시고 기뻐하시고 온전하신")은 복합적 차원 — 시대·환경 따라 다각도로 살핀다.
6. **당대 상황 → 오늘 병렬**: 로마의 상황(팍스 로마나 = 폭력에 의한 가짜 평화)을 먼저 재구성하고 오늘의 유비로 건너온다. 인물 예증(원수 사랑의 최대 수혜자 = 바울 자신) 활용.
7. **점검 질문으로 착지**: "지금 함께 울어주어야 할 사람이 있습니까?" — 독자에게 직접 묻는 실존적 질문.
8. **기도로 내면화**: 적용의 최종 형태는 기도문이다.
9. **외부 묵상 자료**: 필요 시 고전 묵상서(헨리 드러몬드 등) 발췌로 확장 — 출처 명시.

## 공동체 우선 원리

12:3-8에서 바울이 **공동체적 측면(지체의 원리)을 개별적 측면(사랑의 원리)보다 먼저** 다룬 것을 따른다. 적용 도출 시 개인 경건으로 환원하지 말고 공동체 차원을 먼저 검토한다.
