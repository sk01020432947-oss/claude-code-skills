# 교회 댓글·문의 답글

영상 「역대급 클로드 실전 사용법 2027」(그린코끼리, 15:00~17:20)의 '리뷰 답글' 스킬을 교회용으로 옮긴 것이다.
프로젝트 지침은 "무엇을 아는가", 스킬은 "어떻게 일하는가" — 이 방법은 교회 홍보·새가족·일반 대화 어디서나 같이 쓴다.

## 지키는 세 줄 (영상 2단계의 '조건 세 줄')
1. 댓글에 나온 불만·질문은 하나도 빠짐없이 짚는다.
2. 댓글에 없는 사실(지연 이유, 담당자, 내부 사정)은 지어내지 않는다. 모르는 것은 `(확인 필요)`로 남긴다. "담당 부서에 전달하겠습니다"처럼 담당 부서·팀·봉사자가 있다고 전제하는 문장도 쓰지 않는다 — "말씀 잘 들었습니다" 정도로 받고, 전달 대상은 `넣을지 물어볼 것`에 둔다.
3. 보상·개선 약속·일정 확약은 넣지 않는다. 넣을 만하면 끝에 "넣을까요?"라고 묻는다.

## 분위기에 따라 말투를 바꾼다
- 불만·낮은 별점: 먼저 사과, 변명 없이, 짧게. 연락처나 직접 대화 경로를 한 번 안내.
- 질문(예배 시간·주차·새가족): 정보 → 환영 한 줄. 정보는 자료에 있는 것만.
- 감사·은혜 나눔: 감사 + 짧은 축복 한 줄. 설교 내용을 새로 지어 붙이지 않는다.
- 공격·논쟁성 댓글: 논쟁하지 않는 짧은 답 1개와 "답하지 않음" 권고를 같이 낸다.

## 결과 모양
- 버전 A(짧게 2문장) / B(보통 3~4문장) / C(따뜻하게 4~5문장)
- 맨 아래: `확인 필요:` 목록, `넣을지 물어볼 것:` 목록
- 존댓말. 이모지·과한 감탄사 없음. 교인 개인정보(이름·연락처·건강)는 쓰지 않는다.

## 하지 않는 것
- 답글을 직접 게시하거나 메시지를 보내지 않는다. 초안만 만든다.
