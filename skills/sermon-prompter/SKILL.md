# 설교 프롬프터 HTML 출력기

완성된 설교 원고를 받아, 강단에서 자연스럽게 낭독할 수 있도록 **일정한 속도로 위로 자동 스크롤되는
텔레프롬프터 HTML 파일**을 생성한다. 별도 앱·서버 없이 브라우저에서 바로 열린다.
`final-sermon-html` 스킬과 형제 관계로, 본문 구조화 방식은 동일하되 **자동 스크롤(프롬프터) 기능**이 핵심이다.

## 탑재 기능 (고정 사양)

| 항목 | 사양 |
|------|------|
| **자동 스크롤** | `▶ 스크롤` 버튼 — 일정한 속도로 화면이 위로 올라간다. 다시 누르면 정지 |
| **스크롤 속도** | 옵션 버튼 **느림 / 보통 / 빠름** + 미세 조정 `＋` / `−`, 화면에 현재 속도 표시(px/초) |
| 처음으로 | `⤒ 처음` 버튼 — 맨 위로 이동 |
| 단락 이동 | 키보드 `←` / `→` 로 H1 단락 사이 이동 |
| 글꼴 선택 | **리디바탕** / **애플고딕**(우상단), 기본 리디바탕 |
| 글자 크기 | 우상단 `가−` / `가＋`, 20~48px, 기본 30px |
| 배경 | **밝게 / 어둡게**(우상단) — 어둡게는 검은 배경·흰 글씨 프롬프터 모드 |
| 읽기 가이드선 | 화면 40% 지점 안내선 표시/숨김 토글 |
| TTS 음성 | **성우 선택 드롭다운** — 설치된 음성 중 아래 화이트리스트만 노출, 직접 선택 가능 |
| 제시 성우 | **민수(고품질) · 소라(고품질) · 수현(고품질) · 유나(프리미엄) · 지안(프리미엄)** + 영어 **Shamanda**. 기본값은 목록 첫 음성(민수). 허용 음성이 하나도 없으면 설치된 전체 음성으로 대체 |
| TTS 속도 | **1.0× / 1.25× / 1.5×** |
| TTS 읽기 | **H1 단락별** `▶ 읽기` 버튼 + 상단 `▶ 전체 읽기` |
| 단축키 | `Space` 스크롤 시작/정지 · `↑`/`↓` 속도 · `Home` 처음 · `←`/`→` 단락 이동 |

이 사양은 임의로 바꾸지 않는다.

## 워크플로우

### 1단계 — 설교 원고 확보 (반드시 먼저 요청)

이 스킬은 원고를 **렌더링**할 뿐 새로 쓰거나 고치지 않는다.
원고가 첨부·제시되지 않았다면 먼저 이렇게 요청한다.

> "프롬프터로 만들 설교 원고를 붙여넣어 주시거나 파일로 올려 주세요.
>  제목·본문(성경 구절)·서론·대지·결론이 구분된 완성 원고면 됩니다."

원고를 받은 뒤에만 다음 단계로 진행한다.

### 2단계 — 원고를 구조 JSON으로 변환

원고를 읽고 아래 스키마로 정리해 `sermon.json`(작업 폴더)에 저장한다.
**원문 문장은 절대 고치지 않는다.** 단락 분할과 마크업 표시만 한다.

```json
{
  "title": "설교 제목",
  "subtitle": "주일설교 · 2026.06.07 · ○○○ 목사",
  "scripture_ref": "마태복음 5:1-12 (개역개정)",
  "scripture_text": "본문 봉독 텍스트(있을 때만)",
  "sections": [
    { "heading": "서론",        "text": "단락 본문…" },
    { "heading": "1. 첫째 대지", "text": "…" },
    { "heading": "결론",        "text": "…" }
  ]
}
```

**단락(`sections`) 분할 규칙 — 각 항목이 H1 = 하나의 단위가 된다(단락 이동·TTS 읽기 단위).**
- 설교 제목 → `title`, 날짜·예배명·설교자 → `subtitle`
- 본문 성경 구절 → `scripture_ref`. 봉독 본문 전체가 원고에 있으면 `scripture_text`
- **서론 / 각 대지 / 결론**을 각각 하나의 section으로 나눈다
- 원포인트 설교는 의미 전환을 기준으로 3~5단락으로 나눈다

**`text` 필드 작성 규칙 (간이 마크다운):**
- 빈 줄로 문단을 구분한다
- 원고에 표시된 강조는 `**굵게**` 로 (이탤릭은 쓰지 않는다)
- 「」『』 따옴표는 그대로 둔다
- 인용·낭독 인용구는 줄 앞에 `>` 를 붙인다 → 인용 박스
- 설교자 메모·동작 지시는 줄 앞에 `//` 를 붙인다 → TTS 낭독에서 자동 제외
- 이미 완성된 HTML을 직접 넣어야 하면 `text` 대신 `html` 필드를 사용한다

**본문 레이아웃(자동 적용):** 빌드 스크립트가 본문 문단을 **문장 단위 + 쉼표(,) 단위로 줄바꿈**하고,
**문단과 문단 사이에 한 줄(빈 줄)을 삽입**한다. 짧은 줄은 자동 스크롤·낭독에 자연스러운 호흡을 만든다.
1차로 종결부호(`. ! ? 。 …`) 뒤, 2차로 쉼표 뒤에서 끊으며, 따옴표·괄호 안의 쉼표와 숫자 안 쉼표(1,000)는 끊지 않는다.
인용(`>`)은 성경 구절도 **문장마다 줄을 바꾸되**(쉼표는 끊지 않음) 작성자가 나눈 행은 유지한다. 메모(`//`)는 작성자가 나눈 줄을 그대로 보존한다.

설교자의 문체·어휘·표현은 원고 그대로 보존한다. 스킬은 내용을 평가·수정하지 않으며, 단락 분할과 마크업 표시만 한다.

### 3단계 — HTML 생성

```bash
python scripts/build_prompter_html.py \
  --input sermon.json \
  --out "설교프롬프터_[제목].html"
```

- 스크립트가 자동 스크롤·속도 조절·글꼴·크기·배경·유나 TTS가 포함된 완성 HTML을 만든다.
- 저장 위치는 원고가 있던 폴더(또는 해당 주일 설교 폴더)를 기본으로 하되, 명확하지 않으면 한 번 확인한다.

### 4단계 — 결과 안내

```
✅ 생성 완료: 설교프롬프터_[제목].html
   • 자동 스크롤: ▶ 스크롤 (Space) · 속도 느림/보통/빠름 + ＋/−
   • 글꼴 리디바탕/애플고딕 · 크기 가−/가＋ · 배경 밝게/어둡게 (우상단)
   • 가이드선 토글 · 낭독: 성우 선택(민수·소라·수현·유나·지안·Shamanda) 1.0×/1.25×/1.5× · 단락별/전체 읽기
   • 단축키: Space 시작·정지 / ↑↓ 속도 / Home 처음 / ←→ 단락 이동

💡 브라우저(전체화면 권장)에서 열어 사용하세요. 강단 화면·태블릿에 적합합니다.
```

## 참고 사항

- **속도 보정**: 처음에는 `보통`(36px/초)으로 시작해, 실제 낭독 호흡에 맞춰 `↑`/`↓` 또는 `＋`/`−`로 미세 조정한다.
  글자 크기를 키우면 같은 속도라도 더 천천히 읽는 느낌이 된다.
- **자동 스크롤과 TTS는 별개**다. 자동 스크롤 중에는 TTS가 화면을 강제 이동시키지 않는다.
- **어둡게(프롬프터 모드)**: 강단 조명 아래에서는 어두운 배경이 눈부심을 줄여 읽기 편하다.
- **성우 선택**: 상단 `음성` 드롭다운에서 설치된 성우 중 화이트리스트(민수·소라·수현·유나·지안·Shamanda)만 골라 쓴다.
  목록에 안 보이면 해당 음성이 OS에 설치돼 있지 않은 것이다(macOS: 설정 → 손쉬운 사용 → 읽어주기 → 음성 관리에서 고품질/프리미엄 한국어 음성 설치).
  영어 Shamanda로 한국어 원고를 읽으면 발음이 부자연스러우니 한국어 성우 사용을 권한다.
- 허용 성우 목록을 바꾸려면 `assets/template.html`의 `ALLOWED` 배열을 수정한다.
- 리디바탕은 로컬 설치본 우선, 없으면 웹폰트(인터넷 필요). 애플고딕·한국어 음성은 macOS에서 즉시 동작한다.
- 템플릿 파일: `assets/template.html` — 디자인·기능을 손볼 때 여기를 수정한다.
- 자동 스크롤 없이 정적 낭독·TTS 뷰어만 필요하면 자매 스킬 `final-sermon-html`을 사용한다.
