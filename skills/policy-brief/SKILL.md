# policy-brief

주제 → 통계 → 법령 → 검증 → 문서. 수치와 조문은 반드시 도구 응답에서 가져오고, 기억으로 채우지 않는다.

## 0. 입력 확정

사용자 요청에서 아래를 뽑는다. 없으면 기본값을 쓰고 묻지 않는다.

| 항목 | 기본값 |
|---|---|
| 주제 | (필수) 예: 노인 돌봄, 저출산, 장애인 고용 |
| 지역 | 전국 |
| 기간 | 10년 |
| 출력 | 마크다운 + HWPX |
| 용도 | 보고서(`개조식`). "교재·원고용"이면 마크다운만 |

HWPX 프리셋이 정부(`업무보고`)형인지 지자체(`서울방침`)형인지 요청에 드러나지 않으면 `개조식`을 쓴다.

## 1. 통계 (korean-stats)

주제를 정책영역에 대응시킨다.

| 주제 예 | `chain_policy_indicator` domain |
|---|---|
| 저출산·출생·보육 | lowFertility |
| 고령화·노인·돌봄·연금 | aging |
| 주거·전세·주택 | housing |
| 고용·청년 일자리·실업 | jobs |
| 범죄·안전·교통사고 | safety |
| 의료·보건·의사 수 | health |
| 성장·물가·소득 | economy |

- 대응되면 `chain_policy_indicator`(domain, region, yearCount) 한 번.
- 대응 안 되면(장애, 빈곤, 기초생활, 1인가구 등) `quick_trend`(keyword)로 핵심 지표 2~3개. 키워드 미지원이면 `search_statistics` → `get_statistics_data`.
- 지역이 있으면 `quick_rank`로 전국 대비 위치 1줄 추가.
- 쓰는 지표마다 `explain_statistic`으로 출처 문구를 받는다. 본문 출처는 "통계청, 「장래인구추계」" 식의 기관·자료명으로 쓴다(kordoc이 통계표 ID를 자동 삭제한다).

## 2. 법적 근거 (korean-law)

1. `search_law`로 주제의 근거 법률 1~3개(법률 → 시행령 순).
2. `get_law_text`로 목적 조항과 핵심 조문(대상·급여·책임 주체)을 `jo`로 지정해 가져온다. 전문을 가져오지 않는다.
3. 금액·기준표가 필요하면 `get_annexes`.
4. 지역이 지정되면 `search_law`로 해당 지자체 조례를 찾고, 여유가 있으면 `ordinance_radar`로 상위법 반영 여부를 본다.

## 3. 초안 작성

아래 뼈대로 마크다운을 쓴다. 해석과 제언은 수치·조문에서 직접 나오는 것만 적고, 근거 없는 전망은 쓰지 않는다.

```markdown
# {주제} 정책 브리프
> {주제}의 최근 {N}년 현황과 법적 근거를 정리하여 정책 방향 검토에 활용하고자 함

## 현황
### 핵심 지표 추이
| 지표 | {시작연도} | {최근연도} | 증감 |
- 해석 2~3줄
※ 출처: 기관, 「자료명」

## 법적 근거
### 근거 법령
- 「법률명」 제N조(조문 제목): 요지
### 자치법규 (지역 지정 시)

## 쟁점과 시사점
### 쟁점
### 검토 방향
```

## 4. 검증 (생략 금지)

- 초안 전문을 `legal_analysis`(mode=`verify_citations`, text=초안)로 검증한다. 실존하지 않거나 조문 번호가 틀린 인용은 고치거나 지운다.
- 표의 수치를 1단계 도구 응답과 한 번 더 대조한다. 추계치는 "(추계)"를 붙인다.
- 검증 결과를 사용자에게 한 줄로 보고한다: 인용 N건 중 N건 확인, 수정 N건.

## 5. 출력

- 마크다운: 사용자가 경로를 주지 않으면 `~/Desktop/cysjavis/policy-brief/{YYYY-MM-DD}-{주제}.md`.
- HWPX 전에 `npx -y kordoc lint --munche {md}`로 문체 검수. 개조식은 상위 항목을 30자 안팎 명사형으로 끊고, 근거·수치·조문 요지는 `  - ` 하위 항목으로 내린다. "~되어, ~함" 식 대구 문장을 피한다. 경고 0건일 때 생성한다.
- HWPX: kordoc `generate_document`(markdown, output_path=같은 이름 `.hwpx`, preset, date). 결재란·기관명은 사용자가 준 경우에만 넣는다.
- 파일은 클릭 가능한 마크다운 링크로 제시한다.

## 알려진 함정 (2026-09-29 첫 실행에서 확인)

- `get_law_text`는 `mst`로 부르면 법제처 500이 자주 난다. `lawId`로 부르고, 500이면 몇 초 쉬었다 재시도한다.
- 돌봄·장기요양은 `chain_policy_indicator`(aging)에 인구 지표만 나온다. 이용·재정은 `search_statistics`("장기요양 급여실적") → 국민건강보험공단 `DT_35006_N034`(수급자·급여비용·공단부담금, 급여종류별), `DT_35006_N021`(기관 수)을 쓴다.
- 분류 차원이 5개 이상인 표는 `get_statistics_data`가 objL4까지만 받아 "objL 누락" 오류가 난다. 차원이 적은 표로 바꾼다.
- MCP를 세션 중간에 추가했다면 도구가 로드되지 않는다. 원격 서버에 JSON-RPC `tools/call`을 직접 보내 같은 결과를 받을 수 있다.
- `verify_citations`는 법령명 없이 "제4조제4항"만 쓰면 확인필요로 뜬다. 조문마다 「법령명」을 붙인다.

- 공문서 표기 검수는 "저출산"을 "저출생"으로 바꾸라고 하고, 줄표(—)도 경고한다. 본문은 "저출생"으로 쓰되 옛 법령명 「저출산ㆍ고령사회기본법」은 고유명사라 그대로 둔다. 현행 제명은 「인구전략기본법」(lawId 009933)이다.
- 시군 단위 노인시설 분석: 장기요양기관·정원은 `DT_35006_N021`, 인력(요양보호사 등)은 `DT_35006_N022`, 등급·급여별 수급자는 `DT_35006_N030`(objL1=시군구 코드, `get_table_info` filter로 찾기). 입소현원·종사자는 시도 자체 통계(전남 orgId 215 `DT_215008_007~009`)에 있고 periodType이 `F`(3년 주기)라 `Y`로 부르면 "데이터 없음"이 뜬다. 경로당·노인복지관 시군별 수는 KOSIS에 없다. 대신 (1) public-data-lens `search_datasets`("{시군} 경로당")로 공공데이터포털 파일을 찾아 `https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId={FILE_id}&fileDetailSn=1`로 받거나(CSV는 cp949), (2) 시군 누리집의 "어르신 관련시설" 페이지(노인복지과 현황표, 첨부 xlsx)가 가장 최신이다. 시군 페이지의 대표자·시설장 성명은 보고서에 옮기지 않는다. 2026년부터 전남·광주는 "전남광주통합특별시"로 표기된다.
- 시군 통계는 스크립트 한 번으로 다 받는다: `python3 ~/.claude/skills/policy-brief/scripts/sigun_elderly.py {시군명} {공단코드} {전남코드} {인구코드}`.
- 시군 코드 예: 공단 표 순천 `15350AC400M103`·광양 `M105`·여수 `M102`, 전남 215 표 순천 `A04`·광양 `A06`·여수 `A03`, 인구 표 순천 `46150`·광양 `46230`·여수 `46130`. 여수시 누리집은 경로당을 읍면동별 하위 페이지(`/www/sphere/welfare/senior/silver_hall/*_center`, 돌산읍은 상위 페이지)로만 보여 줘 모아서 센다. 시군 누리집의 고령인구 비율은 국가통계포털 값과 다를 수 있으니 둘 다 적는다. 누리집 현황 페이지 이름은 시군마다 다르다(순천 "어르신 관련시설 및 단체", 광양 "노인복지관련 현황"은 읍면동별 노인인구·독거노인까지 있음). 웹검색으로 "{시군}청 노인복지시설 현황 경로당"을 먼저 찾는다.
- 긴 원고는 MCP 대신 CLI가 편하다: `npx -y kordoc generate {md} -o {hwpx} --preset 개조식 --date "YYYY. M. D."`.
- 인구동향 최근 연도는 잠정치다. 표 머리에 "(잠정)"을 붙인다.

## 주의

- 원격 korean-stats에는 질의 문장이 전송된다. 개인 식별 정보를 질의에 넣지 않는다.
- 도구가 실패하거나 데이터가 없으면 그 지표는 "자료 없음"으로 적고 숫자를 지어내지 않는다.
- 법률 자문이 아니다. 문서 끝에 "※ 본 자료는 {날짜} 기준 공개 자료를 정리한 것임"을 넣는다.
