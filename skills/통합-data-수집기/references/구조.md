# 구조 — 어디에 무엇이 있나

`assets/` 의 2026-11-14 스냅숏 기준이다. 줄 번호는 정본이 바뀌면 어긋나므로 **함수 이름·구획 제목으로 찾는다**(`grep -n "def from_disks" 통합정리.py`).

## 목차
1. 도구 폴더의 파일
2. `통합정리.py` 의 자리
3. 맨 위 설정 (새 사람·새 컴퓨터에 맞출 것)
4. 자료 모양
5. 화면 ↔ 파이썬이 주고받는 파일
6. 화면 코드(`PAGE`)의 자리
7. 자동 수집

## 1. 도구 폴더의 파일

| 파일 | 종류 | 역할 |
|---|---|---|
| `통합정리.py` | 코드 | 전부(모으기·합치기·화면 만들기·자동 수집·점검). 표준 라이브러리만 |
| `통합수집기.js` → `통합수집기-북마클릿.txt` | 코드 | 여러 SNS 용 북마클릿 원본과 한 줄로 줄인 것 |
| `수집기.js` → `수집기-북마클릿.txt` | 코드 | 처음 만든 쓰레드 전용 북마클릿(6개 규칙의 원전) |
| `수집기_점검.html` | 코드 | 가짜 SNS 화면으로 북마클릿의 `read()` 를 점검 |
| `parse_manual.py`, `make_review_page.py` | 코드 | 1단계 길: 한 계정 글을 파싱해 검토용 HTML 로 |
| `CLAUDE.md` | 문서 | 사용법·규칙의 정본(이 스킬의 `기능명세.md` 가 그 사본) |
| `통합자료.jsonl` | **자료** | 글 한 줄에 한 건. 남의 글이 들어 있다 |
| `KBG-통합자료수집기.html` | **자료** | 보기 화면(자료가 통째로 들어 있다) |
| `메모태그.json` | **자료** | 메모·태그·별표·지운 표시. 손으로 고치지 않는다 |

| `연결출처.json` | 상태 | 기억해 둔 블로그·유튜브 주소와 연결한 디스크 폴더 |
| `자동수집_상태.json` | 상태 | 지난번에 본 파일들의 크기·시각 |
| `tonghap_build.js` | 상태 | 판 번호와 시각 한 줄(화면이 15초마다 읽는다) |
| `아티팩트_목록.csv` | 상태 | 훅이 발행 때마다 한 줄 더하는 장부 |
| `raw/`, `메모백업/`, `보관/` | 보관 | 가져온 원본·합친 메모 파일·지운 글과 옛 판 |

**자료** 표시가 붙은 것은 스킬·저장소·아티팩트·메일 어디에도 넣지 않는다.

## 2. `통합정리.py` 의 자리

| 구획(파일 안 제목) | 함수 | 하는 일 |
|---|---|---|
| (머리) | `load` `norm_date` `code_date` `rec` | 곁도구 불러오기, 날짜를 한 모양으로, 글 한 건 만들기 |
| 1. 북마클릿 파일 | `from_collector` | 다운로드 폴더의 `sns_*posts*.json` → `raw/` 로 옮기고 읽는다 |
| 2. 유튜브 | `vtt_text` `from_youtube` | `yt-dlp` 로 제목·설명·(자막) |
| 3. 블로그 | `fetch` `strip_html` `parse_feed` `from_blog` | RSS·Atom. 네이버 전문은 `NAVER_PY` |
| 4. 카카오톡 | `kakao_files` `from_kakao` | '대화 내보내기' 파일만(`KAKAO_PY` 사용) |
| 5. 기존 JSON | `from_import` | 이미 모아 둔 JSON·JSONL |
| 5-1. Claude 아티팩트 | `from_artifacts` | 발행 장부 CSV 두 개. id = 아티팩트 주소 |
| 6. 옵시디언 inbox | `front` `from_inbox` | 머리말(front matter)을 읽어 주소로 종류를 가린다(`HOSTS`) |
| 7. 브라우저 북마크 | `bookmark_files` `from_bookmarks` | 크롬 계열 + 사파리. 폴더 경로가 글쓴이 칸 |
| 8. 폰 자료 | `from_phone_files` `from_phone` `photo_previews` `pic` 외 | `폰자료/` 폴더 길 · 맥 앱 자료 길(읽기 전용) · 사진 미리보기 |
| 9. 연결한 디스크 | `_dirs` `disk_name` `disk_files` `from_disks` `volumes` | `/Volumes` 아래 폴더의 파일 이름·종류·크기·날짜 |
| 합치기·저장·화면 | `merge` `take_added` `merge_notes` `load_notes` `purge` | 중복 제거, 직접 추가분 받기, 메모 합치기, 지운 글 빼기 |
| 〃 | `topic` `origin` `shelf` | 화면용 주제·출처·저장소 줄 매기기 |
| 〃 | `note_md` `write_new` `to_obsidian` `put_away` | 옵시디언 새 노트, 다 쓴 내려받기 파일 치우기 |
| 〃 | `stamp` `agent` | 자동 수집(7절) |
| 〃 | `PAGE` | 보기 화면 전체(HTML+CSS+JS, 약 800줄) |
| 〃 | `save` `main` `selfcheck` | 파일 쓰기, 옵션 처리, 스스로 점검 |

`main()` 의 흐름: 잠금(`.lock`) → 옵션에 따라 `--auto` 면 `stamp()` 비교 → jsonl 읽어 `store` → 신호 파일·연결출처 처리 → 고른 수집 함수들 `merge` → `load_notes` → `to_obsidian` → `purge` → `save` → 요약 출력(저장소별 건수) → `--open`.

## 3. 맨 위 설정 (새 사람·새 컴퓨터에 맞출 것)

| 이름 | 지금 값의 뜻 | 바꿀 때 |
|---|---|---|
| `VIEW` | 보기 화면 파일 이름 | 새 사람 이름으로 |
| `DL` | 다운로드 폴더 | 브라우저가 다른 곳에 내려받으면 |
| `AGENT` | LaunchAgent 등록 파일(이름이 곧 Label) | 한 컴퓨터에 수집기가 둘이면 이름이 달라야 한다 |
| `ARTIFACTS` | 아티팩트 장부 CSV 두 개 | 안 쓰면 빈 목록 |
| `KAKAO_PY` | 카톡 내보내기 파서 | `assets/곁도구/` 의 것을 이 자리에 |
| `NAVER_PY` | 네이버 글 전문 읽기(별도 스킬) | 없으면 `--full` 만 안 된다 |
| `INBOX_DIRS` | 읽어 올 옵시디언 폴더 | 옵시디언이 없으면 `[]` |
| `VAULT_INBOX` `VAULT_AUTHOR` | 새 노트를 둘 대기실과 머리말의 author | 그 사람 볼트 규칙에 맞게. 볼트 규칙이 "에이전트가 써도 되는 곳"으로 정한 폴더여야 한다 |
| `HOSTS` | 주소 → 종류 | 새 사이트를 가리려면 한 줄 |
| `LABEL` | 종류 → 화면 이름(화면에서는 `NAME`) | 출처를 더할 때 한 줄 |
| `BM_SHELVES` | 북마크 중 따로 셀 폴더 | 그 사람의 북마크 폴더 이름 |
| `TOPICS` | 주제 낱말 규칙(위에서부터 먼저 맞는 것) | 그 사람의 관심 분야로 통째 교체. 낱말 맞추기라 틀린다 — 틀린 글은 태그로 바로잡는다 |
| `PHONE_DIR` `PICS` | `폰자료/`, `사진미리보기/` | 보통 그대로 |
| `VOLS` `DISK_KIND` `DISK_MAX` `DISK_SKIP` | 디스크 자리·받는 확장자·상한·건너뛸 폴더 | 윈도우·리눅스면 `VOLS` 와 `volumes()` |
| 화면의 `PP` | 한 쪽 카드 수(20) | 사용자가 원하면 |

## 4. 자료 모양

```
글 한 건      {"platform": "threads", "id": "…", "author": "…", "url": "…", "date": "2026-11-14T09:00:00", "title": "…", "text": "…"}
화면용 덧칸   k = 주제, o = 출처, s = 저장소 줄, i = 그림 주소(있을 때만)      ← jsonl 에는 없다
메모 한 건    "platform|id": {"m": 메모, "g": [태그…], "s": 별표, "t": 고친 시각(ms), "x": 지운 표시}
연결출처.json  {"blog": [주소…], "youtube": [주소…], "t": 마지막으로 다시 본 시각, "disk": [폴더…]}
```

- 날짜는 `norm_date` 로 한 모양으로 맞춘다. 없으면 빈 문자열(정렬에서 맨 뒤, 기간 필터에서 빠진다).
- `platform` 은 접두로 묶인다: `phone_*`, `threads*`. 디스크는 platform 이 `disk` 하나고 저장소 줄만 `disk_<디스크/폴더>` 로 갈린다(`shelf()`).

## 5. 화면 ↔ 파이썬이 주고받는 파일 (전부 다운로드 폴더)

| 파일 이름 | 누가 만드나 | 내용 | 파이썬이 하는 일 |
|---|---|---|---|
| `sns_*posts*.json` | 북마클릿 [저장] | 수집한 글 | `raw/` 로 옮기고 합친다 |
| `tonghap_memo_*.json` | 「메모 파일로 저장」 | 메모 전부 + `"+추가"` 칸 | `메모태그.json` 에 합치고 `메모백업/` 으로 |
| `tonghap_wiki_*.json` | 「옵시디언 위키로 보내기」 | 고른 글 열쇠 + 그 메모 | 새 노트를 만들고 치운다 |
| `tonghap_now_*.json` | 「⟳ 지금 업데이트」·연결 창 | 빈 것, 또는 `{"disk": 폴더}` / `{"undisk": 폴더}` | 한 번 정리하고 지운다. 경로는 `/Volumes` 아래만 받는다 |
| `tonghap_build.js` (도구 폴더) | 파이썬 `save()` | `onBuild("판번호", 시각)` | 화면이 15초마다 읽어 판이 바뀌면 새로 고침 |

판 번호는 `PAGE + 자료 + 메모 + …` 의 해시 앞 12자다 — 내용이 같으면 번호도 같아서 화면이 괜히 새로 고쳐지지 않는다.

## 6. 화면 코드(`PAGE`)의 자리

최상위 이름(새 이름을 넣기 전에 여기와 겹치는지 grep 한다):

`D NAME NEXT nm $ el btn img press ls only F FK GRP inG inF notes key note pend keepPend tt ask say undo setNote store commit put tagsOf dl down step copy hl PER sb ss pal setTheme ab sel ba be short apply rename bulk bar ICON shut side card tile closeModal nextPic detail addForm found pg pager COLS cell esc info mine FMT exportForm draw fit qt count linkForm wantAt`

| 이름 | 하는 일 |
|---|---|
| `D`, `N0`, `PP`, `NAME`, `DISKS` | 파이썬이 채워 넣는 자료·메모·쪽 크기·이름표·디스크 목록 |
| `$` `el` `btn` `img` | DOM 도우미. `el(tag, class, text)` 가 `textContent` 로만 넣는다 |
| `F`, `GRP`, `inG`, `inF` | 지금 걸린 필터, 저장소 묶음 규칙 |
| `notes` `key` `note` `setNote` `store` `commit` | 메모 읽기·쓰기(localStorage), 여러 건을 한 번에 저장 |
| `undo` `step` | 되돌리기 ↔ 다시 하기 |
| `ask` `say` | 화면 안 물음 창(`<dialog>`), 토스트 |
| `dl` `down` | 파일 내려받기(`down('tonghap_now_', obj)` 가 신호 파일) |
| `side` | 왼쪽 칸(저장소·주제·일시·출처·태그, 묶음 펴고 접기) |
| `card` `tile` `detail` | 카드, 사진 칸, 펼침 창(‹ › 는 `nextPic`) |
| `found` `pg` `pager` `draw` | 조건에 맞는 글 전부, 지금 쪽, 쪽 번호, 다시 그리기 |
| `bulk` `rename` `bar` | 여러 장에 태그 달기·떼기, 태그 이름 바꾸기, 선택 줄 |
| `addForm` `exportForm` `linkForm` | 자료 추가, 내보내기·공유, 디스크 연결 창 |
| `PER` | 기간 단추(전체·3일·1주일·1달·3개월) |
| `wantAt` | 「지금 업데이트」를 누른 시각 — 그 뒤의 새 판은 곧바로 새로 고친다 |

## 7. 자동 수집

- `--auto-on` 이 `~/Library/LaunchAgents/<AGENT>.plist` 를 쓴다: `WatchPaths`(다운로드 폴더 · inbox 폴더들 · 북마크 파일들 · 아티팩트 장부 · `폰자료/` · `폰자료/통화녹음/` · `/Volumes`) + `StartInterval` 600초 + `ThrottleInterval` 20초. 폴더 감시는 바로 아래 변화만 알려 준다 — 깊은 곳은 10분 주기가 잡는다.
- 불려 나온 `--auto` 는 `stamp()`(지켜보는 파일들의 `[경로, 크기, 시각]`)가 `자동수집_상태.json` 과 같으면 **아무것도 하지 않는다.** 다르면 `--all` 처럼 정리하고 건수만 알림으로 띄운다.
- 파일이 너무 많은 폴더(`폰자료/`)는 낱낱이 적지 않고 전체 크기·가장 최근 시각만 본다.
- 연결해 둔 블로그·유튜브는 6시간에 한 번만 다시 본다(인터넷이 끊기면 건너뛰고 나머지는 정리한다).
- 기록은 `~/Library/Logs/tonghap-auto.log`. 화면 상단에 「⟳ 자동 수집 켜짐/꺼짐」(`__AUTO__`).
- LaunchAgent 의 `PATH` 에 `/opt/homebrew/bin` 을 넣어 두었다 — 없으면 `yt-dlp` 를 못 찾는다.
