## 이 폴더 규칙

- 나는 **비개발자**다 — "폴더 열어서 실행하세요"가 아니라 **여기서 대신 실행하고 결과 숫자만 보고**해준다.
- 수집 파이프라인 3단(수집 북마클릿 → `parse_manual.py` → `make_review_page.py`)은 **계정명만 바꾸면 다른 계정에 그대로 재사용**된다. 새 계정을 분석할 때 맨땅에서 만들지 말 것.
- 계정이 여러 개가 되면 **어느 계정인지 먼저 확인**한다.
- `수집기.js`를 고치면 **북마클릿(`수집기-북마클릿.txt`)도 반드시 같이 재압축**한다 (`npx terser`). 둘이 따로 놀면 안 된다.
- 수집량이 얼마든 **모인 만큼만 정리하고, 부족한 부분은 "자료 부족"으로 명시**한다. 억지로 채우지 않는다.

## 통합 수집 (쓰레드 · X · 인스타 · 페이스북 · 유튜브 · 블로그 · 카톡 · 인박스 · 북마크)

이 컴퓨터는 맥이다. 위 명령의 `python` 은 `python3` 로 바꿔 실행한다.

사용자가 "통합 정리해" 라고 하면 아래를 실행하고 요약의 건수를 그대로 알려준다.

- 쓰레드 저장글: 사용자가 `threads.com/saved` 화면에서 통합 북마크를 누르면 `threads_saved` 로 모인다(남의 글도 거르지 않는다).
- 페이스북 공유글: 사용자가 자기 페이스북 프로필 화면에서 통합 북마크를 누르면, "공유하기"로 올린 글은 `facebook_shared`(화면 이름 "페이스북 공유글")로 따로 모인다 — 글쓴이는 원래 글쓴이, 본문은 덧붙인 말 + 원래 글. 공유가 아닌 글은 예전처럼 `facebook` 으로 담긴다. 공유 여부는 화면 구조로 짐작하며 가짜 화면(`수집기_점검.html`)으로만 점검했다 — 실제 화면에서 공유글이 0개로 나오면 `통합수집기.js` 의 facebook `read()` 를 그 화면에 맞춰 고친다.
