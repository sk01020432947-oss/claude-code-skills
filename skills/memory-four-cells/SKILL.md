# memory-four-cells — 피드백을 네 칸 기억으로

2026-10-30 설치. 근거: 커리어해커 알렉스 영상(youtube 1mZ8dNoWLhI, 4:58~6:54)과 설명란 실습 프롬프트 4~6.
CLAUDE.md는 교훈·선호만 담고, 결정과 상태가 흩어져 있어서 만든다.

## 저장소

`~/Desktop/cysjavis/기억장치/` 의 네 파일. 한 줄 = 한 항목, 최신이 위.

| 파일 | 담는 것 | 형식 |
|---|---|---|
| 교훈.md | 다시 하지 말 것 | `- YYYY-MM-DD · <한 문장> · 근거: "<원문 인용>" · 주제: <폴더/프로젝트>` |
| 상태.md | 지금 어디까지 | 같은 형식. 같은 주제의 옛 상태 줄은 지우지 말고 맨 앞에 `~~취소선~~` |
| 결정.md | 정한 것과 이유 | `- YYYY-MM-DD · <결정> · 이유: <…> · 근거: "<…>" · 주제: <…>` |
| 선호.md | 다음엔 이렇게 | 교훈과 같은 형식 |

한글 파일명이라 읽기·쓰기는 python3로 한다(CLAUDE.md 규칙 6).

## 기록

1. 입력(피드백·메모·회의록)을 문장 단위로 읽고 각 문장을 0~2칸에 넣는다.
2. 원문에 없는 규칙은 만들지 않는다. 애매하면 항목 끝에 `(확인 필요)`.
3. 날짜가 없으면 `날짜 없음`. 개인정보(교인·학생 이름, 연락처)는 빼고 기록.
4. 넣기 전에 같은 내용이 이미 있으면 새 줄을 쓰지 않고 기존 줄에 근거만 덧붙인다.
5. 끝나면 칸별로 추가 건수와 추가한 줄을 보여 준다.
6. 같은 교훈·선호가 두 번째 들어오면 CLAUDE.md 승격을 **제안만** 한다(규칙 파일은 직접 고치지 않음).

## 꺼내기

- "최근 결정": 결정.md에서 최근 순 표 — 날짜 / 결정 / 이유 / 근거 인용.
- "지금 어디까지": 상태.md에서 주제별 최신 줄(취소선 제외).
- "다음 할 일": 상태·결정 + 사용자가 준 최근 메모로 표 — 할 일 / 근거(날짜+인용) / 상태(진행 중·막힘·끝남) / 우선순위.
  기록에 없는 일은 추가하지 않는다. 아무것도 실행하거나 보내지 않는다.
