# my-ppt — 개인 PPT 제작 규칙

PPT/슬라이드 제작 요청 시 아래 규칙을 **예외 없이** 적용한다.
.pptx 파일 생성 자체는 `anthropic-skills:pptx` 스킬(HTML 슬라이드면 해당 워크플로)로 수행하고,
스타일·레이아웃 결정은 전부 이 문서를 따른다.

## 0. 개인화 설정 (사용자가 직접 수정하는 블록)

| 항목 | 값 |
|------|-----|
| 기본 폰트 | **Pretendard** (스킬 내장: `assets/fonts/Pretendard-*.otf`, 시스템에도 설치됨) |
| 로고 | `assets/logo.png` (없으면 로고 생략 — 임의 로고 절대 금지) |
| 기본 소속 | 우리동네작은교회 · 김병곤 목사 |
| 기본 언어 | 슬라이드 본문 한국어, 디자인 프롬프트 영어 |
| 강조색 | 슬라이드 주제에 맞게 제안하되, 확정 전 사용자에게 1회 확인 |

## 1. 필수 규칙

### 폰트
- 모든 텍스트는 Pretendard. 제목 Bold/ExtraBold, 본문 Regular, 캡션 Light.
- HTML 슬라이드일 때는 `assets/fonts/`의 폰트 파일을 @font-face로 임베드하고,
  없으면 `font-family: 'Pretendard', 'Malgun Gothic', sans-serif` 폴백.
- .pptx일 때는 폰트 이름 "Pretendard"를 지정 (수신자 미설치 위험은 완성 시 한 줄로 고지).

### 로고
- MiniMax·샘플·타사 로고를 절대 넣지 않는다.
- `assets/logo.png`(또는 .svg)가 있으면 표지 + 매 슬라이드 하단 한쪽 구석에 작게 배치.
- 로고 파일이 없으면: 로고 없이 만들고, 완성 후 "assets/logo.png에 로고를 넣으면 다음부터 자동 삽입됩니다"라고 한 번만 안내.

### 슬라이드 사이즈
- 항상 **16:9** (pptx: 13.333 × 7.5 in / HTML: 1280 × 720 기준). 묻지 말고 적용.

### 레이아웃 일관성
매 슬라이드에서 다음 요소는 **픽셀 단위로 같은 위치**에 고정한다:
- 챕터명: 좌측 상단 (작은 크기, 강조색)
- 제목: 챕터명 바로 아래, 좌측 정렬
- 부제목: 제목 아래 고정 간격
- 페이지 번호·로고: 하단 고정 위치
표지·섹션 간지만 예외 레이아웃 허용.

### 본문 밀도
- 본문 영역 하단을 크게 비워두지 않는다. 내용·도표·이미지로 밀도 있게 채우되
  여백 리듬을 깨면서까지 욱여넣지는 않는다.
- 내용이 부족해 하단이 비면: 관련 도표/아이콘/보조 설명을 추가해 채우거나, 슬라이드를 병합.

### 디자인 프롬프트는 영어로
- 이미지 생성, 디자인 도구, 아트 디렉션용 프롬프트는 **항상 영어로 작성**한다.
  (한글 프롬프트보다 결과가 훨씬 좋음.)
- 사용자에게 보여주는 설명·대화는 한국어 유지. 수정 요청을 받아도 프롬프트 자체는 영어로 다시 쓴다.

## 2. 작업 순서

1. 주제·분량·용도를 파악 (모호하면 슬라이드 수와 용도만 짧게 확인).
2. 개요(슬라이드별 제목 1줄)를 먼저 보여주고 승인받는다.
3. 위 규칙대로 제작 → 완성 파일을 사용자에게 전달.
4. 수정 요청 시: 규칙은 유지한 채 해당 슬라이드만 고친다.

## 3. 사용자가 새 요구를 말하면

"앞으로 항상 ~해줘" 형태의 요구가 나오면 이 파일의 **개인화 설정 표 또는 필수 규칙에
직접 추가**하여 다음 세션부터도 적용되게 한다.
