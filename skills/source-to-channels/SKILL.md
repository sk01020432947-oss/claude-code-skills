# source-to-channels — 원소스 멀티채널 오케스트레이터

원형: uxjoseph/content-marketing-team (MIT, 영상 QgAXjgAlQ2Y). 구조(기획→병렬 집필→검수)만 가져오고, 집필·이미지·영상은 **이미 설치된 스킬에 위임**한다. 새 집필 에이전트를 만들지 않는다.

## 0. 시작 전 (1회)

- 산출물에 **발표자료·카드뉴스·쇼츠·영상**이 포함되면 `awesome-ai-motion` 스킬을 쓸지 **한 번만** 묻는다. 승낙을 다음 자료로 일반화하지 않는다.
- 채널을 사용자가 안 골랐으면 기본 세트(블로그·카드뉴스·쇼츠 대본·소그룹/토론 질문)만 제안한다. 10종 전체를 기본값으로 돌리지 않는다.

## 1. 원천 수집 — 대본이 없으면 멈춘다

| 원천 | 방법 |
|---|---|
| YouTube URL | `/watch` (자막→Whisper 순). 자막·Whisper 키가 모두 없으면 **설명란만으로 쓰지 말고** 사용자에게 알린다 |
| 웹 글 URL | `defuddle` |
| 내 원고·설교 전사본 | 파일 그대로 읽는다 (가장 신뢰도 높음) |
| 장기 보관할 영상 | `youtube-wiki-ingest` 로 타임스탬프 위키에 적재 후 인용 |

확보한 근거 수준을 브리프에 `근거: 전체 대본 / 설명란만 / 부분` 으로 반드시 적는다. 설명란만이면 본문 인용 금지, 요약형 산출물만 허용.

## 2. 브리프 (planner 역할 — 직접 수행)

`<주제폴더>/brief.md` 에 쓴다. 항목: 원천·근거 수준 / 메인 주제 1줄 / 핵심 메시지 3~5 / 독자·청중 / 톤 / 채널별 지침 / **팩트 앵커**(검수가 대조할 원문 요약, 수치·인용·고유명사). 없는 내용을 만들지 않는다.

## 3. 병렬 집필 — 채널 → 위임 스킬

| 채널 | 위임 |
|---|---|
| 블로그 | `sermon-to-blog` (설교) / `content-strategy`·`copywriting` (일반) |
| 설교 영상 메타·쇼츠 추천 | `sermon-to-youtube` |
| SNS 캡션 | `church-social-post` / `moai-threads-poster:threads-post-draft` |
| 뉴스레터·교우 편지 | `church-email` / `church-letter` |
| 소그룹 질문 | `small-group-questions` |
| 카드뉴스·인스타툰 | `insta-toon`, `kbg-infographic` |
| 이미지·썸네일 | `media-gen-image` (fal nano-banana-pro) |
| 쇼츠 영상 편집 | `video-use` → `video-stitch-captions` |
| 발표덱 | `claude-ppt` 등 덱 스킬 (0단계 질문 적용) |

독립 채널은 **한 메시지에서 Agent 도구를 동시에 호출**한다. 모델은 품질이 중요한 장문(뉴스레터·블로그)만 상위, 짧은 변환(스레드·링크드인·쇼츠 대본)은 경량으로 둔다.

## 4. 검수 게이트 (reviewer 역할)

1. `content-fidelity-auditor` — 브리프 팩트 앵커와 대조 (설교·신학 원고면 본문 해석·교리 훼손 여부 포함)
2. `humanize-korean` 또는 `ai-tell-detector` — AI 티 제거
3. `korean-spell-check` — 맞춤법
4. 플랫폼 규격: 스레드 280자, 쇼츠 대본 약 150~180자, 카드뉴스 4:5(1080×1350), 썸네일 16:9(1280×720)

실패 파일은 해당 채널만 재작성한다. 전체 재실행 금지.

## 5. 저장

- 정본: `~/Desktop/cysjavis/<주제폴더>/<한글이름>` (파일명 한글)
- 요약 노트: 옵시디언 `AI 관련자료/` 아래 주제 폴더
- 링크는 항상 클릭 가능한 마크다운 링크로 제시한다.

## 하지 않는 것

- 외부 게시(블로그·SNS·메일 발송)는 사용자 승인 전에 하지 않는다.
- 설명란/제목만 보고 영상 내용을 쓴 것처럼 산출하지 않는다.
- 통계 수치는 출처 있는 값만. 없으면 "예시"로 표시.
