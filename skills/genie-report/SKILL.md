# Genie Report — 그레이스케일 A4 보고서 생성기 (HTML + PPTX)

우석지니 "텍스트 많고 복잡한 AI 보고서·제안서 PPTX 작성 워크플로우" 영상의 결과물과 방법론을 재현한 스킬.
입력(원고·주제·자료)을 받아 **① A4 세로 HTML 보고서 ② 편집 가능한 네이티브 PPTX** 두 파일을 생성한다.

> 원본 방법론의 제1원칙: **시각화는 최소, 작성과 구조화에 몰입한다.**
> 내용·구조·논리의 밀도가 먼저고, 디자인은 그레이스케일 위에 악센트 1색이면 충분하다.

## 0. 시작 전 확인 (한 턴에 몰아서 질문)

사용자가 이미 밝힌 항목은 건너뛴다:
1. **원고/자료** — 완성 원고가 이상적. 주제만 있으면 목차·초안부터 작성해 확인받는다
2. **분량** — A4 몇 페이지 (보통 2~6장. 페이지 높이가 고정이라 분량 설계가 곧 레이아웃 설계다)
3. **표제부 정보** — 보고서 제목·부제·작성일·작성 주체·보고 대상·문서 구분
4. **악센트 색** — 기본 무채색. 회사 톤앤매너가 있으면 브랜드 1색 (예: `#5B2D90`)
5. **출력** — HTML+PPTX(기본) / PDF 추가

## 1. 내용 작성 원칙 (영상의 핵심 방법론)

- **원문 각색 금지.** 사용자가 준 내용·수치·주장을 요약·생략·변형하지 않는다. 임의 창작 금지. 부족하면 물어본다.
- **제목은 메타포.** 내용 속 상징을 제목으로 승격한다 (영상 예: 레버리지 ETF가 증시를 흔든다 → "꼬리가 몸통을 흔들 때").
- **경어체** 본문. 마크다운 기호(#, *, -)를 본문에 노출하지 않는다 — 하이픈·쉼표·작은따옴표·콜론 등 문장 기호로 대체.
- **차트는 데이터가 있는 곳에만.** 수치 비교가 있으면 바 차트, 항목 대조는 표, 핵심 수치는 KPI 박스. 장식용 도해 금지.
- 초안 → 수정 반영 → 재적용을 반복해 밀도를 올린다. 사용자 수정 피드백이 오면 그 규칙을 이후 페이지 전체에 소급 적용한다.

## 2. 스타일 토큰

```css
--accent:#1A1A1A;  /* 기본 무채색. 톤앤매너 적용 시에만 브랜드 1색으로 교체 */
--ink:#1A1A1A;     /* 제목·강조 */
--body:#333333;    /* 본문 */
--mute:#777777;    /* 캡션·출처·헤더/푸터 */
--line:#DDDDDD;    /* 괘선 */
--fill:#F4F4F4;    /* 표 머리·박스 채움 */
```

**색 규칙**
- **그레이스케일이 기본이고 악센트는 1색뿐이다.** 악센트가 닿는 곳: 페이지 상단 라인, 섹션 번호, KPI 숫자, 바 차트, 표 강조 셀, kicker. 그 외 전부 무채색.
- 컬러가 많다고 좋은 보고서가 아니다 — 그레이스케일 위에 단일 색 하나가 훨씬 강력하다 (영상 원칙).
- 폰트는 프리텐다드 단일. 본문 10.5pt / 행간 1.68 / 양쪽정렬.

## 3. 페이지 해부도 (A4 세로 210×297mm 고정)

```
┌─────────────────────────────┐
│▓ 악센트 라인 1.2mm            │
│ 보고서 제목        n / N      │ ← .phead (JS 자동 쪽번호)
│─────────────────────────────│
│ [표제부: kicker+제목+부제+메타] │ ← 1페이지만 .titleblock
│ 01 섹션 제목                  │ ← h2 (번호 em + 밑줄)
│ 본문 문단 · 부품들             │
│─────────────────────────────│
│ 작성 주체 · 구분      워터마크  │ ← .pfoot
└─────────────────────────────┘
```

- 여백: 상 24mm / 좌우 18mm / 하 20mm. 콘텐츠 폭 174mm.
- **페이지 높이는 고정이다.** 내용이 넘치면 잘린다 — 부품 배치 시 분량을 계산하고, 넘치면 다음 `.page`로 쪼갠다.
- 헤더에는 보고서 제목+쪽번호, 푸터에는 작성 주체+워터마크 (영상의 요구사항 그대로).

## 4. 부품 (변환기가 아는 클래스만 사용 — 임의 클래스 추가 금지)

| 부품 | 마크업 | 용도 |
|------|--------|------|
| 표제부 | `.titleblock` > `.kicker` + `h1` + `.sub` + `.meta>div(b+텍스트)` | 1페이지 상단 |
| 섹션 제목 | `h2 > em(번호) + 텍스트` | 01, 02… 넘버링 |
| 소제목 | `h3` | 섹션 내 구분 |
| 문단 | `p` (강조는 `b`) | 본문 |
| 목록 | `ul > li` | 개조식 |
| 강조 박스 | `.callout > b(제목) + 텍스트` | 핵심 판단·결론 |
| 표 | `table > tr > th/td` (`td.hl` 악센트, `td.num` 우정렬) | 대조·명세 |
| KPI | `.kpirow > .kpi(b숫자+i라벨+small캡션)` ×2~4 | 핵심 수치 |
| 바 차트 | `.barchart > .brow(.lbl+.track>.bar[width:%]+.val)` + `.chartcap` | 수치 비교 |
| 2단 | `.grid2 > .col` ×2 | 병렬 비교 |
| 출처 | `.src` | 표·차트 아래 |

이 클래스 집합이 곧 **HTML↔PPTX 계약**이다. `report2pptx.py`가 이 구조를 파싱해 네이티브 PPTX 개체로
재구성하므로, 새 부품이 필요하면 변환기에도 렌더러를 추가해야 한다.

## 5. 빌드 절차

1. `template.html`을 골격으로 사용 (토큰·부품 CSS·쪽번호 JS·인쇄 CSS 포함). 샘플 내용은 전부 교체.
2. 원고를 섹션(01~0N)으로 분해해 **페이지 계획표**(페이지·섹션·부품 구성)를 만들어 사용자에게 보여준다.
3. `<section class="page">` 단위로 생성. 악센트를 쓰면 `:root`의 `--accent`만 교체.
4. `{주제}-report.html`로 저장. **저장 전에** impeccable 파일 예외를 먼저 등록한다(프리텐다드 단일 폰트는 이 스타일의 확정 사양 — Write 후 등록하면 Stop 훅이 한 번 더 경고하는 경합이 생긴다):
   ```
   node /Users/kbg1023/.claude/plugins/cache/impeccable/impeccable/4.0.3/skills/impeccable/scripts/hook-admin.mjs ignore-value single-font "*" --file "<저장할 절대경로>"
   ```
5. **검증 (필수)**: Edge 헤드리스 print-to-pdf로 페이지 넘침을 확인한다 — **PowerShell 도구**로:
   ```
   msedge --headless=new --print-to-pdf="검증.pdf" --no-pdf-header-footer "file:///...html"
   ```
   확인 항목: ① 내용이 페이지 밖으로 잘리지 않는가 ② 쪽번호가 맞는가 ③ 악센트가 2색 이상 섞이지 않았는가.
6. **PPTX 생성**:
   ```
   python3 /Users/kbg1023/.claude/skills/genie-report/report2pptx.py "보고서.html" --accent "#5B2D90"
   ```
   같은 폴더에 같은 이름 `.pptx` 생성 (--accent 생략 시 무채색). 의존성: python-pptx.
   변환기가 넘침 경고(`[warn] page N`)를 내면 해당 페이지 분량을 줄이거나 쪼갠다.
7. PPTX는 **편집 가능한 텍스트·표·도형**이므로, 사용자가 파워포인트에서 톤앤매너를 마저 다듬는 것이
   영상 워크플로의 4단계다 — 완료 후 "악센트 색만 바꿔 달라"는 요청은 `--accent`로 재생성하면 된다.

## 6. 산출물 안내에 포함할 것

- HTML: 브라우저에서 열림. Ctrl+P → PDF 저장 시 A4 세로, 페이지당 1장 (인쇄 CSS 내장)
- PPTX: 파워포인트에서 전부 편집 가능. A4 세로 판형이므로 인쇄·PDF 내보내기에 그대로 사용
- 악센트 색 변경: HTML은 `--accent` 값 하나, PPTX는 변환기 재실행
