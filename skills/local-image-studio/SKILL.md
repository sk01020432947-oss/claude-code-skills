# local-image-studio

맥북의 로컬 Image Studio 웹 앱에 작업을 넣고 결과 PNG 를 받는다. 여기서 만든 이미지는
브라우저 갤러리(http://127.0.0.1:3210)에도 그대로 쌓인다. 실행 도구는
`scripts/studio_generate.py` 하나다(파이썬 표준 라이브러리만 사용).

## 0. 전제 확인

```bash
python3 <이 스킬 폴더>/scripts/studio_generate.py --status
```

- `설치 폴더: 찾지 못함` → 아직 설치 전. 사용자에게 `apps/image-studio/README.md` 의 설치 3단계
  (`./install.sh --check` → `./install.sh` → `start.command`)를 안내하고 멈춘다. 급하면
  `[[media-gen-image]]` 로 대신 생성할지 묻는다.
- 꺼져 있어도 설치 폴더가 있으면 생성 명령이 자동으로 켠다(웹 앱 30초, ComfyUI 첫 로딩 1분 안팎).
- macOS 가 아니면(리눅스 클라우드 세션 등) 이 스킬은 쓸 수 없다. 로컬 맥의 Claude Code 에서만 동작한다.

## 1. 프롬프트 재작성 → 사용자에게 보여 주기

사용자의 거친 한 줄을 피사체·장면·빛·구도·분위기가 드러나는 문장으로 다시 쓴다.
한국어 그대로 써도 되지만, 세부 묘사가 많으면 영어가 더 정확하다. 재작성 결과를 먼저 보여 준다.

스타일(`--style`)은 프롬프트 뒤에 붙는 묶음이다. 용도에 맞게 고른다.

| 용도 | --style | --ratio |
|---|---|---|
| 성경 장면 일러스트 | `bible-scene` | 16:9 |
| 설교 슬라이드 배경 (글자 자리 비움) | `sermon-slide` | 16:9 |
| 묵상 카드·SNS | `devotional` | 1:1 또는 4:3 |
| 주보 표지 | `bulletin` | 3:4 |
| 웹툰 패널 초안 | `webtoon` | 9:16 또는 3:4 |
| 유튜브 썸네일 배경 | `thumbnail` | 16:9 |
| 그 밖 | `photo` `cinematic` `illustration` `watercolor` `3d` `poster` `none` | 자유 |

성경 장면은 고증 정보(의복·건축·지형·시대)를 `[[sermon-history-culture-geo-context]]` 로 먼저
뽑아 프롬프트에 넣는다. 모델은 기본적으로 서구 회화풍 성경 그림을 그리려 하므로 구체적으로 지시한다.
글자(제목·성구)는 이미지에 넣지 말고 나중에 슬라이드·디자인 도구에서 얹는다.

## 2. 초안 탐색 (시드 여러 개)

```bash
python3 <스킬>/scripts/studio_generate.py "<재작성 프롬프트>" --style <id> --ratio <비율> --preset turbo --count 4
```

- `turbo` 640² 급 12스텝, 한 장 약 1분. 4장이면 4~5분이다. 시작 전에 걸리는 시간을 알려 준다.
- 결과는 `./outputs/studio/` 에 `날짜_seed<시드>_<id>.png` 로 저장되고 `seeds.md` 에 기록된다.
- 결과 파일을 Read 로 열어 직접 보고, 각 시드의 차이(구도·인물·빛)를 짧게 설명한 뒤 고르게 한다.

## 3. 고른 시드만 표준 품질로

```bash
python3 <스킬>/scripts/studio_generate.py "<같은 프롬프트>" --style <id> --ratio <비율> --preset standard --seed <고른 시드>
```

- 표준은 1024² 급 40스텝, 5~6분(저메모리 설치는 10분 안팎). 미리 알린다.
- 같은 시드라도 해상도가 바뀌면 구도가 조금 달라질 수 있다고 말해 둔다.
- 사용자가 기다리기 싫으면 `--no-wait` 로 넣어 두고 브라우저 갤러리에서 확인하게 한다.

## 4. 사진 편집 (외부 전송 없음)

```bash
python3 <스킬>/scripts/studio_generate.py "배경을 늦가을 단풍으로 바꾸고 인물은 그대로 유지" --ref <사진 경로> --preset draft
```

- 참조 이미지는 최대 3장. 출력 크기는 첫 참조 이미지를 따른다.
- 사람 얼굴이 있는 사진은 결과를 반드시 사람이 확인하게 하고, 당사자 동의 없는 합성·변형은 하지 않는다.

## 5. 최종본 넘기기 (선택)

최상급 품질이나 빠른 대량 생산이 필요하면 고른 프롬프트·시드·구도 설명을 `[[media-gen-image]]` 로 넘긴다
(fal.ai, 유료 — `[[cost-preview-confirm]]` 을 거친다).

## 지키는 것

- 안전 필터를 제거한 텍스트 인코더(Heretic 등)는 쓰지 않는다. 이 배포판의 웹 앱은 그런 인코더를 목록에서 숨기고 요청이 와도 기본 인코더로 바꾼다.
- 생성은 한 번에 하나씩 대기열로 돈다. 같은 맥에서 다른 무거운 작업(영상 렌더 등)과 동시에 돌리면 둘 다 크게 느려진다고 알린다.
- 끝나면 사용자가 원할 때 `apps/image-studio/stop.sh` 로 끌 수 있다고 안내한다(웹 앱이 켠 ComfyUI 는 백그라운드에 남는다).

## 오류 대응

| 증상 | 조치 |
|---|---|
| `설치 폴더도 찾지 못했습니다` | `./install.sh` 실행 안내 (`~/.image-studio-root` 가 만들어진다) |
| `3분 안에 켜지지 않았습니다` | `<설치 폴더>/web.log` 확인, `./stop.sh` 후 `start.command` 로 다시 켜기 |
| 작업 `실패`, 메모리 관련 메시지 | 다른 앱을 닫고 `--preset turbo` 또는 `lowmem` 으로 다시 |
| 매우 느림 (스텝당 20초 이상) | 스왑 발생. 브라우저 탭·IDE 를 닫고 해상도를 낮춘다 |
