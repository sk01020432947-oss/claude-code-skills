## 승인 관문 문구 (6:18)


마음에 들면 `승인`만 입력한다. SKILL.md §3 스토리보드 관문과 같은 자리다.

## 음성 먼저 → 자막 → 장면 (8:37~12:37)
1. 30초 대본 → TTS로 MP3 (영상: ElevenLabs / 로컬 대안: `voicebox-local-tts`, 서버 localhost:17493)
2. MP3 → SRT (영상: Vrew / 로컬 대안, 2026-11-21 실측 동작):
   `whisper-cli -m ~/Desktop/cysjavis/KBG-Bible-Labs-Sermon/data/models/ggml-large-v3-turbo-q8_0.bin -l ko -osrt -of narration -f narration_16k.wav`
   (먼저 `ffmpeg -i narration.mp3 -ac 1 -ar 16000 narration_16k.wav`) — 대본과 대조해 오탈자를 고친다.
3. 주문서 + MP3 + SRT 첨부 → 총 길이는 MP3, 장면 경계는 SRT 큐 시각으로 잡는다(모드 D).
4. 렌더 후 `ffmpeg -i clip.mp4 -i narration.mp3 -c:v copy -c:a aac -shortest out.mp4`.

## 주의
- 숫자 영상은 입력 원문과 한 번씩 대조한다(8:00).
- 사용량: 영상 속 실측은 Max 플랜 1분 영상 1회 2~3%(3:09, 화자 경험치 — 일반화 금지).
- 상업 이용은 TTS 서비스의 유료 플랜 조건을 확인한다(영상 9:32는 ElevenLabs 기준 설명).
