## 1. 스타일 사양 (영상 실측)

### 색 — 강조색은 블루 하나만
| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#F3F1E9` | 전체 캔버스. 웜톤 오프화이트. 그라데이션·패턴 없음 |
| `--card` | `#F9F9F5` | 카드, 라이트 타일, 필 |
| `--ink` | `#1B1E1D` | 다크 타일(`#2B2E2D→#141716` 그라데이션), 큰 숫자, 막대 |
| `--text` | `#343432` | 본문, 칩 테두리 |

빨강·초록·노랑은 쓰지 않는다. "좋다/나쁘다"는 블루 vs 회색 디밍으로만 말한다.

### 글꼴
- **Pretendard Variable** 하나(CDN 로드, 로컬 설치본 우선). 큰 숫자 700 / 타일 라벨 700 / 본문 500~600 / 캡션 500.
- 큰 숫자 118px, 자간 −0.035em, `tnum`(고정폭 숫자). 타일 라벨 44px(대)·28px(중)·19px(소).
- 로그·코드만 모노(`SF Mono`/Menlo) 14px.
- **슬라이드 제목은 없다.** 화면은 도식만, 말은 자막이 한다.

### 형태
- **타일 노드**: 둥근 정사각(150px, 반경 32px) 앱 아이콘. 주인공 = 다크, 비교 대상 = 라이트. 아래에 회색 캡션(“라우팅”, “학습 100 · 약 4분”).
- **카드**: 반경 16px, 테두리 없음, 아주 옅은 그림자 2겹. 좌상단 작은 라벨(“시험 250 🔒”) → 큰 숫자 → `n/N` → 와플.
- **와플 격자**: 25열 × N칸. 비율을 면적으로 보여 준다(82/250 → 82칸 블루).
- **필/칩**: 선택지는 흰 필, 정답 표시는 테두리 알약 칩(`정답 · 취소`), 활성 칩은 블루 채움.
- **연결선**: 1.5px 회색 헤어라인. 분기는 베지어 곡선. 점선은 순환·보강 루프에만.
- **막대**: 다크 직사각, 라벨은 아래. 비교 중 아닌 막대는 회색.
- **여백**: 요소는 화면의 40~60%만 쓴다. 나머지는 비운다.

### 자막 (영상의 시그니처)
- 하단 중앙, 바닥에서 118px 위. 다크 박스 + 흰 글씨 31px/600, 패딩 7×16px, 모서리 거의 직각(2px).
- **한 줄, 8~20자 구어체 조각.** 문장을 끊어서 박자마다 하나씩 바꾼다. 페이드 없이 즉시 교체.
- 숫자는 자막과 화면이 같은 박자에 맞물린다("68.8%로 올라갔습니다" ↔ 카운트업).

### 모션 어휘

## 2. 절차

1. **원문 읽기.** 원고·논문·강의안 전체를 읽는다. 원문에 없는 숫자는 만들지 않는다.
2. **대본을 박자로 쪼갠다.** 장면(슬라이드)마다 자막 3~5줄. 자막 한 줄 = 한 박자 = 화면 변화 하나.
3. **장면 유형을 고른다** (템플릿 6종 중):
   - 표지/대비 → 1번(두 타일 + 라벨 선) · 과정/분기 → 2번(입력 → 노드 → 갈래)
   - 수치 변화 → 3번(막대 + 카드 + 와플 + 로그) · A vs B → 4번(두 카드, 진 쪽 디밍)
   - 비중/시간 → 5번(타임라인) · 결론 → 6번(타일 하나)
4. **복사해서 채운다.** `<section class="slide">` 블록을 복사하고 텍스트·숫자·`data-*` 박자만 바꾼다. `<ol class="subs">`의 `<li>` 개수가 그 장의 박자 수다.
5. **검증.** 브라우저로 열어 → 키로 끝까지 넘기며 확인: 자막 한 줄 넘침 없음, 블루는 장마다 한 곳, 요소 겹침 없음, 콘솔 오류 없음.
6. **녹화가 필요하면** `?auto=1`로 열어 화면 녹화(QuickTime/OBS). 자막 글자 수 × 140ms(최소 1.6초)로 자동 진행하고 힌트·페이스캠 자리는 숨긴다. 자막을 영상 편집에서 따로 넣을 땐 `?auto=1&nosubs`. MP4를 바로 뽑아야 하면 `remotion-kr`이나 `video-stitch-captions` 스킬로 넘긴다.

## 3. 조작

`→`/스페이스/클릭 다음 박자 · `←` 이전 · `S` 자막 켜기/끄기 · `F` 전체화면 · `?auto=1` 자동재생 · `?nosubs` 자막 없이 · `?rec` 힌트·페이스캠 자리 숨김.
우하단 300×260px은 페이스캠 자리로 비워 둔다(점선은 편집용 안내, 녹화 모드에서 사라짐). 요소를 그 자리에 두지 않는다.

## 4. 하지 말 것

- 슬라이드 제목, 글머리표 목록, 문단 텍스트. 설명은 자막이 한다.
- 블루 말고 다른 강조색, 그라데이션 배경, 아이콘 남발(작은 선 아이콘이나 이모지 하나까지만).
- 한 박자에 요소 4개 이상 등장, 1.15배 넘는 줌, 회전·바운스 효과.
- 두 줄짜리 자막.
