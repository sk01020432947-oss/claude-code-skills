# kbg 발표자료 1 — 클린 도식

출처: 유튜브 혼잡스(@honjobs) 발표 영상 프레임 실측(2026-10-28). 다른 스타일과 비교·선택은 라우터 [kbg-발표자료](../kbg-발표자료/SKILL.md)에서 한다.
[template.html](template.html)이 정본 틀이다(엔진·CSS 인라인, 단독 실행). **구조와 클래스는 그대로 두고 내용만 바꾼다.**

## 0. 시작 전

- 발표자료이므로 **작업 시작 전 한 번** 묻는다: "`awesome-ai-motion` 스킬도 함께 쓸까요?" (CLAUDE.md 8번). 승낙해도 이 스킬의 시각 규칙이 우선이다.
- [template.html](template.html)을 `~/Desktop/cysjavis/<주제폴더>/<한글이름>.html`로 복사한 뒤 고친다(정본). 아티팩트는 사본이다.
- 통계는 출처 있는 값만 쓴다. 없으면 자막이나 라벨에 "(예시)"를 붙인다.
- 공용 마크업(`data-in`, `data-cams`, `data-count` 등)과 진행 키는 라우터 [kbg-발표자료](../kbg-발표자료/SKILL.md) 2·3절에 있다.

## 1. 스타일 사양 (영상 실측)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#FFFFFF` | 순백. 패턴·그라데이션 없음 |
| `--ink` / `--line` | `#111111` | 제목, 박스 테두리 2.5px, 화살표 |
| `--text` / `--soft` | `#2B2B2B` / `#555` | 본문 / 보조 |
| `--hair` | `#D9D9D9` | 구분선, 비활성 박스 |
| `--red` | `#E8342A` | **핵심 숫자·경고** 강조 |
| `--blue` | `#2A6CF0` | **선택·정답** 강조. 한 장면에 빨강·파랑 중 하나를 주인공으로 |
| `--orange` `--yellow` | `#F5782A` `#FADC46` | 마스코트 목도리, 형광 밑줄 |

| 글꼴 | 쓰임 |
|---|---|
| Pretendard Variable 800 | 제목 `.head` 54px, 박스 `.box` 38px, 본문 |
| Black Han Sans | 표지 큰 제목 `.title`, 큰 숫자 `.big` |
| JetBrains Mono | 터미널·코드 `.term` |

화면 구성: 위 여백 넉넉히, 내용은 세로 가운데(`.area.col`/`.area.row`). 자막은 화면 아래 검정 띠에 흰 글씨 한 줄. 제목이 없는 장면이 많다 — **자막이 제목 역할**.

## 2. 부품

| 클래스 | 모양 |
|---|---|
| `.who` + `.tag` | 표지 마스코트(둥근 얼굴 + 목도리) + 역할 라벨 |
| `.box` (`.blue` `.red` `.black` `.gray` `.left`) | 둥근 모서리 18px 도식 박스. `.black`은 검정 채움 흰 글씨 |
| `.pill` | 빨강/파랑 알약 라벨(32px) — 장면 주제 표시 |
| `.big` + `<sub>` | 빨간 큰 숫자(Black Han Sans) + 단위 |
| `dl.bars` → `dt` + `dd > i[style=--w:…]` | 가로 막대 비교. 막대가 왼쪽에서 자라며 들어옴 |
| `.levels` | 단계 선택기(한 칸만 켜짐) |
| `.vs` | 두 카드 비교, 가운데 VS |
| `.line` / `svg.draw` | 박스 사이 연결선 — 선이 그려지며 등장 |
| `.term` | 다크 터미널 카드 |
| `.stmt` | 화면 가운데 한 문장 결론 |
| `.note` `.small` | 파란 보조 문장 / 회색 출처·주석 |

예시 장면 10개: 표지 마스코트 → 선택 UI와 빨간 숫자 → 막대 비교 → 알약+제목+박스 3개 → 마스코트 흐름(빨간 화살표) → 두 카드 비교(선택은 파란 테두리) → 단계 선택기 → 터미널 → 요약 3박스 → 맺음 문장.

## 3. 모션 어휘

| 움직임 | 구현 | 쓸 때 |
|---|---|---|
| 아래에서 살짝 떠오름 | 기본 `[data-in]` | 모든 요소의 기본 등장 |
| 막대 성장 | `dd.on i` width 전환 | 수치 비교 |
| 숫자 카운트업 | `data-count` | 핵심 숫자 하나 |
| 선 그리기 | `svg.draw` dashoffset | 흐름·관계 |
| 디밍 | 비활성 요소 `.gray`/투명도 | "이것만 보세요" |
| 챕터 레일 | `data-ch` | 4~6개 큰 마디 |

## 절차

1. 원고를 **장면 → 박자**로 쪼갠다. 박자 하나 = 자막 한 줄 = 화면 변화 하나. 자막은 25자 안팎.
2. 템플릿 예시 장면 중 가장 가까운 것을 복제해 내용만 바꾼다. 쓰지 않는 예시 장면은 지운다.
3. 브라우저로 열어 →로 넘기며 확인한다. 넘침·겹침은 글자 크기보다 **박자를 나눠서** 푼다.
4. 장면별 확인 사진: `node ~/.claude/skills/kbg-발표자료/tools/record.mjs 발표.html --shots 확인 --beats`
