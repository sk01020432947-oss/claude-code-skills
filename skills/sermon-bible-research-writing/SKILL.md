# 설교를 위한 성경연구 및 설교문작성 (Research-Based Sermon Preparation)

## 핵심 철학

박사논문을 쓰는 방법론을 설교 준비에 그대로 이식한다. 논문이 "연구 질문 → 문헌 조사 → 분석·종합 → 논증 집필 → 인용 검증"으로 완성되듯, 설교도 "설교 질문 → 본문·자료 연구 → 주석 대화 → 설교문 집필 → 전수 검증"으로 완성한다.

**3대 원칙**:
1. **출처 없는 주장 금지** — 설교 속 모든 역사적 사실·통계·원어 해설·학자 인용은 출처가 확인된 것만 사용한다. 확인 불가 시 반드시 "확인 필요"로 표시하고 설교문에 넣지 않는다.
2. **본문이 주인, 자료는 종** — 연구가 아무리 풍성해도 설교의 논지는 본문에서 나온다. 자료가 본문을 밀어내면 경고한다.
3. **이중 산출** — 연구용(각주 포함)과 강단용(각주 없는 구어체) 두 버전을 항상 함께 만든다. 연구 자산은 축적되고, 강단에서는 자연스럽다.

## 전체 워크플로우 (7단계)

사용자가 본문 또는 주제를 제시하면 1단계부터 시작한다. 특정 단계만 요청하면 그 단계만 수행한다. 각 단계 산출물은 사용자가 지정한 폴더(기본: `설교연구\{본문}_{날짜}\`)에 마크다운으로 저장하여 축적한다.

### 1단계. 설교 질문 정식화 (논문의 '연구 질문' 대응)

- 본문을 받으면 먼저 묻는다: "이 본문으로 회중의 어떤 질문에 답하려 하십니까?"
- 설교 질문을 3가지 형태로 다듬어 제안한다: 해석형(이 본문은 무엇을 말하는가) / 신학형(이 본문은 하나님에 대해 무엇을 계시하는가) / 적용형(이 본문은 오늘 우리에게 무엇을 요구하는가).
- FINER식 점검: 한 편의 설교로 다룰 수 있는 크기인가(Feasible), 회중에게 절실한가(Relevant), 이미 뻔한 답은 아닌가(Novel).
- 산출: `01_설교질문.md` — 확정 설교 질문 + 가설적 빅 아이디어(잠정 논지) 1문장.

### 2단계. 자료 수집 계획과 실행 (논문의 '문헌 수집' 대응)

자료를 3층으로 구분하여 수집 계획표를 만든 뒤 수집한다:

| 층위 | 자료 | 수집 방법 |
|------|------|----------|
| 1차 자료 | 성경 원문(히브리어/헬라어), 주요 번역본 비교, 사본 이독 | sermon-multi-bible-version-compare, sermon-textual-criticism 연계 |
| 2차 자료 | 주석서, 학술논문, 원어 사전(BDAG/HALOT급), 역사·배경 연구 | 사용자 보유 자료 폴더 + 웹 검색(출처 확인된 것만) |
| 3차 자료 | 설교집, 예화, 통계 | 반드시 원출처 역추적 후 사용 |

- **출처 등급제**: 각 자료에 등급을 매긴다. A(원전·표준 학술자료) / B(신뢰할 만한 2차 자료) / C(출처 불명·재인용 — 설교문 사용 금지, 원출처 확인 후 승급).
- **할루시네이션 방지 규약**: 존재가 확인되지 않은 책·논문·인용문은 목록에 넣지 않는다. "칼빈이 말하기를…" 류 인용은 저작명·위치까지 확인되어야 A/B등급. 확인 불가면 "전승되는 말(출처 미상)"로 명시하거나 제외.
- 산출: `02_자료목록.md` — 등급 표시된 자료 목록 + 미확보 자료의 확보 경로.

### 3단계. 본문 연구노트 작성 (논문의 '문헌 정리·paper-study' 대응)

paper-study의 능동 학습 방식을 본문 연구에 적용한다:

- 본문 구조 분석(단락·흐름·키아스무스 등 — sermon-text-analysis-multimethod 연계 가능)
- 핵심 원어 3~5개: 단어, 기본형, 의미 범위, 본문 내 의미, 성경 전체 용례 (가짜 어원 금지 — 어원 오류 의심 시 경고)
- 역사·문화·지리 배경 (sermon-history-culture-geo-context 연계 가능)
- 평행 본문·상호참조
- **능동 회상**: 연구 후 사용자에게 2~3개 질문을 던져 스스로 본문을 재설명하게 하고, 그 답을 노트에 기록한다 (설교자의 언어가 되어야 강단에서 산다).
- 산출: `03_본문연구노트.md` — 표준 템플릿(아래 '연구노트 템플릿' 참조).

### 4단계. 주석 매트릭스와 쟁점 지도 (논문의 '문헌 매트릭스' 대응)

- 주석가·신학자별 입장을 표로 정리: 행=자료, 열=핵심 해석 쟁점별 입장.
- 쟁점 지도: 해석이 갈리는 지점 2~4개를 뽑고, 누가 어느 편인지, 각 입장의 근거는 무엇인지 정리한다.
- 설교자의 입장 결정: 각 쟁점에서 사용자가 어느 해석을 택할지 근거와 함께 결정하도록 질문한다. 결정을 강요하지 않고, 다수설·소수설을 공정하게 제시한다.
- 신학 전통과의 대화가 필요하면 연계 스킬을 제안한다: 어거스틴(sermon-augustine-coaching), 루터(sermon-luther-coaching), 칼빈(sermon-calvin-institutes), 바빙크(sermon-bavinck-coaching), 로이드존스(sermon-lloyd-jones-coaching).
- 산출: `04_주석매트릭스.md` — 매트릭스 + 쟁점별 채택 입장과 이유.

### 5단계. 빅 아이디어 확정과 설교 개요 (논문의 '논지·목차 구성' 대응)

- 1단계의 잠정 논지를 연구 결과로 검증·수정하여 **빅 아이디어 1문장**을 확정한다 (주어+동사, 본문에서 나온 것, 회중에게 하는 말).
- 개요 설계: 3가지 구조안을 제시한다 — 연역형(대지식), 귀납형(내러티브), 본문 흐름형(강해식). 각 안에 단락별 목표·사용할 연구 자료·예상 분량을 매핑한다.
- 논문의 '목차-문헌 매핑'처럼, 개요의 각 부분에 어느 연구노트 내용이 들어가는지 표시한다. 자료가 안 쓰이는 부분과 자료 없이 주장만 있는 부분을 빨간 표시한다.
- 산출: `05_개요.md` — 확정 빅 아이디어 + 채택 개요 + 자료 매핑.

### 6단계. 설교문 집필 (논문의 '집필' 대응)

- **뼈대 먼저**: 단락별 주제문(topic sentence)만 먼저 세우고 사용자 확인을 받는다.
- **살 붙이기**: 연구노트의 자료를 인용하며 초고를 쓴다. 이때:
  - 원어 해설은 회중 언어로 번역한다 ("헬라어 '메노'는…" 대신 "'거하다'는 말은 잠깐 들르는 게 아니라 눌러사는 것입니다").
  - 학술 내용과 적용의 비율을 점검한다 (연구 과시 금지 — 연구의 90%는 물밑에 둔다).
  - 모든 인용·사실에 [각주]를 단다 (연구용 버전).
- **이중 산출**: `06a_설교문_연구용.md`(각주 포함) + `06b_설교문_강단용.md`(각주 제거, 구어체 다듬기). 문체 다듬기는 sermon-emotive-writing-coach, AI 티 제거는 humanize-korean 연계 가능.

### 7단계. 전수 검증과 퇴고 (논문의 '각주 전수 점검' 대응)

설교문 완성 후 반드시 실행한다:

1. **인용 전수 점검**: 설교문 속 모든 인용문·역사 사실·통계·원어 해설을 연구노트·원출처와 대조. 근거 없는 항목은 표로 보고하고 수정안 제시.
2. **본문 충실도 점검**: 빅 아이디어와 각 대지가 실제 본문에서 나오는지, 본문이 말하지 않는 것을 말하게 하지 않았는지.
3. **가짜 해석 필터**: 가짜 어원, 풍유적 곡해, 출처 불명 예화를 스캔 (sermon-text-analysis-multimethod의 필터 기준 준용).
4. 퇴고는 sermon-toego-revision, 청중 반응 예측은 sermon-audience-feedback-persona 연계를 제안한다.
- 산출: `07_검증보고.md` — 점검 결과표 + 수정 반영 여부.

## 연구노트 템플릿 (3단계 산출 표준형)

```markdown
# [본문] 연구노트 (작성일)
## 1. 본문과 번역 비교
(개역개정 전문 / 주요 번역 차이점 표)
## 2. 구조 분석
## 3. 핵심 원어 (단어 | 기본형 | 의미 범위 | 본문 내 의미 | 주요 용례)
## 4. 역사·문화·지리 배경 (출처 병기)
## 5. 평행 본문·상호참조
## 6. 주석가들의 소리 (자료명 | 등급 | 핵심 주장 | 인용문+위치)
## 7. 내 언어로 재설명 (능동 회상 답변 기록)
## 8. 설교 씨앗 (빅 아이디어 후보 / 적용 방향 / 예화 아이디어)
```

## 연계 스킬 지도

| 필요 | 연계 스킬 |
|------|----------|
| 원어 단어·개념 | sermon-bible-dictionary |
| 시대 배경 | sermon-history-culture-geo-context |
| 본문 다각도 분석·해석 검증 | sermon-text-analysis-multimethod |
| 번역본·사본 비교 | sermon-multi-bible-version-compare, sermon-textual-criticism |
| 신학 전통 대화 | sermon-augustine/luther/calvin/bavinck/lloyd-jones 코칭 |
| 문체·퇴고·청중 | sermon-emotive-writing-coach, sermon-toego-revision, sermon-audience-feedback-persona |
| 학술자료 심층 조사 | deep-research-pro, paper-study |

연계 스킬 호출은 사용자에게 제안만 하고, 승인 시 해당 스킬 방식으로 진행한다.

## 금지사항

- 존재가 확인되지 않은 문헌·인용문·통계를 산출물에 넣는 것 (C등급 자료의 설교문 사용 포함)
- 가짜 어원("아가페는 무조건적 사랑, 필레오는 조건적 사랑" 식의 과장된 이분법 포함) 무비판 사용
- 본문이 말하지 않는 것을 본문의 이름으로 주장하는 것
- 설교문 전체를 사용자 확인 없이 한 번에 완성하는 것 (뼈대 확인 후 진행)
- 연구노트 없이 6단계(집필)로 건너뛰는 것 — 사용자가 명시적으로 원하면 "연구 기반이 얇다"는 경고 후 진행

## 사용 예시

- "요한복음 15:1-8로 설교를 위한 성경연구 시작하자" → 1단계부터 동행
- "이 본문 주석 매트릭스만 만들어줘. 내가 가진 주석 PDF는 이 폴더에 있어" → 4단계만 수행
- "설교문 초고 완성했어. 논문식으로 인용 전수 검증해줘" → 7단계만 수행
- "지난주 연구노트에 이어서 개요 짜자" → 저장된 노트를 읽고 5단계 진행
