# kbg 발표자료 3 — 손글씨 한 장 지도

출처: 유튜브 혼잡스(@honjobs) 발표 영상 프레임 실측(2026-10-28). 다른 스타일과 비교·선택은 라우터 [kbg-발표자료](../kbg-발표자료/SKILL.md)에서 한다.
[template.html](template.html)이 정본 틀이다(엔진·CSS 인라인, 단독 실행). **구조와 클래스는 그대로 두고 내용만 바꾼다.**

## 0. 시작 전

- 발표자료이므로 **작업 시작 전 한 번** 묻는다: "`awesome-ai-motion` 스킬도 함께 쓸까요?" (CLAUDE.md 8번). 승낙해도 이 스킬의 시각 규칙이 우선이다.
- [template.html](template.html)을 `~/Desktop/cysjavis/<주제폴더>/<한글이름>.html`로 복사한 뒤 고친다(정본). 아티팩트는 사본이다.
- 통계는 출처 있는 값만 쓴다. 없으면 자막이나 라벨에 "(예시)"를 붙인다.
- 공용 마크업(`data-in`, `data-cams`, `data-count` 등)과 진행 키는 라우터 [kbg-발표자료](../kbg-발표자료/SKILL.md) 2·3절에 있다.

## 1. 스타일 사양 (영상 실측)

| 토큰 | 값 | 쓰임 |
|---|---|---|
| `--bg` | `#FFFFFF` | 종이 |
| `--ink` | `#1A1A1A` | 손글씨, 선 |
| `--red` | `#E2362B` | 번호 동그라미 `.no`, 강조 타원, 체크 |
| `--blue` | `#2A6CF0` | 보조 주석 |
| `--yellow` | `#FADC46` | 형광 `.hi` |
| `--dimbg` | `#8E918E` | 포커스 카드 뒤 어두운 회색 |

| 글꼴 | 쓰임 |
|---|---|
| Nanum Pen Script (`--pen`) | 큰 손글씨 `.hw` 80px, `.hw.xl` 120px |
| Gaegu (`--hand`) | 작은 손글씨 `.hw.s` 58px, 주석 |
| Pretendard | 자막(하단, 흰 테두리 그림자), 카드 본문 |

화면 구성: **장면 1이 핵심**. 큰 종이(`.world` 3600×2100) 위에 제목(가운데 위) + 4구역(좌상·우상·좌하·우하)을 놓고, `data-cams`로 박자마다 한 구역씩 비춘 뒤 마지막 박자에 k≈.52로 전체를 보여준다. 자막은 아래에 흰 후광을 두른 검정 글씨.

## 2. 부품

| 클래스 | 모양 |
|---|---|
| `.world` + `.at` | 큰 종이, `.at`은 left/top 절대 배치 |
| `.hw` (`.s` `.xl`) | 써지는 손글씨 |
| `svg.draw` | 선·화살표·밑줄이 그려짐. 그리기 전엔 숨김 |
| `.chk` | 손그림 체크박스. 부모가 켜지면 안의 체크가 그려짐 |
| `.no` | 빨간 번호 동그라미 ①②③ |
| `.hi` | 노랑 형광 |
| `.doodle[data-icon]` | 손그림 느낌 아이콘 |
| `.focus` > `.card` > `.shot` | 어둡게 깐 배경 위 흰 카드 + 화면 캡처 자리 |
| 빨간 타원 + "↳ 출처 확인!" | 카드 안 특정 줄 강조 |

예시 장면 3개: ① 한 장 지도(카메라 7박자) ② 포커스 카드(빨간 타원 강조) ③ 체크리스트.

## 3. 모션 어휘

| 움직임 | 구현 | 쓸 때 |
|---|---|---|
| 카메라 팬·줌 | `data-cams="x,y,k|…"` | 구역 이동. 구역은 k 1.3~1.35, 전체 보기 k .5 안팎 |
| 글씨 쓰기 | `.hw` clip-path 왼→오 | 제목·항목 |
| 선 그리기 | `svg.draw` | 연결·화살표·밑줄 |
| 체크 | `.chk.on` | 체크리스트 |
| 포커스 | `.focus` | 한 부분만 크게 보여줄 때 |

카메라 좌표는 **구역 중심**이다. 구역을 옮기면 `data-cams`도 같이 고친다. 확인은 `--shots … --beats`.

## 절차

1. 원고를 **장면 → 박자**로 쪼갠다. 박자 하나 = 자막 한 줄 = 화면 변화 하나. 자막은 25자 안팎.
2. 템플릿 예시 장면 중 가장 가까운 것을 복제해 내용만 바꾼다. 쓰지 않는 예시 장면은 지운다.
3. 브라우저로 열어 →로 넘기며 확인한다. 넘침·겹침은 글자 크기보다 **박자를 나눠서** 푼다.
4. 장면별 확인 사진: `node ~/.claude/skills/kbg-발표자료/tools/record.mjs 발표.html --shots 확인 --beats`
